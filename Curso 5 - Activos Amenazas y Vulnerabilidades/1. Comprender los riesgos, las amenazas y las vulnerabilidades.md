# Comprender los Riesgos, las Amenazas y las Vulnerabilidades

En esta lectura introductoria del **Curso 5: Activos, Amenazas y Vulnerabilidades**, se examinan los tres conceptos pilares de la gestión de la seguridad de la información: **Riesgo**, **Amenaza** y **Vulnerabilidad**, su interrelación matemática y operativa, y cómo los analistas de seguridad evalúan la probabilidad y el impacto para proteger los activos críticos de una organización.

## 2. La Ecuación del Riesgo de Seguridad

El riesgo cuantifica la probabilidad de que una amenaza explote una vulnerabilidad y la magnitud del daño resultante.

$$\text{Riesgo} = \text{Probabilidad (Likelihood)} \times \text{Impacto (Impact)}$$

```
┌─────────────────────────┐                           ┌─────────────────────────┐
│      PROBABILIDAD       │                           │         IMPACTO         │
├─────────────────────────┤             ✖             ├─────────────────────────┤
│ ¿Qué tan probable es    │                           │ ¿Qué tan severo será el │
│ que ocurra el evento?   │                           │ daño financiero u       │
│ (Enfoque principal del  │                           │ operativo si ocurre?    │
│ analista defensivo).    │                           │                         │
└─────────────────────────┘                           └─────────────────────────┘
```

### ¿Por qué se calcula el riesgo en las organizaciones?
1. **Prevenir Incidentes Costosos:** Evitar disrupciones operativas, multas regulatorias y pérdidas de reputación.
2. **Mejora Continua:** Identificar brechas de seguridad en arquitecturas, software y políticas internas.
3. **Definir el Apetito de Riesgo:** Determinar qué riesgos pueden ser tolerados, mitigados, transferidos o evitados.
4. **Priorización de Recursos:** Asignar presupuesto y esfuerzos defensivos a la protección de los activos más valiosos (*crown jewels*).

> [!TIP]
> **Enfoque del Analista de Ciberseguridad:** Aunque el impacto depende del activo afectado, la labor diaria del analista se concentra en **reducir la probabilidad** mediante controles de seguridad, parches, monitoreo y concienciación.

## 4. Categorías de Amenazas

Las amenazas se clasifican según la intencionalidad del origen:

```
┌────────────────────────────────────────────────────────┐
│                 CATEGORÍAS DE AMENAZAS                 │
└──────────────────────────┬─────────────────────────────┘
                           │
          ┌────────────────┴────────────────┐
          ▼                                 ▼
┌──────────────────┐               ┌──────────────────┐
│   INTENCIONADAS  │               │ NO INTENCIONADAS │
├──────────────────┤               ├──────────────────┤
│ • Cibercrimen    │               │ • Errores humanos│
│ • Malware / APTs │               │ • Tailgating     │
│ • Sabotaje       │               │ • Desastres nat. │
│ • Ransomware     │               │ • Fallos de hw   │
└──────────────────┘               └──────────────────┘
```

* **Amenazas Intencionadas:** Actores maliciosos deliberados (hackers, competidores desleales, atacantes internos) que explotan sistemas para robo de datos, extorsión o interrupción.
* **Amenazas No Intencionadas:** Incidentes fortuitos o descuidos (un empleado que sostiene la puerta en una zona restringida permitiendo el acceso no autorizado / *tailgating*, errores de configuración accidental o desastres climáticos).

## 5. Categorías de Vulnerabilidades

Los puntos débiles del entorno corporativo se dividen en dos vertientes principales:

| Categoría | Origen | Ejemplos en Seguridad |
| :--- | :--- | :--- |
| **Técnicas** | Fallos en tecnología, código o arquitectura. | Puertos abiertos innecesarios, contraseñas por defecto, software sin parchar, protocolos inseguros (HTTP/Telnet). |
| **Humanas** | Comportamientos, hábitos y descuidos de las personas. | Pérdida de tarjetas de acceso físicas, uso de contraseñas débiles, susceptibilidad a ataques de ingeniería social y phishing. |

---

## Puntos Clave

> [!IMPORTANT]
> * **Distinción Rigurosa:** El riesgo es el resultado potencial; la amenaza es la fuerza o evento adverso; la vulnerabilidad es la debilidad existente que hace posible el ataque.
> * **Fórmula Clave:** $\text{Riesgo} = \text{Probabilidad} \times \text{Impacto}$. La gestión de seguridad busca minimizar la probabilidad de explotación.
> * **Diversidad de Fuentes:** Las amenazas pueden ser deliberadas o accidentales, y las vulnerabilidades abarcan tanto fallas tecnológicas como factores humanos.
> * **Valor Profesional:** Dominar y comunicar con precisión esta taxonomía es indispensable para interactuar eficazmente en equipos de respuesta a incidentes y auditoría.
