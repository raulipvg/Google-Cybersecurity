# Directrices de Seguridad en Acción (NIST CSF)

En esta lectura del **Curso 5: Activos, Amenazas y Vulnerabilidades**, se analiza la estructura operativa e implementación práctica del **Marco de Ciberseguridad del NIST (NIST CSF)**, sus tres componentes fundamentales (**Núcleo**, **Niveles** y **Perfiles**), la incorporación de la función **Gobernar** (CSF v2.0), y la metodología de 4 pasos de **CISA** para evaluar y madurar la postura de seguridad organizacional.

---

## 1. Orígenes y Evolución del NIST CSF

El **Marco de Ciberseguridad del NIST** (*NIST Cybersecurity Framework - CSF*) fue publicado originalmente en 2014 por el Instituto Nacional de Estándares y Tecnología de los Estados Unidos (NIST) para proteger la **infraestructura crítica nacional**.

```
┌────────────────────────────────────────────────────────┐
│               EVOLUCIÓN Y ALCANCE DEL CSF              │
└──────────────────────────┬─────────────────────────────┘
                           │
          ┌────────────────┴────────────────┐
          ▼                                 ▼
┌──────────────────┐               ┌──────────────────┐
│   ORIGEN (2014)  │               │ CSF 2.0 (HOY)    │
├──────────────────┤               ├──────────────────┤
│ • Infraestructura│               │ • Global / PYMEs │
│   crítica en EE.UU│              │ • Cualquier sector│
│ • 5 Funciones    │               │ • 6 Funciones    │
│   básicas        │               │   (+ Gobernar)   │
└──────────────────┘               └──────────────────┘
```

* **Naturaleza Voluntaria e Imparcial:** El CSF no es una ley obligatoria, sino un conjunto voluntario de directrices, normas y mejores prácticas de libre adopción.
* **Flexibilidad Universal:** Diseñado para ser adoptado por organizaciones de cualquier tamaño, presupuesto o sector industrial (desde startups hasta multinacionales y entidades públicas).

## 3. El Núcleo del CSF: Las 6 Funciones Fundamentales

En febrero de 2024, el NIST actualizó el marco al **CSF 2.0**, añadiendo la función **Gobernar (*Govern*)** para posicionar el liderazgo y la estrategia de riesgos en el centro de todas las operaciones de seguridad:

```
                          ┌─────────────────────────┐
                          │   GOBERNAR (Govern)     │ ➔ Estrategia, Políticas y Liderazgo
                          └────────────┬────────────┘
                                       │
     ┌──────────────────┬──────────────┴───────┬──────────────────┐
     ▼                  ▼                      ▼                  ▼
┌──────────────┐ ┌──────────────┐      ┌──────────────┐ ┌──────────────┐
│ IDENTIFICAR  │ │   PROTEGER   │      │   DETECTAR   │ │  RESPONDER   │
│  (Identify)  │ │  (Protect)   │      │   (Detect)   │ │  (Respond)   │
├──────────────┤ ├──────────────┤      ├──────────────┤ ├──────────────┤
│ Inventario de│ │ Controles y  │      │ Monitorización││ Contención y │
│ activos y    │ │ salvaguardas │      │ continua de  │ │ mitigación   │
│ riesgos.     │ │ preventivas. │      │ incidentes.  │ │ del ataque.  │
└──────────────┘ └──────────────┘      └──────────────┘ └──────────────┘
                                                              │
                                                              ▼
                                                       ┌──────────────┐
                                                       │  RECUPERAR   │
                                                       │  (Recover)   │
                                                       ├──────────────┤
                                                       │ Restauración │
                                                       │ y resiliencia│
                                                       └──────────────┘
```

### Matriz de Funciones del Núcleo (Core):

| Función | Propósito Principal | Ejemplo Operativo en Ciberseguridad |
| :--- | :--- | :--- |
| **Gobernar (*GV*)** | Establecer la estrategia de ciberseguridad, gestión de riesgos en la cadena de suministro y supervisión directiva. | Definir políticas corporativas de seguridad y apetito de riesgo. |
| **Identificar (*ID*)** | Comprender los activos organizacionales, el entorno legal y las vulnerabilidades existentes. | Mantener un inventario actualizado de hardware y bases de datos. |
| **Proteger (*PR*)** | Implementar controles defensivos para limitar o contener el impacto de un potencial ataque. | Desplegar autenticación MFA, cifrado de datos y capacitación anti-phishing. |
| **Detectar (*DE*)** | Monitorear continuamente los sistemas para descubrir eventos e intrusiones de seguridad con rapidez. | Configuración de reglas de alerta en herramientas SIEM e IDS/IPS. |
| **Responder (*RS*)** | Ejecutar planes de contención, erradicación y comunicación tras la confirmación de un incidente. | Aislar un host infectado de la red y ejecutar el playbook de respuesta. |
| **Recuperar (*RC*)** | Restaurar capacidades operativas y servicios afectados, aplicando lecciones aprendidas. | Restaurar bases de datos desde copias de seguridad limpias y verificadas. |

## 4. Niveles de Implementación (*Tiers*)

Los niveles del CSF (del 1 al 4) no representan necesariamente una calificación obligatoria, sino una escala para evaluar qué tan integrados y automatizados están los procesos de ciberseguridad:

| Nivel | Denominación | Características de la Postura de Seguridad |
| :---: | :--- | :--- |
| **Tier 1** | **Parcial (*Partial*)** | Gestión de riesgos informal y reactiva; controles limitados y aislados. |
| **Tier 2** | **Informado sobre Riesgo (*Risk Informed*)** | Conciencia de seguridad existente, pero los procesos no están estandarizados a nivel corporativo. |
| **Tier 3** | **Repetible (*Repeatable*)** | Políticas formalmente documentadas, procesos consistentes y personal entrenado. |
| **Tier 4** | **Adaptativo (*Adaptive*)** | Seguridad predictiva y automatizada; adopción ágil de defensas frente a amenazas avanzadas (*APTs*). |

## 5. Metodología de Implementación según CISA

La **Agencia de Ciberseguridad y Seguridad de las Infraestructuras de EE.UU. (CISA)** propone un ciclo metódico de 4 fases para aplicar el CSF en cualquier industria:

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│     FASE 1      │       │     FASE 2      │       │     FASE 3      │       │     FASE 4      │
│  Perfil Actual  │ ────► │  Evaluación de  │ ────► │   Análisis de   │ ────► │ Plan de Acción  │
│ (Current State) │       │     Riesgos     │       │ Brechas (Gaps)  │       │ (Implementation)│
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

1. **Crear el Perfil Actual (*Current Profile*):** Mapear el estado real de las operaciones de seguridad actuales y delimitar los activos críticos del negocio.
2. **Realizar una Evaluación de Riesgos (*Risk Assessment*):** Analizar qué amenazas y vulnerabilidades amenazan los activos y contrastar con regulaciones legales.
3. **Análisis de Brechas (*Gap Analysis*):** Comparar el Perfil Actual con el Perfil Objetivo (*Target Profile*) para priorizar las deficiencias más críticas.
4. **Implementar el Plan de Acción:** Asignar recursos y ejecutar proyectos específicos para cerrar las brechas identificadas.

> [!NOTE]
> **Marcos frente a Regulaciones:** Las **regulaciones** (como HIPAA, PCI DSS o GDPR) son leyes obligatorias cuyo incumplimiento acarrea multas severas; los **marcos** (como NIST CSF o ISO 27001) son herramientas estructuradas voluntarias que facilitan alcanzar y demostrar dicho cumplimiento.

## Puntos Clave

> [!IMPORTANT]
> * **Estructura Tríadica:** El CSF se compone de **Núcleo** (qué hacer), **Niveles** (nivel de madurez) y **Perfiles** (alineación con metas del negocio).
> * **Novedad CSF 2.0:** La función **Gobernar** sitúa la toma de decisiones ejecutiva y la cadena de suministro en el centro de la resiliencia digital.
> * **Ciclo CISA:** Implementar el marco requiere documentar el estado actual, evaluar riesgos, medir brechas frente al estado deseado y ejecutar planes correctivos.
> * **Alineación Global:** Facilita la comunicación entre áreas técnicas y directivas, simplificando auditorías y relaciones de confianza con clientes y proveedores.
