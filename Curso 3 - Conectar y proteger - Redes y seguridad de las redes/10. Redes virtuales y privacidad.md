# Redes Virtuales y Privacidad

En esta lectura se sintetiza el funcionamiento de las principales herramientas y tecnologías de seguridad de red encargadas de mantener la confidencialidad de los datos y controlar el acceso a redes privadas. Se examina en profundidad el funcionamiento de los **Firewalls** (sin estado, con estado y NGFW), los **servidores Proxy** (directo e inverso), las **VPNs** (*Virtual Private Networks*) y su integración con **SD-WAN**.

---

## Síntesis de Protocolos de Red y Seguridad Inalámbrica

Para contextualizar el filtrado y cifrado de tráfico, es fundamental recordar las tres categorías de protocolos y los estándares de seguridad inalámbrica:

| Categoría | Función Principal | Ejemplos Representativos |
| :--- | :--- | :--- |
| **Comunicación** | Establecer y mantener conexiones entre clientes y servidores. | TCP, UDP, HTTP, DNS, SMTP |
| **Gestión** | Supervisión, diagnóstico y resolución de problemas de red. | ICMP, ARP |
| **Seguridad** | Cifrado y protección de datos en tránsito. | IPSec, SSL/TLS, HTTPS, SFTP |

> **Recordatorio de Seguridad Wi-Fi:** Los protocolos de seguridad inalámbrica (como **WPA2** y **WPA3**) cifran la comunicación vía radio entre el dispositivo y el punto de acceso mediante **AES**. WPA3 añade **SAE** para resistir ataques de fuerza bruta. Ambas versiones cuentan con modo **Personal** (clave única PSK para hogares) y modo **Enterprise** (autenticación centralizada 802.1X/RADIUS para organizaciones).

## Firewalls (Cortafuegos)

Un **firewall** es un dispositivo de hardware o una aplicación virtual de red (*Network Virtual Appliance* - NVA) que inspecciona y filtra el tráfico de red entrante y saliente basándose en políticas de seguridad predeterminadas.

```

                  │              EVOLUCIÓN DE FIREWALLS             │
                  └────────────────────────┬────────────────────────┘
                                           │
         ┌─────────────────────────────────┼─────────────────────────────────┐
         │                                 │                                 │
         ▼                                 ▼                                 ▼
┌──────────────────┐              ┌──────────────────┐              ┌──────────────────┐
│   SIN ESTADO     │              │    CON ESTADO    │              │  NUEVA GENERACIÓN│
│   (Stateless)    │              │    (Stateful)    │              │     (NGFW)       │
├──────────────────┤              ├──────────────────┤              ├──────────────────┤
│ • Evalúa cada    │              │ • Rastrea tabla  │              │ • DPI (Deep      │
│   paquete aislado│              │   de estados     │              │   Packet Insp.)  │
│ • Requiere reglas│              │ • Regla en una   │              │ • Conciencia de  │
│   bidireccionales│              │   sola dirección │              │   aplicaciones   │

└──────────────────┘              └──────────────────┘              └──────────────────┘
```

### Categorías Principales de Firewalls:

#### 1. Firewalls Sin Estado (Stateless)
- **Funcionamiento:** Evalúan cada paquete de datos de manera aislada basándose en reglas estáticas (dirección IP de origen/destino y número de puerto).
- **Limitación:** No recuerdan si un paquete forma parte de una conexión previamente establecida.
- **Configuración:** Requieren definir reglas explícitas en **ambas direcciones** (entrante y saliente).

#### 2. Firewalls Con Estado (Stateful)
- **Funcionamiento:** Mantienen una **tabla de estado** *(state table)* que rastrea las conexiones activas y el contexto de las sesiones de comunicación.
- **Ventaja:** Solo requieren configurar una regla en una sola dirección (ej. permitir tráfico saliente). El firewall inspecciona la tabla de estado y permite automáticamente el tráfico de retorno correspondiente sin necesitar una regla entrante adicional.

#### 3. Firewalls de Nueva Generación (NGFW - Next-Generation Firewall)
Representan el nivel más avanzado de protección perimetral, superando las capacidades del firewall con estado tradicional.
- **Inspección Profunda de Paquetes (DPI - *Deep Packet Inspection*):** Examina el contenido real del cuerpo del paquete (payload) y no solo las cabeceras.
- **Conciencia de Aplicación (*Application-Aware*):** Pueden identificar, permitir o bloquear tráfico basándose en la aplicación específica (ej. bloquear llamadas de VoIP dentro de una app sin bloquear todo el tráfico HTTP).
- **IPS (*Intrusion Prevention System*):** Detectan y bloquean proactivamente patrones de ataque en tiempo real.
- **Servicios Adicionales:** Incorporan sandboxing de malware en la nube, filtrado de URLs/DNS y antivirus de red.

## Servidores Proxy

Un **servidor proxy** actúa como intermediario o barrera entre los clientes de una red interna y los recursos externos en Internet, utilizando mecanismos como NAT para enmascarar la red privada.

```
                     FORWARD PROXY (PROXY DIRECTO)
┌────────────────┐        ┌────────────────┐        ┌────────────────┐
│ Cliente Interno├───────>│  Forward Proxy ├───────>│ Servidor Web   │
│  (Red Privada) │        │ (Filtra/Oculta)│        │   (Internet)   │
└────────────────┘        └────────────────┘        └────────────────┘

                     REVERSE PROXY (PROXY INVERSO)
┌────────────────┐        ┌────────────────┐        ┌────────────────┐
│ Usuario Remoto ├───────>│ Reverse Proxy  ├───────>│Servidores Int. │
│   (Internet)   │        │ (Protege/WAF)  │        │ (Red Privada)  │
└────────────────┘        └────────────────┘        └────────────────┘
```

### Tipos de Servidores Proxy:

1. **Forward Proxy (Proxy Directo):**
   - Intercepta las solicitudes salientes de los **usuarios internos** que acceden a recursos en Internet.
   - **Funciones:** Ocultar la dirección IP interna, aplicar políticas de navegación (bloqueo de sitios maliciosos o no autorizados) y guardar en caché contenido web para acelerar la navegación.

2. **Reverse Proxy (Proxy Inverso):**
   - Intercepta las peticiones de **usuarios externos** dirigidas a los servidores internos de la organización.
   - **Funciones:** Proteger los servidores de la red privada frente a ataques directos, realizar balanceo de carga *(load balancing)*, descarga de SSL/TLS *(SSL Offloading)* y actuar como Web Application Firewall (WAF).

## Redes Privadas Virtuales (VPN) y SD-WAN

### Red Privada Virtual (VPN)
Una **VPN** es un servicio que crea un túnel de comunicación seguro sobre una red pública no segura (como Internet), cifrando los datos en tránsito y ocultando la dirección IP real del usuario.

- **Mecanismo de Encapsulación:** Proceso mediante el cual los datos originales (sin cifrar o cifrados) se envuelven dentro de un nuevo paquete cifrado con cabeceras adicionales. Esto permite transmitir la información de forma anónima y protegida a través de la infraestructura pública.

```
[Paquete Cifrado Exterior (IP Pública VPN)] ───► [Datos Originales Cifrados (IP Privada)]
```

- **Uso Corporativo:** Permite a los empleados remotos conectarse de forma segura a la red interna corporativa y acceder a servidores, bases de datos o aplicaciones empresariales.
- **Uso Personal:** Oculta la ubicación geográfica y la IP del usuario a sitios web externos y proveedores de Internet (ISP), preservando la privacidad.

### Integración con SD-WAN
- **SD-WAN (*Software-Defined Wide Area Network*):** Servicio de red WAN virtual definida por software que optimiza la conexión de usuarios distribuidos geográficamente con aplicaciones alojadas en múltiples nubes o centros de datos.
- **Tendencia SASE (*Secure Access Service Edge*):** Las organizaciones modernas combinan el cifrado de las VPNs con la gestión dinámica de rutas de SD-WAN para ofrecer acceso seguro basado en la nube.

---

## Puntos Clave

1. **Firewalls Con Estado vs. Sin Estado:** Los firewalls con estado rastrean conexiones activas en una tabla de estado (requieren reglas en una sola dirección); los sin estado evalúan paquetes aislados sin memoria.
2. **NGFW:** Ofrecen inspección profunda de paquetes (DPI), filtrado a nivel de aplicación (Capa 7) e IPS integrado.
3. **Proxies:** Forward proxy protege a los usuarios internos al navegar afuera; Reverse proxy protege a los servidores internos frente al tráfico entrante.
4. **VPN y Encapsulación:** Enuelven datos cifrados dentro de nuevos paquetes para proteger la confidencialidad y dirección IP en tránsito.
5. **SD-WAN + VPN:** Arquitectura moderna para conectar de forma segura infraestructuras distribuidas y entornos multi-nube.
