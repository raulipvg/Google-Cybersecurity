## Parte 1: Proporcione un resumen del problema encontrado en el registro de tcpdump

Como parte del protocolo DNS, se utilizó el protocolo UDP para contactar al servidor DNS y recuperar la dirección IP correspondiente al nombre de dominio `yummyrecipesforme.com`. Se utilizó el protocolo ICMP para responder con un mensaje de error, lo que indica problemas para contactar al servidor DNS. El mensaje UDP enviado desde su navegador al servidor DNS se muestra en las dos primeras líneas de cada evento del registro. La respuesta de error ICMP del servidor DNS a su navegador se muestra en la tercera y cuarta línea de cada evento del registro con el mensaje de error: *"udp port 53 unreachable"* (puerto UDP 53 inalcanzable). 

Dado que el puerto 53 está asociado con el tráfico del protocolo DNS, sabemos que se trata de un problema con el servidor DNS. Los problemas al ejecutar el protocolo DNS quedan más en evidencia debido a que el signo más después del número de identificación de la consulta 35084 indica banderas con el mensaje UDP y el símbolo *"A?"* indica banderas asociadas a la ejecución de operaciones del protocolo DNS. Debido al mensaje de respuesta de error ICMP sobre el puerto 53, es muy probable que el servidor DNS no esté respondiendo. Esta suposición se ve respaldada por las banderas asociadas con el mensaje UDP saliente y la recuperación del nombre de dominio.

## Parte 2: Explique su análisis de los datos y proporcione al menos una causa del incidente

El incidente ocurrió hoy a la 1:24 p.m. Los clientes notificaron a la organización que recibieron el mensaje *"destination port unreachable"* (puerto de destino inalcanzable) cuando intentaron visitar el sitio web `yummyrecipesforme.com`. El equipo de ciberseguridad que brinda servicios de TI a la organización cliente está investigando actualmente el problema para que los clientes puedan volver a acceder al sitio web. 

En nuestra investigación del problema, realizamos pruebas de captura de paquetes (*packet sniffing*) utilizando `tcpdump`. En el archivo de registro resultante, encontramos que el puerto 53 de DNS no estaba localizable (*unreachable*). El siguiente paso es identificar si el servidor DNS está caído o si el tráfico hacia el puerto 53 está siendo bloqueado por el firewall. El servidor DNS podría estar caído debido a un ataque de Denegación de Servicio (DoS) exitoso o a una mala configuración.
