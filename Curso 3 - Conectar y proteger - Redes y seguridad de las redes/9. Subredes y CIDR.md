# Subredes y Notación CIDR

En esta lectura se examina el concepto de **división en subredes** *(subnetting)* y el sistema de **Enrutamiento Sin Clases entre Dominios** (*Classless Inter-Domain Routing* - **CIDR**), analizando cómo estas técnicas permiten segmentar redes de computadoras para mejorar la eficiencia del tráfico y fortalecer la postura de ciberseguridad mediante la creación de zonas de seguridad aisladas.

---

## Visión General de la División en Subredes (Subnetting)

La **división en subredes** es la técnica mediante la cual una red IP grande se divide en varios segmentos lógicos más pequeños y organizados denominados **subredes** *(subnets)*.

- **Metáfora:** Si la red global de una empresa equivale a una gran ciudad, cada subred representa un barrio o sector bien delimitado dentro de esa ciudad.
- **Funcionamiento:** Se logra combinando una dirección IP con una **máscara de subred**, creando efectivamente una *"red dentro de otra red"*.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                RED EMPRESARIAL GLOBAL                                 │
└───────────────────────────────────────────┬────────────────────────────────────────────┘
                                            │
         ┌──────────────────────────────────┼──────────────────────────────────┐
         │                                  │                                  │
         ▼                                  ▼                                  ▼
┌──────────────────┐               ┌──────────────────┐               ┌──────────────────┐
│    SUBRED A      │               │    SUBRED B      │               │    SUBRED C      │
│  (Servidores)    │               │  (Administración)│               │  (Invitados)     │
│ 192.168.1.0/24   │               │ 192.168.2.0/24   │               │ 192.168.3.0/24   │
└──────────────────┘               └──────────────────┘               └──────────────────┘
```

### Ventajas Operativas de la Subdivisión:
1. **Eficiencia en las Comunicaciones:** Si dos dispositivos pertenecen a la misma subred, los *switches* conmutan el tráfico directamente entre ellos sin enviar paquetes al router, reduciendo la latencia y la congestión.
2. **Optimización del Ancho de Banda:** Contiene el tráfico de difusión *(broadcast)* dentro de los límites de cada subred en lugar de inundar toda la red corporativa.
3. **Creación de Zonas de Seguridad:** Permite definir fronteras lógicas (Zona Controlada, Zona Desmilitarizada o DMZ, Zona Restringida) e imponer reglas de control de acceso entre ellas.

## CIDR (Classless Inter-Domain Routing / Enrutamiento Sin Clases entre Dominios)

### Evolución: Del Direccionamiento Con Clase a CIDR

En los inicios de Internet (década de 1980), se utilizaba el **direccionamiento con clase** (*Classful Addressing*), el cual agrupaba las direcciones IP en bloques rígidos:
- **Clase A:** `/8` (redes gigantescas)
- **Clase B:** `/16` (redes medianas)
- **Clase C:** `/24` (redes pequeñas)
- **Clase D y E:** Multicast y uso experimental.

Hacia la década de 1990, la rápida expansión de Internet agotó las direcciones de estas clases rígidas. Para solucionar este problema, se introdujo **CIDR** (*Classless Addressing*), eliminando la estructura rígida de clases y permitiendo asignar máscaras de subred de longitud variable con total flexibilidad.

### Notación CIDR (Prefijo de Red)

CIDR utiliza la notación de **barra diagonal (`/`)** seguida de un número al final de la dirección IP. Este número representa la cantidad de **bits de red** en la máscara de subred.

#### Ejemplo de Notación CIDR: `198.51.100.0/24`
- **Dirección IP de Red:** `198.51.100.0`
- **Prefijo CIDR:** `/24` (indica que los primeros 24 bits pertenecen a la red y los 8 bits restantes a los hosts).
- **Máscara de Subred equivalente:** `255.255.255.0`
- **Rango de Direcciones IPv4 comprendidas:** Desde `198.51.100.0` hasta `198.51.100.255` (256 direcciones IP totales en el bloque).

## Ventajas de Seguridad de la División en Subredes

Para los analistas de ciberseguridad, el *subnetting* proporciona ventajas estratégicas fundamentales:

1. **Aislamiento y Microsegmentación:** Permite aislar departamentos o tipos de tráfico (ej. separar el tráfico de IoT o red de invitados del entorno de servidores de producción).
2. **Control de Tráfico mediante Firewalls y ACLs:** Al dividir la red en subredes, se pueden ubicar cortafuegos (*Firewalls*) y Listas de Control de Acceso (*ACLs*) entre ellas para inspeccionar, filtrar y bloquear conexiones no autorizadas.
3. **Contención de Incidentes y Malware:** Si un malware o un atacante compromete un equipo en una subred aislada, la segmentación impide que el ataque se propague libremente (*movimiento lateral*) a otras partes sensibles de la organización.
4. **Eficiencia en la Utilización de IP Públicas:** Permite a la empresa utilizar internamente miles de direcciones IP privadas divididas en múltiples subredes sin necesidad de solicitar rangos de IP públicas adicionales a su Proveedor de Servicios de Internet (ISP).

---

## Puntos Clave

1. **Concepto de Subnetting:** División de una red grande en subredes lógicas más pequeñas y manejables para mejorar la eficiencia y seguridad.
2. **Definición de CIDR:** Sistema de direccionamiento sin clase (*Classless*) que utiliza la notación `/prefijo` para definir el tamaño de la subred de manera flexible.
3. **Notación de Barra (`/`):** El número tras la barra indica cuántos bits representan la red (ej. `/24` equivale a `255.255.255.0`).
4. **Aplicación en Ciberseguridad:** Facilita la creación de zonas de seguridad (DMZ, Zonas Restringidas), previene el movimiento lateral de amenazas y permite aplicar reglas de Firewall/ACL detalladas.
