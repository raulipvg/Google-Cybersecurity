# Protocolos VPN: WireGuard e IPSec

En esta lectura se profundiza en las **Redes Privadas Virtuales (VPN)**, analizando las diferencias estructurales entre las VPN de **Acceso Remoto** y las VPN de **Sitio a Sitio** (*Site-to-Site*), así como una comparativa detallada entre dos de los protocolos de cifrado VPN más utilizados: **WireGuard** e **IPSec**.

---

## Conceptos Fundamentales de VPN

Una **VPN (*Virtual Private Network*)** es un servicio de seguridad que establece un túnel cifrado de comunicación entre un dispositivo final y una red remota a través de una infraestructura pública no segura (como Internet).

- **Función Principal:** Ocultar la dirección IP real del cliente, cifrar los datos en tránsito y garantizar el acceso confiable a recursos de red.
- **Punto Final (*Endpoint*):** Cualquier dispositivo conectado a la red capaz de enviar o recibir datos (computadoras, servidores, dispositivos móviles, routers).
- **Protocolo VPN:** Conjunto estandarizado de reglas e instrucciones que definen cómo se establece el túnel, cómo se realiza la autenticación y qué algoritmos de cifrado se aplican para transmitir los datos entre endpoints.

## Tipos de VPN: Acceso Remoto vs. Sitio a Sitio

```
                     VPN DE ACCESO REMOTO (Cliente a Servidor)
┌─────────────────┐        Túnel Cifrado (Internet)       ┌─────────────────┐
│ Dispositivo User├──────────────────────────────────────>│  Servidor VPN   ├─► Red Interna
│ (Laptop/Mobile) │                                       │  (Gateway Corp) │
└─────────────────┘                                       └─────────────────┘

                       VPN DE SITIO A SITIO (Red a Red)
┌─────────────────┐        Túnel Cifrado (Internet)       ┌─────────────────┐
│   Red Sede A    ├──────────────────────────────────────>│   Red Sede B    │
│(Router Gateway A)│                                      │(Router Gateway B)│
└─────────────────┘                                       └─────────────────┘
```

### 1. VPN de Acceso Remoto (Remote Access VPN)
- **Propósito:** Conectar usuarios individuales o empleados remotos con la red de su organización o con un servidor VPN de privacidad.
- **Mecanismo:** El dispositivo cliente instala un software o cliente VPN que establece una conexión cifrada contra un servidor VPN central a través de Internet.
- **Uso Común:** Teletrabajadores que acceden a sistemas corporativos o usuarios personales que buscan anonimizar su tráfico en redes Wi-Fi públicas.

### 2. VPN de Sitio a Sitio (Site-to-Site VPN)
- **Propósito:** Interconectar dos o más redes completas (LANs) pertenecientes a una misma organización pero ubicadas en diferentes coordenadas geográficas.
- **Mecanismo:** La conexión se establece directamente entre dispositivos de borde (*gateways* o routers) de cada ubicación de forma transparente para los usuarios finales.
- **Uso Común:** Conectar oficinas sucursales con la sede central o centros de datos.
- **Consideración:** Tienen una complejidad de configuración y mantenimiento significativamente superior a las VPN de acceso remoto.

## Comparativa de Protocolos: WireGuard vs. IPSec

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                          WIREGUARD  vs.  IPSEC                                         │
└────────────────────────────────────────────────────────────────────────────────────────┘

        WIREGUARD                                         IPSEC
 ┌──────────────────────┐                         ┌──────────────────────┐
 │ • Diseño Moderno     │                         │ • Protocolo Tradicional│
 │ • ~4,000 líneas code │                         │ • Muy Complejo       │
 │ • Alta Velocidad     │                         │ • Soporte Nativo OS  │
 │ • Cifrado Moderno    │                         │ • Estándar Enterprise│
 └──────────────────────┘                         └──────────────────────┘
```

### 1. WireGuard
- **Naturaleza:** Protocolo VPN de código abierto (*open-source*) extremadamente ligero y moderno.
- **Base de Código:** Desarrollado con aproximadamente **4,000 líneas de código** (en comparación con las cientos de miles de IPSec/OpenVPN), lo que facilita su auditoría de seguridad y reduce drásticamente la superficie de ataque.
- **Rendimiento:** Ofrece velocidades de conexión y descarga muy superiores, con menor consumo de CPU y menor latencia.
- **Versatilidad:** Diseñado para funcionar de manera óptima tanto en conexiones **Cliente-Servidor (Acceso Remoto)** como **Sitio a Sitio**.
- **Casos de Uso Ideales:** Transmisión de video de alta definición, descargas de archivos pesados y entornos móviles con cambios frecuentes de red.

### 2. IPSec (Internet Protocol Security)
- **Naturaleza:** Conjunto estandarizado de protocolos que opera en la **Capa de Red (Capa 3)** del modelo OSI/TCP-IP. Es uno de los estándares VPN más antiguos y probados del mercado.
- **Compatibilidad:** Ampliamente respaldado de forma nativa por prácticamente todos los sistemas operativos (Windows, macOS, Linux, iOS, Android) y hardware de red (Cisco, Fortinet, Palo Alto).
- **Seguridad:** Utiliza criptografía sólida para autenticación y cifrado (AH y ESP), ampliamente probada en entornos corporativos durante décadas.
- **Complejidad:** Alta complejidad de configuración debido a la cantidad de parámetros negotiados en IKE (*Internet Key Exchange*).

| Característica | WireGuard | IPSec |

| **Antigüedad / Madurez** | Moderno (Lanzado en 2016) | Histórico / Maduro (Años 90) |

| **Escenario Principal** | Acceso Remoto, móviles y Sitio a Sitio ágil | VPNs Corporativas Sitio a Sitio tradicionales |

## Criterios de Selección para Ciberseguridad

Al seleccionar un protocolo VPN, los analistas de seguridad deben considerar los siguientes factores:

1. **Infraestructura Existente:** Si la organización utiliza equipamiento de red empresarial tradicional, **IPSec** suele ser la opción integrada por defecto.
2. **Requisitos de Rendimiento:** Si se requiere maximizar el ancho de banda y reducir la latencia en conexiones móviles o teletrabajo, **WireGuard** es la opción preferida.
3. **Mantenimiento y Auditoría:** La simplicidad de **WireGuard** disminuye el riesgo de errores de configuración humana, mientras que **IPSec** requiere administradores con experiencia específica en IKEv1/IKEv2.

---

## Puntos Clave

1. **Concepto de Protocolo VPN:** Reglas que rigen la creación del túnel cifrado y el transporte de datos entre endpoints.
2. **Acceso Remoto vs. Sitio a Sitio:** Acceso remoto conecta usuarios a la red; Sitio a Sitio conecta redes enteras entre sí.
3. **WireGuard:** Protocolo moderno, ultra rápido, ligero y de código abierto ideal para alto rendimiento.
4. **IPSec:** Protocolo corporativo tradicional de Capa 3, universalmente compatible y probado para conexiones Sitio a Sitio.
