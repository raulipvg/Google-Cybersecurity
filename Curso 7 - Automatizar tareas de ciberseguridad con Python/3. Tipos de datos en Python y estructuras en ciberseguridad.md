# Tipos de Datos y Estructuras en Python para Ciberseguridad

En esta tercera entrega del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se profundiza en el sistema de tipos de datos del lenguaje. Como analista de seguridad, manipular registros de red, cabeceras de paquetes, reglas de cortafuegos y alertas de SIEM requiere dominar tanto los **tipos de datos escalares fundamentales** (`str`, `int`, `float`, `bool`) como las **estructuras de datos y colecciones avanzadas** (`list`, `tuple`, `dict`, `set`), comprendiendo sus implicaciones en la mutabilidad, el consumo de memoria y la integridad de la evidencia.

---

## 1. Fundamentos del Sistema de Tipos en Python

Python es un lenguaje de **tipado dinámico** y **fuertemente tipado**:
* **Dinámico:** No es necesario declarar explícitamente el tipo de una variable al crearla; el intérprete infiere el tipo en tiempo de ejecución según el valor asignado.
* **Fuerte:** El intérprete no realiza conversiones automáticas implícitas entre tipos incompatibles (por ejemplo, intentar sumar una cadena de texto y un número entero generará un `TypeError` en lugar de concatenarlos silenciosamente).

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                          JERARQUÍA DE TIPOS DE DATOS EN PYTHON                            │
└─────────────────────────────────────────────┬─────────────────────────────────────────────┘
                                              │
         ┌────────────────────────────────────┴────────────────────────────────────┐
         ▼                                                                         ▼
┌───────────────────────────────────────────┐             ┌───────────────────────────────────────────┐
│        TIPOS ESCALARES / BÁSICOS          │             │     COLECCIONES / ESTRUCTURAS DE DATOS    │
├───────────────────────────────────────────┤             ├───────────────────────────────────────────┤
│ • Cadena (str): Texto Unicode             │             │ • Lista (list): Secuencia mutable []      │
│ • Entero (int): Números sin decimal       │             │ • Tupla (tuple): Secuencia inmutable ()   │
│ • Flotante (float): Precisión decimal     │             │ • Diccionario (dict): Clave-Valor {k: v}  │
│ • Booleano (bool): True / False           │             │ • Conjunto (set): Valores únicos {v}      │
└───────────────────────────────────────────┘             └───────────────────────────────────────────┘
```

### Inspección de Tipos con `type()` e `isinstance()`
Para verificar el tipo de dato que contiene una variable durante una investigación forense:

```python
ip_origen = "192.168.1.50"
puerto = 443
es_malicioso = True

print(type(ip_origen))      # <class 'str'>
print(type(puerto))         # <class 'int'>
print(isinstance(es_malicioso, bool)) # True
```

## 2. Tipos de Datos Escalares (Primitivos)

### 2.1. Cadenas de Caracteres (`str`)

Una **cadena (*string*)** es una secuencia ordenada e **inmutable** de caracteres Unicode. Puede contener letras, números, símbolos de puntuación, espacios y caracteres especiales de escape.

#### Sintaxis y Buenas Prácticas de Comillas:
Las cadenas pueden delimitarse con comillas dobles (`""`) o comillas simples (`''`). Ambas son funcionalmente idénticas en Python, pero se recomienda mantener una convención homogénea (Google Cybersecurity utiliza comillas dobles):

```python
mensaje_alerta = "updates needed"
porcentaje_riesgo = "20%"
version_agente = "5.0"
puerto_cadena = "35"
mascara_red = "**/**/**"
cadena_vacia = "" # Cadena sin caracteres de longitud 0
```

#### Propiedades Críticas en Seguridad:
* **Cadena Vacía (`""`):** Posee una longitud de 0 (`len("") == 0`) y evalúa a `False` en contextos booleanos. Se utiliza a menudo para inicializar variables de lectura de logs o representar campos faltantes.
* **Inmutabilidad:** Una vez creada, una cadena no puede modificarse internamente. Cualquier operación de limpieza (como eliminar saltos de línea con `.strip()`) genera un objeto completamente nuevo en memoria, garantizando que el registro original no sea corrupto accidentalmente.
* **Formateo Moderno con f-strings (Python 3.6+):**
  ```python
  host = "srv-database-01"
  estado = "CRITICAL"
  print(f"[ALERTA SOC] Host: {host} | Estado de Seguridad: {estado}")
  ```

---

### 2.2. Números Enteros (`int`)

Los **enteros (*integers*)** representan números enteros positivos, negativos o cero, sin punto decimal.

```python
reintentos_fallidos = 5
codigo_estado_http = 404
temperatura_rack = -12
puerto_ssh = 22
```

#### Particularidades Técnicas en Python 3:
* **Precisión Arbitraria:** A diferencia de lenguajes como C, Java o Go (donde un entero de 32 bits desborda a los 2.147.483.647), los enteros en Python 3 tienen **precisión ilimitada**. Su tamaño máximo solo está restringido por la memoria RAM disponible del sistema, lo cual es vital al procesar números extremadamente grandes en algoritmos criptográficos (como claves RSA o curvas elípticas).
* **Operaciones Aritméticas Básicas:**
  ```python
  intentos = 5 + 2    # Suma -> 7
  diferencia = 10 - 3 # Resta -> 7
  factor = 4 * 2      # Multiplicación -> 8
  ```

---

### 2.3. Números de Punto Flotante (`float`)

Los **flotantes (*floating-point numbers*)** representan números que contienen un punto decimal, siguiendo el estándar de precisión doble IEEE 754.

```python
score_cvss = 9.8
latencia_ms = 0.34
temperatura_sensor = -2.2
tiempo_cero = 0.0
```

#### División Entera (`//`) vs. División Real (`/`):
En Python 3, el comportamiento de los operadores de división es fundamental para evitar cálculos erróneos en métricas de seguridad:

```python
# 1. División Estándar (/): SIEMPRE devuelve un tipo float
print(1 / 4)       # Salida: 0.25 (float)
print(1.0 / 4.0)   # Salida: 0.25 (float)
print(4 / 2)       # Salida: 2.0  (float, incluso si la división es exacta)

# 2. División de Piso o Entera (//): Redondea hacia abajo al entero más cercano
print(1 // 4)      # Salida: 0    (int)
print(1.0 // 4.0)  # Salida: 0.0  (float: mantiene el tipo flotante pero redondea abajo)
print(7 // 2)      # Salida: 3    (int)
```

> [!TIP]
> **Casos de Uso en Ciberseguridad:** Los flotantes se utilizan para calcular promedios de tráfico por segundo (*bandwidth throughput*), porcentajes de paquetes TCP retransmitidos y puntuaciones del Sistema de Puntuación de Vulnerabilidades Comunes (*CVSS Base Score*).

---

### 2.4. Datos Booleanos (`bool`)

El tipo de dato **booleano** solo puede adoptar uno de dos valores literales: `True` (Verdadero) o `False` (Falso).

```python
acceso_concedido = True
usuario_bloqueado = False
```

#### Reglas de Uso y Operadores de Comparación:
* **Sin Comillas:** Los booleanos son palabras reservadas y **no deben llevar comillas**. Si se escribe `"True"`, Python lo tratará como una cadena de texto (`str`) de cuatro caracteres, no como un booleano.
* **Resultados de Comparación:** Toda expresión de comparación matemática o de igualdad produce un resultado booleano:
  ```python
  print(9 > 10)         # False
  print(443 == 443)     # True
  print("root" != "admin") # True
  ```
* **Subclase de Entero:** En Python, `bool` es una subclase de `int`. Numéricamente, `True` equivale a `1` y `False` equivale a `0`.

## 3. Estructuras de Datos y Colecciones

Las tareas de ciberseguridad rara vez trabajan con un único dato aislado; generalmente involucran colecciones de registros, listas de usuarios autorizados, reglas de acceso y pares de claves criptográficas.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                    COLECCIONES EN PYTHON: MATRIZ DE PROPIEDADES                           │
├──────────────┬────────────┬─────────────┬─────────────┬─────────────────┬─────────────────┤
│ Estructura   │ Sintaxis   │ Mutable     │ Ordenada    │ Admite Duplicad.│ Búsqueda (Avg)  │
├──────────────┼────────────┼─────────────┼─────────────┼─────────────────┼─────────────────┤
│ **Lista**    │ `[a, b, c]`│ **Sí**      │ **Sí**      │ **Sí**          │ $O(N)$ (Lineal) │
│ **Tupla**    │ `(a, b, c)`│ **No**      │ **Sí**      │ **Sí**          │ $O(N)$ (Lineal) │
│ **Diccionario**|`{k: v}`  │ **Sí**      │ **Sí** (3.7+)│ Claves: **No**  │ $O(1)$ (Hash)   │
│ **Conjunto** │ `{a, b, c}`│ **Sí**      │ **No**      │ **No** (Únicos) │ $O(1)$ (Hash)   │
└──────────────┴────────────┴─────────────┴─────────────┴─────────────────┴─────────────────┘
```

---

### 3.1. Listas (`list`)

Una **lista** es una colección secuencial, ordenada y **mutable** de elementos delimitada por corchetes (`[]`). Puede contener elementos homogéneos o mezclar tipos heterogéneos, e incluso anidar otras listas.

```python
# Listas homogéneas y heterogéneas
ids_alertas = [12, 36, 54, 1, 7]
usuarios_soc = ["eraab", "arusso", "drosas"]
estados_reglas = [True, False, True, True]
registro_mixto = [15, "approved", True, 45.5, False]
lista_vacia = [] # Lista sin elementos
```

#### Operaciones Dinámicas en el SOC:
Al ser mutable, una lista permite agregar, eliminar o modificar elementos en tiempo de ejecución:
```python
ips_cuarentena = ["10.0.0.4", "10.0.0.9"]

# Agregar una nueva IP detectada por el IDS
ips_cuarentena.append("192.168.1.105")

# Eliminar una IP tras verificar falso positivo
ips_cuarentena.remove("10.0.0.4")

print(ips_cuarentena) # ['10.0.0.9', '192.168.1.105']
```

---

### 3.2. Tuplas (`tuple`)

Una **tupla** es una colección secuencial, ordenada e **inmutable** delimitada por paréntesis (`()`).

```python
usuarios_estaticos = ("wjaffrey", "arutley", "dkot")
metricas_sensores = (46, 2, 13, 2, 8, 0, 0)
flags_permiso = (True, False, True, True)
config_servicio = ("wjaffrey", 13, True)
```

#### Relevancia en Ciberseguridad e Integridad:
* **Garantía de Inmutabilidad (*Tamper-Proof*):** Una vez instanciada, no es posible añadir, quitar ni reordenar elementos en una tupla. Si se almacenan identificadores de software autorizados o firmas de binarios en una tupla, el código garantiza que ninguna función interna modificará accidentalmente la lista de control de acceso durante la ejecución.
* **Eficiencia de Memoria:** Las tuplas consumen significativamente menos memoria RAM que las listas y su acceso es marginalmente más rápido, lo que las hace ideales para procesar millones de registros de red estáticos.
* **Uso en Enlaces de Red (*Sockets*):** La biblioteca estándar `socket` de Python utiliza tuplas de dos elementos para definir direcciones de red inmutables: `("192.168.1.1", 80)`.

```python
# Ejemplo de endpoint inmutable
socket_servidor = ("10.10.10.1", 443)
# socket_servidor[1] = 8080  # Esto generará TypeError: 'tuple' object does not support item assignment
```

---

### 3.3. Diccionarios (`dict`)

Un **diccionario** es una estructura de datos basada en **pares clave-valor (*key-value pairs*)** delimitada por llaves (`{}`). Cada clave se asocia a un valor mediante dos puntos (`:`), y los pares se separan por comas.

```python
edificios_datacenter = {
    1: "East",
    2: "West",
    3: "North",
    4: "South"
}

perfil_analista = {
    "username": "drosas",
    "soc_level": 2,
    "clearance": "Top Secret",
    "active": True
}
```

#### Eficiencia y Recuperación en $O(1)$:
* **Búsqueda Indexada Inmediata:** A diferencia de una lista (donde buscar un elemento requiere recorrerla de principio a fin, complejidad $O(N)$), en un diccionario la búsqueda por clave se calcula mediante una función hash en tiempo constante $O(1)$, sin importar si el diccionario contiene 10 o 10.000.000 de registros.
* **Similitud con JSON / Eventos SIEM:** Los registros estructurados de eventos en plataformas como Splunk o Chronicle (UDM) se representan naturalmente en Python como diccionarios:
  ```python
  evento_auth = {
      "timestamp": "2026-09-20T16:00:00Z",
      "event_type": "USER_LOGIN",
      "src_ip": "198.51.100.45",
      "success": False
  }
  print(f"IP atacante: {evento_auth['src_ip']}")
  ```

---

### 3.4. Conjuntos (`set`)

Un **conjunto (*set*)** es una colección **desordenada** de elementos **únicos** delimitada por llaves (`{}`) o instanciada con `set()`.

```python
usuarios_activos = {"jlanksy", "drosas", "nmason"}
```

#### Características Clave:
* **Eliminación Automática de Duplicados:** Si se intenta insertar un elemento existente, el conjunto ignora la duplicación silenciosamente.
* **Deduplicación Ultrarrápida en Logs:** Si se extraen 500.000 IPs atacantes de un archivo Syslog, convertirlas a un conjunto elimina todas las repeticiones instantáneamente:
  ```python
  ips_crudos = ["192.168.1.1", "10.0.0.1", "192.168.1.1", "172.16.0.5", "10.0.0.1"]
  ips_unicas = set(ips_crudos)
  print(ips_unicas) # {'192.168.1.1', '10.0.0.1', '172.16.0.5'}
  ```
* **Operaciones Matemáticas de Conjuntos en Threat Intelligence:**
  ```python
  iocs_semana_pasada = {"malware.exe", "trojan.bin", "dropper.ps1"}
  iocs_semana_actual = {"dropper.ps1", "ransomware.exe", "keylogger.py"}

  # Intersección (&): Amenazas persistentes observadas en ambas semanas
  persistentes = iocs_semana_pasada & iocs_semana_actual
  print("Amenazas persistentes:", persistentes) # {'dropper.ps1'}

  # Diferencia (-): Amenazas mitigadas o desaparecidas
  mitigadas = iocs_semana_pasada - iocs_semana_actual
  print("Amenazas inactivas:", mitigadas) # {'malware.exe', 'trojan.bin'}
  ```

## 4. Mutabilidad, Inmutabilidad y Protección de la Evidencia

En seguridad informática y análisis forense digital, la distinción entre tipos mutables e inmutables es de vital importancia:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    CLASIFICACIÓN DE MUTABILIDAD EN PYTHON                    │
├──────────────────────────────────────┬───────────────────────────────────────┤
│ TIPOS INMUTABLES (NO MODIFICABLES)   │ TIPOS MUTABLES (MODIFICABLES IN-SITU) │
├──────────────────────────────────────┼───────────────────────────────────────┤
│ • int, float, bool                   │ • list (listas)                       │
│ • str (cadenas de texto)             │ • dict (diccionarios)                 │
│ • tuple (tuplas)                     │ • set (conjuntos)                     │
│ • bytes                              │ • bytearray                           │
└──────────────────────────────────────┴───────────────────────────────────────┘
```

> [!IMPORTANT]
> **Preservación de Evidencia Forense:**
> Al procesar artefactos de un compromiso (como firmas hash, marcas de tiempo o volcados de memoria), utilizar estructuras **inmutables** (como cadenas o tuplas) previene que rutinas intermedias de análisis corrompan o alteren los valores de la evidencia, asegurando la integridad de la cadena de custodia probatoria.

## 5. Conversión de Tipos (*Type Casting*) y Gestión de Errores

Con frecuencia, los datos leídos desde archivos de registro (`.log`, `.csv`, `.json`) o sockets de red ingresan al script en formato de cadena de texto (`str`). Para operar matemáticamente con ellos, el analista debe realizar una conversión de tipos (*casting*):

```python
# Entrada cruda recibida desde un log de firewall
puerto_texto = "8080"
puerto_numero = int(puerto_texto) # Conversión a entero

# Conversión de conteo a string para concatenar en reporte
total_amenazas = 42
reporte = "Amenazas detectadas: " + str(total_amenazas)

# Conversión a booleano
print(bool(""))     # False (cadena vacía)
print(bool("admin"))# True (cadena no vacía)
print(bool(0))      # False (cero)
print(bool(1))      # True
```

> [!WARNING]
> **Manejo de Errores en Casting de Logs:**
> Si un archivo de registro contiene campos corruptos (por ejemplo, el texto `"puerto: desconocido"` en lugar de `"80"`), invocar `int("desconocido")` provocará un fallo de ejecución `ValueError`. En scripts de producción de un SOC, estas conversiones deben protegerse siempre mediante bloques de control de excepciones (`try / except`).

## 6. Puntos Clave para el Analista de Ciberseguridad

* **Selección Estratégica del Tipo:** Utilizar `str` para identificadores alfanuméricos, `int` para puertos/códigos de estado, `float` para puntuaciones de riesgo (CVSS) y `bool` para indicadores de estado y control de flujo.
* **Listas vs. Tuplas:** Utilizar listas cuando los datos cambien dinámicamente (añadir nuevas IPs a una cola de escaneo) y tuplas cuando se requiera inmutabilidad estricta y protección contra modificaciones accidentales (pares IP/puerto, credenciales fijas).
* **Diccionarios para Registros Estructurados:** Los diccionarios son el equivalente natural a los registros JSON y eventos UDM/CIM de los sistemas SIEM, proporcionando búsquedas inmediatas en tiempo constante $O(1)$.
* **Conjuntos para Deduplicación y CTI:** Los conjuntos (`set`) permiten depurar millones de eventos duplicados en una sola instrucción y calcular correlaciones complejas (intersecciones y diferencias de IoCs) de manera algebraica.
* **Precisión en División:** Recordar que `/` genera siempre flotantes y `//` realiza división entera de piso truncando decimales.
