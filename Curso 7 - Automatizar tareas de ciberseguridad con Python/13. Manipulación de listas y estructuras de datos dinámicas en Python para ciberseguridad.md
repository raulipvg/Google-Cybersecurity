# Manipulación de Listas y Estructuras de Datos Dinámicas en Python para Ciberseguridad

En esta decimotercera entrega del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se explora a fondo el tipo de dato **Lista (`list`)**, la estructura de datos dinámica por excelencia en Python. En las operaciones de un Centro de Operaciones de Seguridad (SOC), los analistas utilizan listas para gestionar colecciones en constante cambio: listas de control de acceso (ACL), rangos de direcciones IP en cuarentena, inventarios de activos comprometidos, colas de eventos del SIEM y hashes de malware bajo análisis. Se profundiza en la **indexación**, el **rebanado (*slicing*)**, la **mutabilidad in-situ**, los métodos estructurales (`.append()`, `.insert()`, `.remove()`, `.index()`) y las técnicas de población dinámica mediante bucles y comprensiones.

---

## 1. Las Listas como Contenedores Dinámicos en el SOC

Una **lista** es una colección secuencial, ordenada y **mutable** de elementos heterogéneos delimitada por corchetes (`[ ]`). A diferencia de las cadenas de caracteres (que son inmutables), las listas están diseñadas específicamente para crecer, reducirse y reorganizarse en tiempo de ejecución.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                          MODELO DE MEMORIA DE UNA LISTA EN CPYTHON                        │
└─────────────────────────────────────────────┬─────────────────────────────────────────────┘
                                              │
 ┌──────────────────────────────────────┐     │     ┌──────────────────────────────────────┐
 │      ARRAY DINÁMICO DE PUNTEROS      │     │     │          OBJETOS EN EL HEAP          │
 ├──────────────────────────────────────┤     │     ├──────────────────────────────────────┤
 │ [0] ─────────────────────────────────┼─────┼───► │ Objeto str: "elarson"                │
 │ [1] ─────────────────────────────────┼─────┼───► │ Objeto str: "fgarcia"                │
 │ [2] ─────────────────────────────────┼─────┼───► │ Objeto str: "tshah"                  │
 │ [3] ─────────────────────────────────┼─────┼───► │ Objeto str: "sgilmore"               │
 └──────────────────────────────────────┘     │     └──────────────────────────────────────┘
```

> [!NOTE]
> **Heterogeneidad de Tipos:** Aunque en ciberseguridad las listas suelen almacenar colecciones homogéneas (como solo cadenas de IPs o solo códigos de estado enteros), Python permite alojar múltiples tipos de datos en una misma lista: `["srv-web01", 443, True, 9.8]`.

## 2. Indexación y Rebanado (*Slicing*) de Listas

Cada elemento de la lista ocupa una posición numerada que inicia en el índice `0`.

### 2.1. Indexación Directa
Para extraer un único elemento, se utiliza la notación entre corchetes con el índice deseado:

```python
username_list = ["elarson", "fgarcia", "tshah", "sgilmore"]

# Extracción mediante variable
print(username_list[2]) # "tshah"

# Extracción directa sobre literal
print(["elarson", "fgarcia", "tshah", "sgilmore"][2]) # "tshah"
```

---

### 2.2. Rebanado de Listas (*Sublistas*)
Al aplicar la sintaxis `lista[inicio:fin]`, el resultado es una **nueva lista independiente** denominada sublista. El índice `inicio` es inclusivo y `fin` es estrictamente exclusivo ($[inicio, fin)$):

```python
username_list = ["elarson", "fgarcia", "tshah", "sgilmore"]

# Extrae los elementos en los índices 0 y 1 (el índice 2 'tshah' queda excluido)
sublista = username_list[0:2]
print("Sublista extraída:", sublista) # ['elarson', 'fgarcia']
```

> [!WARNING]
> **Alineación de Índices y `IndexError`:**
> Al igual que con las cadenas, intentar acceder a un índice inexistente (`username_list[10]`) provocará un error fatal `IndexError: list index out of range`. Sin embargo, el rebanado (`username_list[0:100]`) es tolerante y no arroja error; simplemente devuelve todos los elementos disponibles hasta el final de la lista.

## 3. Mutabilidad: Modificación de Elementos In-Situ

La diferencia arquitectónica más importante entre las cadenas y las listas es la **mutabilidad**. En una lista, es posible reasignar un elemento individual directamente mediante su índice sin necesidad de crear una lista nueva en memoria:

```python
username_list = ["elarson", "fgarcia", "tshah", "sgilmore"]
print("Antes de modificar:", username_list)

# Modificación directa del elemento en el índice 1
username_list[1] = "bmoreno"

print("Después de modificar:", username_list)
# Salida: ['elarson', 'bmoreno', 'tshah', 'sgilmore']
```

```
MUTABILIDAD IN-SITU:
  username_list[1] ────(se desvincula de "fgarcia")────► [ "fgarcia" ] (Liberado)
         │
         └─────────────────────────────────────────────► [ "bmoreno" ]
```

* La dirección de memoria de la lista (`id(username_list)`) **sigue siendo exactamente la misma**.
* Esta característica permite actualizar estados masivos de seguridad (como cambiar el flag de un firewall o actualizar un usuario) con un costo de memoria mínimo.

## 4. Métodos Estructurales de Lista

Los métodos de lista permiten alterar la longitud y el orden de los elementos.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                       MÉTODOS DE MANIPULACIÓN DE LISTAS EN PYTHON                         │
├──────────────┬────────────────────────────────────────────────────────────────────────────┤
│ Método       │ Efecto Operativo en la Estructura de Datos                                 │
├──────────────┼────────────────────────────────────────────────────────────────────────────┤
│ `.append(x)` │ Agrega el elemento `x` al final absoluto de la lista.                      │
│ `.insert(i,x)`│ Inserta el elemento `x` en el índice exacto `i`, desplazando el resto.     │
│ `.remove(x)` │ Busca y elimina la primera ocurrencia del valor `x`.                       │
│ `.index(x)`  │ Devuelve el índice numérico de la primera coincidencia del valor `x`.     │
└──────────────┴────────────────────────────────────────────────────────────────────────────┘
```

---

### 4.1. Inserción al Final con `.append()`
El método `.append()` añade un único elemento al final de la lista. Es el método más eficiente en términos de CPU (complejidad amortizada **$O(1)$**), ya que no requiere desplazar los demás elementos en memoria.

```python
username_list = ["bmoreno", "wjaffrey", "tshah", "sgilmore"]
username_list.append("btang")

print("Lista con nuevo usuario:", username_list)
# ['bmoreno', 'wjaffrey', 'tshah', 'sgilmore', 'btang']
```

#### Población de Listas en Bucles `for`:
Es el patrón estándar para acumular eventos leídos desde archivos o APIs de seguridad:

```python
# Inicialización de lista acumuladora vacía
numbers_list = []

for i in range(5):
    numbers_list.append(i)

print("Lista poblada:", numbers_list) # [0, 1, 2, 3, 4]
```

---

### 4.2. Inserción en Posición Específica con `.insert()`
El método `.insert(indice, elemento)` sitúa un nuevo dato en cualquier posición arbitraria. Los elementos que ocupaban ese índice y los subsiguientes se desplazan automáticamente un paso hacia la derecha:

```python
username_list = ["elarson", "bmoreno", "tshah", "sgilmore"]

# Insertar "wjaffrey" en el índice 2 (tercera posición)
username_list.insert(2, "wjaffrey")

print(username_list)
# ['elarson', 'bmoreno', 'wjaffrey', 'tshah', 'sgilmore']
```
* **Costo Computacional:** Posee una complejidad temporal **$O(N)$**. Si la lista contiene 1.000.000 de IPs y se inserta al inicio (`.insert(0, ip)`), Python debe mover 1.000.000 de punteros en memoria. Use `.append()` siempre que el orden al inicio no sea indispensable.

---

### 4.3. Eliminación por Valor con `.remove()`
El método `.remove(elemento)` busca secuencialmente el valor especificado y **elimina únicamente su primera aparición**:

```python
username_list = ["elarson", "bmoreno", "wjaffrey", "tshah", "sgilmore"]

# Elimina al usuario revocado
username_list.remove("elarson")

print("Lista tras revocación:", username_list)
# ['bmoreno', 'wjaffrey', 'tshah', 'sgilmore']
```

> [!CAUTION]
> **Peligro de `ValueError` en `.remove()`:**
> Si el elemento no existe en la lista, `.remove()` arroja un error crítico `ValueError: list.remove(x): x not in list`. En scripts del SOC, valide siempre la pertenencia con el operador `in` o envuelva la instrucción en un bloque `try/except`:
> ```python
> target_user = "hacker_unknown"
> if target_user in username_list:
>     username_list.remove(target_user)
> else:
>     print(f"[-] El usuario {target_user} ya no estaba presente.")
> ```

---

### 4.4. Localización de Índices con `.index()`
Devuelve la posición numérica de la primera aparición del elemento buscado:

```python
username_list = ["bmoreno", "wjaffrey", "tshah", "sgilmore", "btang"]

# Localizar la posición de "tshah"
posicion = username_list.index("tshah")
print(f"El analista tshah se encuentra en el índice: {posicion}") # 2
```

* **Diferenciación Técnica:** Aunque comparte nombre con el método de cadena, `.index()` de lista es una función distinta optimizada para colecciones de objetos.
* **Manejo de Duplicados:** Si un elemento se repite dos veces, devuelve únicamente el índice de la primera instancia.
* **Excepción:** Si el elemento no existe, también arroja `ValueError`.

## 5. Matriz Comparativa: Métodos de Lista y Complejidad

| Método | Sintaxis | Complejidad | Modifica Original | Comportamiento si Falla |
| :--- | :--- | :--- | :--- | :--- |
| **`.append(x)`** | `lista.append("ip")` | **$O(1)$** (Inmediato) | **Sí** (Añade al final) | N/A |
| **`.insert(i, x)`**| `lista.insert(0, "ip")`| **$O(N)$** (Desplaza) | **Sí** (Añade en índice)| Ajusta si índice excede |
| **`.remove(x)`** | `lista.remove("ip")` | **$O(N)$** (Busca) | **Sí** (Elimina 1er match)| **Arroja `ValueError`** |
| **`.index(x)`**  | `lista.index("ip")`  | **$O(N)$** (Busca) | **No** (Solo consulta) | **Arroja `ValueError`** |

## 6. Casos Prácticos en Operaciones de Ciberseguridad (SOC)

### Caso 1: Triage Dinámico de Usuarios en Cuarentena

```python
# Lista de control de acceso a servidores críticos
allowed_users = ["analyst_01", "analyst_02", "soc_lead"]
quarantined_users = []

def suspender_usuario(usuario):
    """Mueve un usuario de la lista de permitidos a la lista de cuarentena."""
    if usuario in allowed_users:
        allowed_users.remove(usuario)
        quarantined_users.append(usuario)
        print(f"[ACCION SOC] Usuario {usuario} suspendido y puesto en cuarentena.")
    else:
        print(f"[!] El usuario {usuario} no se encuentra activo.")

suspender_usuario("analyst_02")

print("Usuarios autorizados actuales:", allowed_users)   # ['analyst_01', 'soc_lead']
print("Cuentas bajo investigación:   ", quarantined_users) # ['analyst_02']
```

---

### Caso 2: Población y Limpieza de Lista de IoCs de Red

```python
# Registros simulados de IPs atacantes con falsos positivos conocidos
raw_firewall_alerts = ["198.51.100.4", "192.168.1.1", "203.0.113.88", "127.0.0.1", "198.51.100.4"]
cleaned_iocs = []

# Filtrar direcciones de loopback y duplicados para crear una lista de bloqueo limpia
for ip in raw_firewall_alerts:
    if ip != "127.0.0.1" and ip not in cleaned_iocs:
        cleaned_iocs.append(ip)

print("Direcciones IP catalogadas para contención:", cleaned_iocs)
# Salida: ['198.51.100.4', '192.168.1.1', '203.0.113.88']
```

---

### Caso 3: Reemplazo In-Situ de Activo Retirado en el Inventario

```python
# Inventario de enrutadores perimetrales
edge_routers = ["router-north-01", "router-east-02", "router-south-01"]

# Se detecta falla física en "router-east-02" y se reemplaza por equipo de respaldo
failing_router = "router-east-02"
replacement_router = "router-east-02-BACKUP"

if failing_router in edge_routers:
    posicion_falla = edge_routers.index(failing_router)
    # Actualización in-situ conservando la posición topológica en la lista
    edge_routers[posicion_falla] = replacement_router
    print(f"[INVENTARIO ACTUALIZADO] Posición {posicion_falla} asignada a {replacement_router}.")

print("Inventario activo:", edge_routers)
```

## 7. Puntos Clave para el Analista de Ciberseguridad

* **Estructura Mutable:** A diferencia de las cadenas y tuplas, las listas pueden modificarse directamente en memoria mediante corchetes (`lista[i] = nuevo_valor`), optimizando el uso de recursos al gestionar grandes volúmenes de telemetría.
* **Rebanado Retorna Sublistas:** Extraer un segmento `lista[0:2]` genera una nueva lista sin alterar la original.
* **Eficiencia de Inserción:** Privilegie `.append()` ($O(1)$) para acumular logs; use `.insert()` ($O(N)$) solo cuando el elemento requiera una posición jerárquica obligatoria.
* **Eliminación Defensiva:** `.remove()` solo elimina la primera instancia coincidente y arroja un error `ValueError` si el dato no existe; compruébelo siempre con `in`.
* **Uso de `.index()`:** Permite localizar elementos exactos en inventarios para auditorías o reemplazos específicos.
