En esta décima entrega del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se profundiza en la arquitectura modular del lenguaje, el uso de la **Biblioteca Estándar de Python (*Python Standard Library*)**, las distintas sintaxis de **importación de módulos y funciones**, y la incorporación de **bibliotecas externas** mediante el gestor de paquetes `pip`. ### 2.1. Detección de Anomalías Estadísticas con el Módulo `statistics`
En ciberseguridad, los promedios aritméticos simples pueden ocultar ataques o verse severamente distorsionados por picos aislados. El módulo `statistics` ofrece dos funciones métricas fundamentales:
* **`mean()` (Media Aritmética):** Suma todos los valores y los divide entre el total. Es altamente sensible a valores extremos (*outliers*).
* **`median()` (Mediana):** Valor situado en el centro de un conjunto de datos ordenado. Es una métrica **robusta** que refleja la tendencia real independientemente de picos extremos generados por un ataque.

#### Análisis Forense de Inicios de Sesión Fallidos:
Considere los intentos fallidos mensuales de un usuario a lo largo del año:

```python
import statistics

# Doce meses de intentos fallidos registrados en el SIEM
monthly_failed_attempts = [20, 17, 178, 33, 15, 21, 19, 29, 32, 15, 25, 19]

# 1. Cálculo de la media
media_intentos = statistics.mean(monthly_failed_attempts)
print("Media aritmética (mean):", media_intentos) # 35.25

# 2. Cálculo de la mediana
mediana_intentos = statistics.median(monthly_failed_attempts)
print("Mediana robusta (median):", mediana_intentos) # 20.5
```

```text
Salida:
Media aritmética (mean): 35.25
Mediana robusta (median): 20.5
```

> [!IMPORTANT]
> **Interpretación Forense de la Discrepancia:**
> La mediana (`20.5`) indica que el comportamiento habitual del usuario ronda los 20 fallos por mes. La media (`35.25`) está fuertemente inflada debido al mes 3, donde se registraron **178 intentos fallidos**. Ese valor atípico (*outlier*) representa una anomalía evidente: un ataque de fuerza bruta o una prueba masiva de contraseñas (*password spraying*) ocurrida en ese periodo específico.

## 3. Sintaxis y Mecanismos de Importación

Existen dos estrategias principales para incorporar módulos en los scripts de seguridad:

### 3.1. Importación Completa del Módulo (`import module`)
Carga el módulo completo y requiere invocar sus funciones mediante la **notación de punto (*dot notation*)**: `modulo.funcion()`.

```python
import statistics

monthly_failed_attempts = [20, 17, 178, 33, 15, 21, 19, 29, 32, 15, 25, 19]
print("Media:", statistics.mean(monthly_failed_attempts))
print("Mediana:", statistics.median(monthly_failed_attempts))
```
* **Ventaja:** Evita colisiones de nombres al mantener un espacio de nombres (*namespace*) explícito. El código es autoexplicativo: queda claro de qué biblioteca procede cada función.

---

### 3.2. Importación Específica de Funciones (`from module import func`)
Extrae únicamente las funciones requeridas y las coloca directamente en el espacio de nombres local, permitiendo invocarlas sin el prefijo del módulo:

```python
from statistics import mean, median

monthly_failed_attempts = [20, 17, 178, 33, 15, 21, 19, 29, 32, 15, 25, 19]

# Se invocan directamente sin prefijo
print("Media:", mean(monthly_failed_attempts))
print("Mediana:", median(monthly_failed_attempts))
```
* **Ventaja:** Código más conciso y limpio cuando se utilizan ciertas funciones matemáticas repetidamente.

---

### 3.3. Uso de Alias para Espacios de Nombres (`import module as alias`)
Permite abreviar nombres de módulos largos mediante la palabra clave `as`, manteniendo la protección contra colisiones:

```python
import statistics as stats

intentos = [10, 20, 30]
print(stats.mean(intentos))
```

---

### 3.4. Antipatrón Crítico de Seguridad: La Importación Comodín (`from module import *`)
Importar todo el contenido de un módulo sin filtros (`from os import *`) es considerado una pésima práctica de ingeniería:
* **Contaminación del Espacio de Nombres (*Namespace Pollution*):** Introduce cientos de nombres desconocidos en su script.
* **Sombreamiento Involuntario:** Si el módulo externo contiene una función llamada `open()` o `id()`, sobrescribirá las funciones integradas de Python, provocando fallos impredecibles en el manejo de archivos y objetos.

## 4. Ecosistema de Bibliotecas Externas y Gestor `pip`

Cuando la Biblioteca Estándar no es suficiente, los analistas recurren al repositorio oficial comunitario **PyPI (*Python Package Index*)**, que contiene cientos de miles de paquetes de terceros.

### 4.1. Instalación de Paquetes con `pip`
Para instalar bibliotecas externas en un entorno local o de terminal:
```bash
pip install numpy beautifulsoup4 requests scapy
```

En entornos interactivos de cuadernos (**Jupyter Notebook** o **Google Colaboratory**), se utiliza el comando mágico `%pip`:
```python
%pip install numpy
```

## 5. Seguridad en la Cadena de Suministro de Software (*PyPI Supply Chain*)

Los atacantes atacan activamente los entornos de desarrollo mediante **ataques a la cadena de suministro de software (*Software Supply Chain Attacks*)**:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                  AMENAZAS COMUNES EN EL GESTOR DE PAQUETES PIP               │
├──────────────────────────────┬───────────────────────────────────────────────┤
│ **Typosquatting**            │ Publicar paquetes maliciosos con nombres muy  │
│                              │ similares a los legítimos (ej. `reqeusts` en  │
│                              │ lugar de `requests` o `beautifull-soup`).     │
├──────────────────────────────┼───────────────────────────────────────────────┤
│ **Dependency Confusion**     │ Engañar a `pip` para descargar librerías      │
│                              │ públicas maliciosas con el mismo nombre que   │
│                              │ paquetes privados de la empresa.              │
└──────────────────────────────┴───────────────────────────────────────────────┘
```

> [!WARNING]
> **Fijación de Versiones (*Version Pinning*):**
> En entornos corporativos del SOC, nunca ejecute instalaciones arbitrarias sin verificar el nombre exacto. Es una buena práctica congelar las dependencias verificadas en un archivo `requirements.txt` con hashes criptográficos:
> ```bash
> pip install -r requirements.txt --require-hashes
> ```

## 6. Matriz Comparativa de Estrategias de Importación

| Estrategia | Sintaxis | Notación al Llamar | Riesgo de Colisión | Recomendación PEP 8 |
| :--- | :--- | :--- | :--- | :--- |
| **Módulo Completo** | `import statistics` | `statistics.mean()` | Nulo (Espacio aislado) | **Muy recomendada** (Mapeo explícito) |
| **Importación Específica**| `from statistics import mean` | `mean()` | Bajo (Solo nombres elegidos)| **Recomendada** (Limpia y selectiva) |
| **Con Alias** | `import statistics as stats` | `stats.mean()` | Nulo (Espacio aislado) | **Recomendada** (Para nombres largos) |
| **Comodín (*Wildcard*)** | `from statistics import *` | `mean()` | **Crítico (Muy alto)** | **Estrictamente desaconsejada** |

## 7. Casos Prácticos en Operaciones de Ciberseguridad (SOC)

### Caso 1: Detección Estadística de Fuerza Bruta con `statistics`

```python
import statistics

# Registro de intentos fallidos en ventanas de 10 minutos (últimas 8 horas)
ventanas_trafico = [2, 1, 0, 3, 4, 1, 850, 2, 0, 1, 3]

mediana_base = statistics.median(ventanas_trafico)
media_observada = statistics.mean(ventanas_trafico)

print(f"Línea base habitual (Mediana): {mediana_base} eventos/ventana")
print(f"Media afectada por el pico:    {media_observada:.2f} eventos/ventana")

# Regla: Si el valor máximo supera 10 veces la mediana habitual
if max(ventanas_trafico) > (mediana_base * 10) and mediana_base > 0:
    print("[ALERTA CRÍTICA] Pico masivo de eventos anómalos detectado por el motor estadístico.")
```

---

### Caso 2: Extracción de Enlaces Maliciosos en Correos Phishing con `bs4`

```python
# Simulación de extracción de enlaces en cuerpo HTML de correo sospechoso
# Requiere: %pip install beautifulsoup4
from bs4 import BeautifulSoup

correo_html = """
<html>
    <body>
        <p>Su cuenta ha sido bloqueada. Inicie sesión para recuperarla:</p>
        <a href="http://portal-login-falso.xyz/update">Haga clic aquí</a>
        <a href="http://microsoft.com">Soporte legítimo</a>
    </body>
</html>
"""

soup = BeautifulSoup(correo_html, "html.parser")

print("Enlaces extraídos del correo de phishing:")
for enlace in soup.find_all("a"):
    url = enlace.get("href")
    if ".xyz" in url or "login" in url:
        print(f"[ALERTA IoC] Enlace sospechoso aislado: {url}")
```

## 8. Puntos Clave para el Analista de Ciberseguridad

* **Biblioteca Estándar:** Provee módulos preinstalados (`re`, `csv`, `os`, `glob`, `time`, `datetime`, `statistics`) que resuelven las tareas más comunes del SOC sin depender de librerías externas.
* **Métricas Estadísticas:** `mean()` calcula el promedio aritmético pero es susceptible a valores extremos; `median()` entrega una línea base representativa para detectar picos anómalos de fuerza bruta.
* **Sintaxis de Importación:** `import modulo` preserva el espacio de nombres requiriendo `modulo.funcion()`; `from modulo import funcion` permite llamadas directas.
* **Peligro del Comodín (`*`):** `from modulo import *` contamina el espacio de nombres y puede sobrescribir funciones nativas críticas del sistema.
* **Gestión de Paquetes Externos:** Librerías como `BeautifulSoup` (`bs4`), `NumPy`, `requests` y `Scapy` se descargan desde PyPI mediante `pip` o `%pip install` en notebooks, exigiendo cautela contra amenazas de *typosquatting*.
