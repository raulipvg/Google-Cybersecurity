# Conozca Python: Fundamentos de Programación y Automatización en Ciberseguridad

En este módulo inaugural del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se sientan las bases conceptuales, arquitectónicas y prácticas de la programación aplicada a la seguridad de la información. Se analiza cómo una computadora procesa las instrucciones desde el código fuente hasta los impulsos binarios de la CPU, el funcionamiento interno del intérprete de Python, las diferencias críticas entre versiones de sintaxis (Python 2 vs. Python 3) y las seis áreas operativas esenciales donde la automatización con Python transforma la eficiencia de un Centro de Operaciones de Seguridad (SOC).

---

## 1. Fundamentos de la Programación y Ejecución en el Hardware

La **programación** es el proceso formal de diseñar, escribir, probar y mantener un conjunto estructurado de instrucciones que indican a un sistema computacional cómo realizar tareas específicas de forma autónoma.

### 1.1. De la Lógica Humana a los Ceros y Unos

Las computadoras no comprenden el lenguaje natural humano ni las abstracciones matemáticas complejas de manera directa. A nivel de hardware, una **Unidad Central de Procesamiento (CPU)** es un circuito electrónico digital compuesto por miles de millones de transistores que solo reconocen dos estados físicos:
* **Presencia de voltaje (1 lógico)**
* **Ausencia de voltaje (0 lógico)**

Las operaciones elementales que ejecuta la CPU (como sumar registros binarios, desplazar bits o cargar direcciones de memoria RAM) se codifican mediante secuencias de números binarios denominadas **Código Máquina (*Machine Code*)**.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                      NIVELES DE ABSTRACCIÓN EN LA COMPUTACIÓN                             │
└─────────────────────────────────────────────┬─────────────────────────────────────────────┘
                                              │
                                              ▼
 ┌─────────────────────────────────────────────────────────────────────────────────────────┐
 │ Lenguaje de Alto Nivel (Python)                                                         │
 │ Código legible, abstracciones matemáticas, manejo automático de memoria:               │
 │ >>> print("Intrusión detectada desde:", ip_address)                                     │
 └────────────────────────────────────────────┬────────────────────────────────────────────┘
                                              │ Traducción / Bytecode + Intérprete
                                              ▼
 ┌─────────────────────────────────────────────────────────────────────────────────────────┐
 │ Lenguaje Ensamblador / Código Intermedio (Assembly / Bytecode)                          │

 │ LOAD_GLOBAL, CALL_FUNCTION, STORE_FAST                                                  │
 └────────────────────────────────────────────┬────────────────────────────────────────────┘
                                              │ Ensamblado / Emisión Binaria

 │ Código Máquina (Binario Puro)                                                           │

```

Comunicar directamente instrucciones a la CPU en binario o ensamblador requeriría meses de desarrollo manual para tareas simples y expondría al analista a graves errores de desbordamiento de memoria (*buffer overflow*). Los lenguajes de alto nivel como **Python** resuelven este problema proporcionando una sintaxis limpia, concisa y cercana al lenguaje natural.

## 2. Arquitectura y Funcionamiento Interno de Python

Python es un lenguaje de programación de **propósito general**, **alto nivel**, **multiparadigma** (soporta programación estructurada, orientada a objetos y funcional) y de **tipado dinámico y fuerte**.

### 2.1. ¿Cómo procesa una computadora el código Python?

A diferencia de lenguajes puramente compilados (como C o C++), que traducen todo el código fuente directamente a un archivo binario ejecutable específico de la plataforma antes de ejecutarse, Python utiliza un **intérprete**.

El intérprete de referencia estándar es **CPython** (desarrollado en C). Su flujo de procesamiento consta de dos fases:

1. **Compilación a Código Intermedio (*Bytecode*):**
   Al ejecutar un script `.py`, el motor de Python primero verifica la sintaxis y lo compila a una representación intermedia de bajo nivel optimizada llamada **Bytecode** (con extensión `.pyc`, almacenada en el directorio caché `__pycache__`).
2. **Máquina Virtual de Python (*Python Virtual Machine* - PVM):**
   La PVM es el motor de ejecución que lee el Bytecode línea por línea y lo traduce en llamadas nativas del sistema operativo e instrucciones binarias para la CPU física.

```
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  Código Fuente  │ ───►  │  Compilador     │ ───►  │  Bytecode       │ ───►  │ Máquina Virtual │ ───► [ CPU / SO ]
│   script.py     │       │  Interno CPython│       │  script.pyc     │       │   (PVM)         │      (Binario)
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

> [!NOTE]
> **Ventaja de la Interpretación:** Permite la **independencia de la plataforma**. Un mismo script de Python para auditar un cortafuegos puede ejecutarse en Windows, GNU/Linux o macOS sin necesidad de recompilar el código para cada arquitectura de procesador (x86_64, ARM, etc.), siempre que exista un intérprete de Python instalado en el host.

## 3. Versiones de Python: La Ruptura Histórica entre Python 2 y Python 3

Al desarrollar scripts de seguridad, es imperativo conocer la versión del intérprete en uso. Existen diferencias estructurales incompatibles entre las versiones mayores.

### 3.1. Cronología y Fin de Ciclo (*End-of-Life* - EOL)
* **Python 2 (2000 - 2020):** Dominó durante una década la creación de herramientas de pentesting y explotación (ej. versiones antiguas de Metasploit, exploit-db, Scapy inicial). Sin embargo, el **1 de enero de 2020 llegó oficialmente a su Fin de Vida (*End-of-Life*)**, dejando de recibir parches de seguridad y mantenimiento.
* **Python 3 (2008 - Presente):** Diseñado deliberadamente para corregir fallas fundamentales de diseño en el lenguaje, introduciendo cambios no retrocompatibles (*breaking changes*). En la actualidad, **todas las herramientas, bibliotecas y organizaciones modernas de ciberseguridad utilizan exclusivamente Python 3**.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                     DIFERENCIAS CRÍTICAS DE SINTAXIS: PYTHON 2 vs. PYTHON 3               │
├─────────────────────────┬──────────────────────────────┬──────────────────────────────────┤
│ Característica          │ Python 2 (Obsoleto)          │ Python 3 (Estándar Actual)       │
├─────────────────────────┼──────────────────────────────┼──────────────────────────────────┤
│ Declaración `print`     │ Sentencia sin paréntesis:    │ Función obligatoria:             │
│                         │ `print "Intrusion detected"` │ `print("Intrusion detected")`    │
├─────────────────────────┼──────────────────────────────┼──────────────────────────────────┤
│ Cadenas de texto        │ ASCII por defecto            │ **Unicode (UTF-8) por defecto**  │
│ y manipulación de bytes │ Cadenas y bytes mezclados    │ Separación estricta entre        │
│                         │ (propenso a fallos binarios) │ `str` (texto) y `bytes` (red)    │
├─────────────────────────┼──────────────────────────────┼──────────────────────────────────┤
│ División entera         │ Trunca decimales:            │ División flotante exacta:        │
│                         │ `5 / 2` ──► `2`              │ `5 / 2` ──► `2.5`                │
│                         │                              │ (`5 // 2` para división entera)  │
├─────────────────────────┼──────────────────────────────┼──────────────────────────────────┤
│ Entrada de usuario      │ `raw_input()` para strings   │ `input()` unificado para strings │
│                         │ `input()` evaluaba código    │ (seguro contra inyecciones)      │
└─────────────────────────┴──────────────────────────────┴──────────────────────────────────┘
```

> [!IMPORTANT]
> **Relevancia Forense y de Red del Tipado de Cadenas en Python 3:**
> En ciberseguridad, analizar paquetes de red capturados o archivos ejecutables binarios requiere manipular bytes puros. Python 3 separa rígidamente los objetos `str` (secuencias de caracteres legibles codificados en Unicode) de los objetos `bytes` (flujos hexadecimales brutos `b'\x41\x42\x43'`), lo que previene errores catastróficos en scripts de análisis forense y desensamblado.

## 4. El Rol Estratégico de Python en la Ciberseguridad

En el ámbito de la seguridad de la información, el factor crítico no suele ser la velocidad matemática bruta de la CPU, sino el **tiempo de desarrollo y reacción del analista (*Time-to-Action*)**. Python permite crear prototipos de defensa y scripts operativos en minutos en lugar de días.

La **automatización** consiste en implementar soluciones tecnológicas para ejecutar flujos de trabajo repetitivos y metódicos sin intervención humana, reduciendo la tasa de error y mitigando la sobrecarga operativa en el SOC.

### 4.1. Análisis Automatizado de Registros (*Log Analysis*)
Los analistas se enfrentan a gigabytes diarios de archivos de registro. Python permite abrir, iterar y buscar patrones maliciosos mediante expresiones regulares sin abrir manualmente editores de texto masivos.

```python
# Ejemplo conceptual: Detección de intentos fallidos en logs de autenticación
failed_attempts = {}

with open("/var/log/auth.log", "r") as log_file:
    for line in log_file:
        if "Failed password" in line:
            # Extrae la dirección IP del atacante
            parts = line.split()
            ip_address = parts[parts.index("from") + 1]
            failed_attempts[ip_address] = failed_attempts.get(ip_address, 0) + 1

# Filtrar direcciones IP que superan el umbral de fuerza bruta
for ip, count in failed_attempts.items():
    if count >= 5:
        print(f"[ALERTA] Posible Fuerza Bruta desde {ip}: {count} fallos registrados.")
```

### 4.2. Análisis Inicial y Triage de Malware (*Malware Analysis*)
Antes de enviar una muestra desconocida a ingeniería inversa profunda, Python permite automatizar el cálculo de huellas criptográficas y la consulta a servicios de reputación global como VirusTotal mediante APIs REST:

```python
import hashlib

def calcular_sha256(ruta_archivo):
    sha256_hash = hashlib.sha256()
    with open(ruta_archivo, "rb") as f:
        # Lee en bloques de 4KB para no saturar memoria RAM con archivos grandes
        for byte_block in iter(lambda: f.read(4096), b""):
            sha256_hash.update(byte_block)
    return sha256_hash.hexdigest()

archivo_sospechoso = "factura_maliciosa.exe"
print(f"Hash SHA-256 para verificación CTI: {calcular_sha256(archivo_sospechoso)}")
```

### 4.3. Gestión Dinámica de Listas de Control de Acceso (*ACL Management*)
Cuando un sistema IDS o SIEM detecta una IP maliciosa confirmada, un script en Python puede invocar comandos del sistema o interactuar con APIs de cortafuegos (Palo Alto, Fortinet, AWS Security Groups o Linux `iptables`) para revocar el acceso en milisegundos:

```python
import subprocess

def bloquear_ip(ip_ofensora):
    comando = ["sudo", "iptables", "-A", "INPUT", "-s", ip_ofensora, "-j", "DROP"]
    resultado = subprocess.run(comando, capture_output=True, text=True)
    if resultado.returncode == 0:
        print(f"[REMEDIACIÓN EXITOSA] IP {ip_ofensora} bloqueada en la tabla INPUT.")
    else:
        print(f"[ERROR AL BLOQUEAR] {resultado.stderr}")
```

### 4.4. Detección de Intrusiones e Inspección de Red (*Network Inspection*)
Haciendo uso de bibliotecas especializadas como `scapy` o sockets nativos, Python puede interceptar paquetes en la interfaz de red, verificar banderas anómalas (como escaneos NULL o Xmas en TCP) y disparar alarmas en tiempo real:

```python
# Inspección de cabeceras TCP con sockets estándar
import socket

# Crear un socket crudo para escuchar tráfico ICMP o TCP
# (Requiere privilegios de administrador / root)
s = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_ICMP)
print("[*] Sensor activo escuchando paquetes ICMP (pings anómalos)...")
```

### 4.5. Auditoría de Cumplimiento Normativo y Configuración (*Compliance*)
Las normativas (ISO 27001, PCI DSS, CIS Benchmarks) exigen que archivos sensibles del sistema mantengan permisos estrictos. Python puede auditar todo un árbol de directorios de manera periódica:

```python
import os
import stat

archivo_critico = "/etc/shadow"

if os.path.exists(archivo_critico):
    permisos = stat.filemode(os.stat(archivo_critico).st_mode)
    # Verificar que otros usuarios no tengan permisos de lectura/escritura
    if permisos != "-rw-r-----":
        print(f"[HALLAZGO DE CUMPLIMIENTO] Permisos no seguros en {archivo_critico}: {permisos}")
    else:
        print(f"[CONFORME] Permisos correctos en {archivo_critico}.")
```

### 4.6. Escaneo de Red y Descubrimiento de Superficie de Ataque (*Reconnaissance*)
Permite verificar rápidamente si un rango de puertos críticos se encuentra expuesto hacia el exterior sin depender de software de terceros:

```python
import socket

def escanear_puerto(objetivo, puerto):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(1.0) # Espera máxima de 1 segundo
    conexion = s.connect_ex((objetivo, puerto))
    if conexion == 0:
        print(f"[+] Puerto {puerto} ABIERTO en {objetivo}")
    s.close()

# Prueba en servidor local
for puerto_comun in [21, 22, 80, 443, 3389]:
    escanear_puerto("192.168.1.1", puerto_comun)
```

## 6. Puntos Clave para el Analista de Ciberseguridad

* **La Programación como Multiplicador de Fuerza:** Escribir código no es una disciplina reservada a los desarrolladores de software; para el analista de seguridad, es la herramienta que permite procesar miles de alertas en segundos en lugar de horas.
* **El Intérprete y la Portabilidad:** Python compila a Bytecode y se ejecuta mediante la PVM (*Python Virtual Machine*), permitiendo que el mismo script de defensa funcione en servidores dispares sin modificaciones.
* **Estandarización Total en Python 3:** Python 2 está formalmente extinto. Python 3 proporciona separación rigurosa entre texto Unicode y flujos binarios (`bytes`), esencial para la ingeniería inversa y el análisis de protocolos de red.
* **Automatización en el SOC:** Automatizar tareas como parseo de logs, bloqueo de IPs maliciosas y cálculo de hashes optimiza las métricas clave de respuesta ante incidentes (MTTD y MTTR).
