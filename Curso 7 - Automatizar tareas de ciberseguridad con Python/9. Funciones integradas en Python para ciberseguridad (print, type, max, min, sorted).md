# Funciones Integradas en Python para Ciberseguridad: print(), type(), max(), min() y sorted()

En esta novena entrega del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se explora el uso avanzado de las **funciones integradas (*built-in functions*)** esenciales del lenguaje: `print()`, `type()`, `max()`, `min()` y `sorted()`. En el Centro de Operaciones de Seguridad (SOC), los analistas utilizan estas funciones para emitir telemetría legible, validar tipos de datos antes de analizarlos, identificar valores atípicos (*outliers*) en duraciones de sesión de usuario y ordenar listas cronológicas de incidentes respetando la integridad probatoria de la evidencia original.

---

## 1. El Ecosistema de Funciones Integradas (*Built-in Functions*)

Las **funciones integradas** son rutinas que forman parte del núcleo estándar de Python (alojadas en el módulo `builtins`). Están cargadas permanentemente en la memoria del intérprete y pueden ser invocadas directamente sin necesidad de instalar paquetes externos ni utilizar sentencias `import`.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                    RESOLUCIÓN DE FUNCIONES INTEGRADAS EN CPYTHON                          │
└─────────────────────────────────────────────┬─────────────────────────────────────────────┘
                                              │
 ┌──────────────────────────────────────┐     │     ┌──────────────────────────────────────┐
 │          ESPACIO DE NOMBRES          │     │     │           MÓDULO BUILTINS            │
 ├──────────────────────────────────────┤     │     ├──────────────────────────────────────┤
 │ 1. print(...) ───────────────────────┼─────┼───► │ Implementación en C optimizada       │
 │ 2. type(...) ────────────────────────┼─────┼───► │ Retorno instantáneo de tipo          │
 │ 3. max(...) / min(...) ──────────────┼─────┼───► │ Algoritmos de búsqueda de extremos   │
 │ 4. sorted(...) ──────────────────────┼─────┼───► │ Algoritmo Timsort (O(N log N))       │
 └──────────────────────────────────────┘     │     └──────────────────────────────────────┘
```

> [!NOTE]
> **Rendimiento Nativo en C:** Al estar compiladas directamente dentro de CPython, las funciones integradas se ejecutan a velocidad de lenguaje C, lo que resulta fundamental cuando un script del SOC debe procesar cientos de miles de líneas de registros de cortafuegos en segundos.

## 2. Emisión y Formateo de Telemetría con `print()`

La función `print()` envía la representación en texto de uno o más objetos hacia la salida estándar (*stdout*, comúnmente la terminal o la celda del notebook).

### 2.1. Múltiples Argumentos y Separación Automática
`print()` acepta un número arbitrario de argumentos separados por comas. Por defecto, Python inserta un espacio en blanco entre cada uno:

```python
sistema = "SIEM-Chronicle"
alertas_activas = 14
nivel = "CRITICAL"

# Impresión combinada de múltiples tipos (str, int, str)
print("Estado del sistema:", sistema, "| Alertas pendientes:", alertas_activas, "| Severidad:", nivel)
```

```text
Salida:
Estado del sistema: SIEM-Chronicle | Alertas pendientes: 14 | Severidad: CRITICAL
```

### 2.2. Parámetros Avanzados: `sep` y `end`
Para estructurar salidas en formato delimitado (como CSV o logs formateados para ingesta en Splunk):

* **`sep` (*Separator*):** Define la cadena que se inserta entre los argumentos (por defecto es `" "`).
* **`end` (*Ending*):** Define el carácter final que se imprime tras el último argumento (por defecto es el salto de línea `"\n"`).

```python
# Generación de una línea CSV para bitácora forense usando sep=","
print("2026-09-20T18:00:00Z", "192.168.1.105", "SSH", "AUTH_FAIL", sep=",")

# Impresión continua en una sola línea mediante end=""
print("[*] Verificando integridad de archivos...", end=" ")
# (operaciones de cálculo intermedias...)
print("[OK]")
```

```text
Salida:
2026-09-20T18:00:00Z,192.168.1.105,SSH,AUTH_FAIL
[*] Verificando integridad de archivos... [OK]
```

## 3. Inspección y Validación de Tipos con `type()`

La función `type()` devuelve la clase o categoría del tipo de dato al que pertenece el objeto pasado como argumento. Acepta exactamente un argumento.

```python
print(type("security"))  # <class 'str'>
print(type(7))           # <class 'int'>
print(type(45.5))        # <class 'float'>
print(type(True))        # <class 'bool'>
print(type(["10.0.0.1"]))# <class 'list'>
```

### 3.1. Relevancia en Ciberseguridad: Prevención de Excepciones
Los archivos de registro crudos ingresan como cadenas de texto (`str`). Si un analista intenta comparar numéricamente un puerto leído de un log (`"443"`) con un entero (`443`), la condición fallará silenciosamente o generará un error:

```python
puerto_recibido = "443"

# Validación de tipo previa a la toma de decisiones
if type(puerto_recibido) == str:
    puerto_numerico = int(puerto_recibido) # Casting defensivo

if puerto_numerico == 443:
    print("[+] Tráfico HTTPS identificado correctamente.")
```

## 4. Composición de Funciones (*Function Composition*)

La **composición de funciones** consiste en anidar la llamada de una función dentro de otra, pasando la salida (*return*) de la función interna como argumento directo para la externa.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                    EVALUACIÓN DE ADENTRO HACIA AFUERA (INSIDE-OUT)                        │
└─────────────────────────────────────────────┬─────────────────────────────────────────────┘
                                              │
                    print( type( "security" ) )
                           └────────┬───────┘
                                    │ 1. Evalúa type("security")
                                    ▼
                          print( <class 'str'> )
                          └─────────┬──────────┘
                                    │ 2. Ejecuta print() con el resultado
                                    ▼
                          Muestra: <class 'str'>
```

* El intérprete evalúa primero la expresión más interna.
* Dado que `type()` devuelve un objeto de tipo clase pero no lo muestra por sí mismo, componerlo con `print()` es el método estándar para visualizar el tipo de una variable en consola.

## 5. Detección de Extremos y Valores Atípicos: `max()` y `min()`

Las funciones `max()` y `min()` analizan valores numéricos o iterables y devuelven el elemento mayor o menor respectivamente.

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                    MODALIDADES DE ENTRADA PARA MAX() Y MIN()                              │
├──────────────────────────────────────┬────────────────────────────────────────────────────┤
│ Modalidad 1: Múltiples Argumentos    │ `max(12, 45, 7, 88)` ──► Devuelve `88`             │
│ (Valores escalares separados)        │ `min(12, 45, 7, 88)` ──► Devuelve `7`              │
├──────────────────────────────────────┼────────────────────────────────────────────────────┤
│ Modalidad 2: Colección Iterable      │ `tiempos = [15, 3, 45, 120, 8]`                    │
│ (Lista, Tupla o Conjunto)            │ `max(tiempos)` ──► Devuelve `120`                  │
│                                      │ `min(tiempos)` ──► Devuelve `3`                    │
└──────────────────────────────────────┴────────────────────────────────────────────────────┘
```

### 5.1. Caso de Uso en SOC: Análisis de Duración de Sesiones de Usuario
En auditorías de autenticación, las sesiones anómalamente largas o extremadamente cortas son indicadores clave de compromiso:
* **Sesión Máxima Inusual:** Puede indicar una conexión persistente abierta por una herramienta de comando y control (C2) o una sesión desatendida susceptible de secuestro (*session hijacking*).
* **Sesión Mínima Inusual:** Puede revelar un escaneo automatizado o un script de prueba de credenciales (*credential stuffing*) que se desconecta en segundos.

```python
# Duración de las sesiones de un usuario en minutos durante una semana
session_times = [15, 45, 12, 180, 5, 60, 2]

sesion_mas_corta = min(session_times)
sesion_mas_larga = max(session_times)

print("Sesión más corta registrada:", sesion_mas_corta, "minutos")
print("Sesión más larga registrada:", sesion_mas_larga, "minutos")

# Regla de detección de anomalías
if sesion_mas_larga > 120:
    print("[ALERTA SOC] Sesión que supera las 2 horas detectada. Requiere revisión.")
```

```text
Salida:
Sesión más corta registrada: 2 minutos
Sesión más larga registrada: 180 minutos
[ALERTA SOC] Sesión que supera las 2 horas detectada. Requiere revisión.
```

## 6. Organización de Telemetría con `sorted()`

La función `sorted()` toma como entrada cualquier iterable (lista, tupla o cadena) y devuelve una **nueva lista ordenada**.

### 6.1. Principio de No Modificación (Preservación Forense de la Evidencia)
A diferencia del método de lista `.sort()` (que modifica la lista original in-situ y devuelve `None`), la función **`sorted()` no altera el iterable original**.

```python
time_list = [15, 3, 45, 120, 8]

# 1. sorted() genera una nueva lista ordenada
sorted_times = sorted(time_list)

print("Lista ordenada:", sorted_times)   # [3, 8, 15, 45, 120]
print("Lista original:", time_list)     # [15, 3, 45, 120, 8] (INALTERADA)
```

> [!IMPORTANT]
> **Integridad Forense:** En investigaciones de incidentes, preservar el orden cronológico original en el que ocurrieron los eventos en disco es indispensable para la cadena de custodia probatoria. Usar `sorted()` permite analizar los eventos ordenados por gravedad o IP sin destruir el orden temporal de los registros originales.

---

### 6.2. Parámetro `reverse=True` (Orden Descendente)
Por defecto, `sorted()` organiza en orden ascendente (menor a mayor). Para clasificar alertas de mayor a menor severidad o tráfico de mayor a menor volumen:

```python
cvss_scores = [4.5, 9.8, 7.2, 5.0, 10.0]
prioridad_parches = sorted(cvss_scores, reverse=True)

print("Vulnerabilidades priorizadas:", prioridad_parches)
# Salida: [10.0, 9.8, 7.2, 5.0, 4.5]
```

---

### 6.3. Ordenamiento Alfabético y de Cadenas de Texto
Cuando el iterable contiene cadenas de texto, `sorted()` las organiza en base a su orden léxico en la tabla Unicode/ASCII:
* Los caracteres numéricos van antes que las letras: `"10.0.0.1"` precede a `"admin"`.
* Las letras mayúsculas preceden a las minúsculas: `"Admin"` precede a `"admin"`.

```python
analistas = ["sgilmore", "elarson", "bmoreno", "tshah"]
print(sorted(analistas)) # ['bmoreno', 'elarson', 'sgilmore', 'tshah']
```

---

### 6.4. Restricción Crítica: Homogeneidad de Tipos
`sorted()` utiliza internamente el operador de comparación menor que (`<`). En Python 3, **no es posible comparar tipos incompatibles entre sí**:

```python
lista_mixta = [1, 2, "hello"]
# sorted(lista_mixta) 
# Provoca: TypeError: '<' not supported between instances of 'str' and 'int'
```

> [!WARNING]
> Para evitar fallos en scripts de ingestión, asegúrese de que todos los elementos de la lista pertenezcan a la misma clase (`int` con `int`, o convertir todo a `str` con una comprensión de listas) antes de invocar `sorted()`.

## 7. Matriz Comparativa: `sorted()` vs. Método de Lista `.sort()`

| Criterio | Función `sorted(iterable)` | Método de Lista `lista.sort()` |
| :--- | :--- | :--- |
| **Tipo de Invocación** | Función integrada global: `sorted(x)` | Método propio de listas: `x.sort()` |
| **Tipo de Retorno** | Devuelve una **nueva lista ordenada** | Modifica in-situ y devuelve **`None`** |
| **Estado del Original** | **Preserva el objeto original intacto** | **Sobrescribe y destruye el orden original**|
| **Tipos Soportados** | Cualquier iterable (listas, tuplas, strings, sets)| **Únicamente objetos de tipo `list`** |
| **Uso Forense Recomendado**| **Obligatorio** (protege la cadena de custodia) | Desaconsejado si se requiere el orden temporal|

## 8. Casos Prácticos en Operaciones de Ciberseguridad (SOC)

### Caso 1: Triage de Picos Inusuales de Intentos de Autenticación

```python
# Conteo de intentos de autenticación fallidos por hora en un servidor SSH
intentos_por_hora = [3, 1, 0, 4, 125, 2, 8, 1500, 5, 0]

menor_actividad = min(intentos_por_hora)
pico_maximo = max(intentos_por_hora)

print(f"Línea base mínima: {menor_actividad} fallos/hora.")
print(f"Pico anómalo detectado: {pico_maximo} fallos/hora.")

if pico_maximo >= 1000:
    print("[ALERTA CRÍTICA] Posible ataque de fuerza bruta distribuida (DDoS/Brute Force).")
```

---

### Caso 2: Auditoría y Despliegue Ordenado de Direcciones IP Bloqueadas

```python
# Lista desordenada de IPs recolectadas desde alertas del IDS
ips_bloqueadas = ["192.168.1.50", "10.0.0.1", "172.16.0.4", "192.168.1.5"]

# Generación de lista ordenada para reporte ejecutivo sin modificar el registro temporal
ips_ordenadas = sorted(ips_bloqueadas)

print("Registro original de detección:", ips_bloqueadas)
print("Lista normalizada para el cortafuegos:", ips_ordenadas)
```

## 9. Puntos Clave para el Analista de Ciberseguridad

* **`print()` Multiuso:** Permite inspeccionar el flujo de ejecución y dar formato a los eventos mediante los parámetros `sep` y `end`.
* **`type()` como Medida Preventiva:** Se utiliza para validar que los datos extraídos de logs posean el tipo esperado antes de realizar operaciones matemáticas o comparaciones lógicas.
* **Composición de Funciones:** Permite evaluar expresiones de adentro hacia afuera (`print(type(var))`), acelerando la depuración en scripts de respuesta a incidentes.
* **Extremos con `max()` y `min()`:** Herramientas analíticas rápidas para detectar anomalías, picos de tráfico y duraciones atípicas de sesión.
* **`sorted()` e Integridad Forense:** Genera siempre una lista nueva sin mutar el iterable original, salvaguardando la fidelidad de la evidencia y exigiendo homogeneidad estricta de tipos de datos.
