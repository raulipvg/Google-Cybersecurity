# Manipulación de Cadenas y Análisis de Texto en Python para Ciberseguridad

En esta duodécima entrega del **Curso 7: Automatizar tareas de ciberseguridad con Python**, se profundiza en las técnicas de **inspección, extracción y transformación de cadenas de texto (*strings*)**. En el Centro de Operaciones de Seguridad (SOC), la gran mayoría de la telemetría (direcciones IP, URLs, nombres de dominio, hashes criptográficos, nombres de usuario y registros de eventos) se procesa como cadenas. Dominar la **indexación positiva y negativa**, la **notación entre corchetes**, el **rebanado (*slicing*)**, las funciones `str()` y `len()`, y métodos críticos como `.upper()`, `.lower()` y `.index()` es indispensable para analizar IoCs y automatizar la respuesta a incidentes.

---

## 1. El Rol Crítico de las Cadenas en la Telemetría del SOC

Una **cadena (*string*)** es una secuencia ordenada e **inmutable** de caracteres Unicode. En ciberseguridad, se utiliza para representar cualquier información que no requiere operaciones aritméticas directas pero sí parsing, validación y búsqueda de patrones:

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                     DATOS DE CADENA HABITUALES EN OPERACIONES DEL SOC                     │
├────────────────────────────┬──────────────────────────────────────────────────────────────┤
│ Tipo de Dato de Seguridad  │ Ejemplo Real en Registros o Alertas                          │
├────────────────────────────┼──────────────────────────────────────────────────────────────┤
│ **Dirección IPv4 / IPv6**  │ `"192.168.1.105"`, `"2001:0db8:85a3::8a2e:0370:7334"`        │
│ **Localizador URL**        │ `"https://portal-verificacion.xyz/login.php?token=992"`       │
│ **Nombre de Dominio**      │ `"c2-command-node.ru"`, `"auth.corporativo.local"`           │
│ **Hash Criptográfico**     │ `"e4d909c290d0fb1ca068ffaddf22cbd0"` (MD5, 32 caracteres)   │
│ **Identificador de Activo**│ `"h32rb17"` (ID de hardware), `"EMP-99201"` (ID de empleado) │
│ **Línea de Syslog**        │ `"Sep 20 18:00:01 srv-01 sshd[124]: Failed password for root"`│
└────────────────────────────┴──────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **Inmutabilidad de Cadenas:** Toda operación que modifica una cadena (como convertir a mayúsculas o tomar un fragmento) **crea un nuevo objeto en memoria RAM** y deja la cadena original intacta. Esto protege la evidencia forense original contra corrupciones accidentales durante el análisis.

## 2. Indexación y Notación entre Corchetes (*Bracket Notation*)

Cada carácter dentro de una cadena ocupa una posición numérica fija denominada **índice (*index*)**. Python soporta un sistema dual de indexación: **positiva** (de izquierda a derecha comenzando en `0`) y **negativa** (de derecha a izquierda comenzando en `-1`).

### 2.1. Mapa de Índices: Identificador de Dispositivo `"h32rb17"`

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    SISTEMA DUAL DE ÍNDICES EN PYTHON                         │
├───────────────────────┬────┬────┬────┬────┬────┬────┬────────────────────────┤
│ Carácter              │ h  │ 3  │ 2  │ r  │ b  │ 1  │ 7                      │
├───────────────────────┼────┼────┼────┼────┼────┼────┼────────────────────────┤
│ **Índice Positivo**   │ 0  │ 1  │ 2  │ 3  │ 4  │ 5  │ 6                      │
├───────────────────────┼────┼────┼────┼────┼────┼────┼────────────────────────┤
│ **Índice Negativo**   │ -7 │ -6 │ -5 │ -4 │ -3 │ -2 │ -1                     │
└───────────────────────┴────┴────┴────┴────┴────┴────┴────────────────────────┘
```

### 2.2. Extracción de Caracteres Individuales
Se accede al carácter colocando el índice deseado entre corchetes `[ ]` inmediatamente después del literal o de la variable:

```python
device_id = "h32rb17"

# Acceso mediante índice positivo (primer carácter)
primer_caracter = device_id[0]
print("Primer carácter:", primer_caracter) # h

# Acceso mediante índice negativo (último carácter)
ultimo_caracter = device_id[-1]
print("Último carácter:", ultimo_caracter) # 7
```

> [!WARNING]
> **Prevención de `IndexError`:** Si intenta acceder a un índice igual o mayor a la longitud de la cadena (por ejemplo, `device_id[7]`), Python arrojará inmediatamente una excepción fatal `IndexError: string index out of range`. En scripts de producción, valide siempre la longitud con `len()` antes del acceso indexado.

## 3. Rebanado de Cadenas (*String Slicing*)

El **rebanado (*slicing*)** permite extraer una secuencia continua de caracteres (una subcadena) especificando un rango de índices.

### 3.1. Sintaxis Formal: `cadena[inicio:fin]`
* **`inicio` (*start*):** Índice donde comienza la extracción (**inclusivo**).
* **`fin` (*stop*):** Índice donde concluye la extracción (**estrictamente exclusivo**). La extracción se detiene exactamente una posición antes de este índice ($[inicio, fin)$).

```python
# Extracción del prefijo de hardware (los 3 primeros caracteres: índices 0, 1 y 2)
device_id = "h32rb17"
prefijo = device_id[0:3]

print("Prefijo extraído:", prefijo) # "h32"
```

```
MECANISMO DE CORTE:
  Índices:   0   1   2   3   4   5   6
  Cadena:   [h] [3] [2] [r] [b] [1] [7]
  Corte:    └── 0:3 ──┘ (El índice 3 'r' queda EXCLUIDO)
```

### 3.2. Abreviaturas y Casos de Uso Comunes en el SOC
* **Omitir el inicio (`[:fin]`):** Extrae desde el principio hasta `fin - 1`.
  ```python
  url = "https://malicious.xyz"
  protocolo = url[:5] # Extrae "https"
  ```
* **Omitir el final (`[inicio:]`):** Extrae desde `inicio` hasta el último carácter de la cadena.
  ```python
  archivo = "payload_ransomware.exe"
  extension = archivo[-4:] # Extrae ".exe" usando índice negativo
  ```
* **Inversión de Cadena (`[::-1]`):** Utiliza un paso (*step*) de `-1` para invertir la cadena, técnica habitual para decodificar cadenas de malware ofuscadas.

## 4. Funciones Nativas para Cadenas: `str()` y `len()`

### 4.1. Conversión de Tipos con `str()`
Convierte números enteros, flotantes o estructuras en cadenas de texto legibles. Es indispensable para inspeccionar IDs numéricos y concatenar eventos en bitácoras:

```python
employee_id = 19329302
# employee_id[:3]  <- Generaría TypeError: 'int' object is not subscriptable

# Conversión defensiva para habilitar rebanado y búsqueda
string_id = str(employee_id)
departamento = string_id[:2]
print(f"ID: {string_id} | Código de departamento: {departamento}") # 19
```

---

### 4.2. Conteo de Longitud con `len()`
Devuelve la cantidad total de caracteres presentes en la cadena (incluyendo espacios y símbolos).

```python
device_id = "h32rb17"
device_id_length = len(device_id)

if device_id_length == 7:
    print("The device ID has 7 characters.")
```

#### Eficiencia Computacional:
En CPython, los objetos de cadena almacenan su longitud en la cabecera de su estructura de datos en C (`PyASCIIObject`). Por tanto, invocar `len()` **no recorre la cadena**; se ejecuta en tiempo constante **$O(1)$**, lo que garantiza máximo rendimiento al auditar millones de hashes o contraseñas.

## 5. Métodos de Cadena para Normalización y Búsqueda

Un **método** es una función especializada que pertenece a un tipo de datos específico y se invoca mediante la notación de punto (`objeto.metodo()`).

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                    MÉTODOS DE CADENA ESENCIALES PARA EL ANALISTA DEL SOC                  │
├──────────────┬────────────────────────────────────────────────────────────────────────────┤
│ Método       │ Función Operativa en Ciberseguridad                                        │
├──────────────┼────────────────────────────────────────────────────────────────────────────┤
│ `.upper()`   │ Convierte todas las letras a mayúsculas. Normalización de cabeceras HTTP.  │
│ `.lower()`   │ Convierte todas las letras a minúsculas. Crucial para IoCs y dominios DNS. │
│ `.index()`   │ Localiza el índice de la primera aparición de un carácter o subcadena.     │
│ `.find()`    │ Localiza subcadenas devolviendo `-1` si no existen (sin excepciones).      │
└──────────────┴────────────────────────────────────────────────────────────────────────────┘
```

---

### 5.1. Normalización de Mayúsculas y Minúsculas: `.upper()` y `.lower()`
En ciberseguridad, los atacantes alternan mayúsculas y minúsculas para evadir filtros de detección (*cAsE EvAsIoN*). Asimismo, los hashes criptográficos extraídos de distintas fuentes (VirusTotal, AlienVault OTX) pueden venir en mayúsculas o minúsculas:

```python
# Normalización de nombres de departamento y dominios
departamento = "Information Technology"
print(departamento.upper()) # "INFORMATION TECHNOLOGY"
print(departamento.lower()) # "information technology"

# Comparación defensiva de firmas SHA-256
hash_virustotal = "E4D909C290D0FB1CA068FFADDF22CBD0"
hash_calculado  = "e4d909c290d0fb1ca068ffaddf22cbd0"

# Comparación segura normalizando a minúsculas
if hash_virustotal.lower() == hash_calculado.lower():
    print("[ALERTA CRÍTICA] Coincidencia exacta de malware en la base de datos CTI.")
```

---

### 5.2. Localización de Subcadenas con `.index()`

El método `.index()` busca la primera aparición de una subcadena dentro de la cadena principal y **devuelve el índice exacto del primer carácter coincidente**:

```python
device_id = "h32rb17"
posicion_r = device_id.index("r")
print("Índice de 'r':", posicion_r) # 3
```

#### Comportamiento ante Múltiples Coincidencias:
`.index()` siempre devuelve **únicamente la primera ocurrencia**, ignorando las apariciones posteriores:
```python
# Contiene 'r' en el índice 0 y en el índice 3
dispositivo = "r45rt46"
print(dispositivo.index("r")) # 0
```

#### Búsqueda de Subcadenas Completas:
Permite ubicar identificadores dentro de listas o cadenas delimitadas:
```python
registro_usuarios = "tsnow, tshah, bmoreno - updated"
tshah_index = registro_usuarios.index("tshah")
print("Subcadena 'tshah' inicia en índice:", tshah_index) # 7
```

---

### 5.3. El Riesgo de `ValueError` y la Alternativa Defensiva `.find()`

Si la subcadena no existe dentro de la cadena principal, el método `.index()` **provoca una excepción fatal `ValueError: substring not found`**, interrumpiendo el script:

```python
# ❌ FALLO DE EJECUCIÓN SI NO SE MANEJA LA EXCEPCIÓN:
# "h32rb17".index("a")  # Genera ValueError

# ✔️ PATRÓN DEFENSIVO 1: Bloque try / except
try:
    posicion = "h32rb17".index("a")
except ValueError:
    posicion = -1
    print("[-] Carácter no encontrado en el identificador.")

# ✔️ PATRÓN DEFENSIVO 2: Uso del método .find()
# .find() devuelve -1 si no encuentra la subcadena, sin arrojar excepciones
posicion_find = "h32rb17".find("a")
print("Resultado con .find():", posicion_find) # -1
```

> [!CAUTION]
> **Peligro de Colisión con Subcadenas Cortas:**
> Al buscar un nombre como `"tshah"`, no busque únicamente prefijos como `"ts"`. Si ejecuta `"tsnow, tshah".index("ts")`, Python devolverá `0` (el índice de `"tsnow"`), provocando un falso positivo en el triage de cuentas.

## 6. Matriz Comparativa: Métodos y Operaciones de Cadena

| Operación | Sintaxis de Ejemplo | Resultado Devuelto | Comportamiento si Falla / No Existe |
| :--- | :--- | :--- | :--- |
| **Indexación** | `cadena[0]` | Carácter único | Arroja `IndexError` |
| **Rebanado (*Slice*)**| `cadena[0:3]` | Subcadena de longitud 3 | Ajusta silenciosamente a los límites |
| **Longitud** | `len(cadena)` | Entero con total caracteres| N/A (Tiempo constante $O(1)$) |
| **Mayúsculas** | `cadena.upper()` | Nueva cadena en mayúsculas | N/A |
| **Minúsculas** | `cadena.lower()` | Nueva cadena en minúsculas | N/A |
| **Búsqueda Index** | `cadena.index("sub")` | Entero (índice del 1er char)| **Arroja `ValueError`** |
| **Búsqueda Find** | `cadena.find("sub")` | Entero (índice del 1er char)| **Devuelve `-1` sin error** |

## 7. Casos Prácticos en Operaciones de Ciberseguridad (SOC)

### Caso 1: Extracción del Primer Octeto de Red de una Dirección IPv4

```python
def extraer_primer_octeto(direccion_ip):
    """Aísla el primer octeto de una dirección IPv4 utilizando rebanado e índices."""
    try:
        primer_punto = direccion_ip.index(".")
        octeto = direccion_ip[:primer_punto]
        return int(octeto)
    except (ValueError, IndexError):
        return None

ip_ejemplo = "192.168.1.50"
octeto_red = extraer_primer_octeto(ip_ejemplo)

if octeto_red == 192:
    print(f"[CONFORME] La IP {ip_ejemplo} pertenece a la subred corporativa 192.x.x.x")
```

---

### Caso 2: Parser y Normalización de Dominio en URLs Sospechosas

```python
url_alerta = "HTTPS://EVIL-PHISHING-SERVER.XYZ/LOGIN/INDEX.HTML"

# 1. Normalizar toda la URL a minúsculas
url_normalizada = url_alerta.lower()

# 2. Verificar protocolo seguro mediante rebanado
if url_normalizada[:8] == "https://":
    print("[+] Tráfico cifrado HTTPS detectado.")

# 3. Aislar el dominio raíz utilizando .index()
inicio_dominio = 8 # Después de "https://"
fin_dominio = url_normalizada.index("/", inicio_dominio)
dominio_aislado = url_normalizada[inicio_dominio:fin_dominio]

print("Dominio malicioso catalogado para bloqueo DNS:", dominio_aislado)
# Salida: evil-phishing-server.xyz
```

## 8. Puntos Clave para el Analista de Ciberseguridad

* **Secuencia Inmutable:** Las cadenas no pueden modificarse in-situ; todo rebanado o transformación genera un nuevo objeto en memoria, preservando la fidelidad de la evidencia original.
* **Índices Positivos y Negativos:** Los índices positivos inician en `0` (extremo izquierdo); los negativos inician en `-1` (extremo derecho, ideal para aislar extensiones de archivos o sufijos).
* **Semántica del Rebanado:** `[inicio:fin]` incluye el índice de inicio pero excluye estrictamente el de fin ($[inicio, fin)$).
* **Normalización Obligatoria:** Los métodos `.upper()` y `.lower()` eliminan discrepancias tipográficas en hashes criptográficos y nombres de dominio antes de contrastarlos con bases de CTI.
* **Manejo Seguro de `.index()`:** `.index()` solo devuelve la primera aparición y arroja `ValueError` si la subcadena no existe; en scripts desatendidos, capture el error o utilice `.find()`.
