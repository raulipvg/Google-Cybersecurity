# Glosario de Ciberseguridad (Certificado de Google Cybersecurity)

Este glosario contiene términos y definiciones clave traducidos al español para facilitar el aprendizaje y la referencia rápida.

## A

* **Ruta de archivo absoluta (Absolute file path):** La ruta de archivo completa, que comienza desde la raíz.
* **Controles de acceso (Access controls):** Controles de seguridad que gestionan el acceso, la autorización y la rendición de cuentas de la información.
* **Rastreo activo de paquetes o Packet sniffing activo (Active packet sniffing):** Un tipo de ataque donde los paquetes de datos se manipulan en tránsito.
* **Protocolo de resolución de direcciones (ARP - Address Resolution Protocol):** Un protocolo de red utilizado para determinar la dirección MAC del siguiente router o dispositivo en la ruta.
* **Amenaza persistente avanzada (APT - Advanced persistent threat):** Un caso en el que un actor de amenaza mantiene acceso no autorizado a un sistema durante un período prolongado de tiempo.
* **Inteligencia artificial (IA) adversarial (Adversarial artificial intelligence):** Una técnica que manipula la tecnología de inteligencia artificial (IA) y aprendizaje automático (ML) para llevar a cabo ataques de manera más eficiente.
* **Adware (software publicitario):** Un tipo de software legítimo que a veces se utiliza para mostrar anuncios digitales en aplicaciones.
* **Algoritmo (Algorithm):** Un conjunto de reglas utilizadas para resolver un problema.
* **Análisis (Analysis):** La investigación y validación de alertas.
* **Angler phishing (phishing de soporte técnico falso):** Una técnica en la que los atacantes se hacen pasar por representantes de servicio al cliente en las redes sociales.
* **Análisis basado en anomalías (Anomaly-based analysis):** Un método de detección que identifica comportamientos anormales.
* **Software antivirus (Antivirus software):** Un programa de software utilizado para prevenir, detectar y eliminar malware y virus.
* **Aplicación (Application):** Un programa que realiza una tarea específica.
* **Token de interfaz de programación de aplicaciones o Token de API (Application programming interface token):** Un pequeño bloque de código cifrado que contiene información sobre un usuario.
* **Argumento en Linux (Argument):** Información específica que necesita un comando.
* **Argumento en Python (Argument):** Los datos que se pasan a una función cuando se la llama.
* **Array (arreglo/vector):** Un tipo de datos que almacena datos en una lista ordenada separada por comas.
* **Inteligencia artificial o IA (Artificial intelligence):** Programas informáticos que pueden completar tareas cognitivas típicamente asociadas con la inteligencia humana.
* **Herramienta de IA (AI tool):** Software impulsado por IA que puede automatizar o asistir a los usuarios en una variedad de tareas.
* **Usuario de IA (AI user):** Alguien que aprovecha la IA para completar una tarea personal o profesional.
* **Evaluar (Assess):** El quinto paso del RMF (Marco de Gestión de Riesgos) del NIST que significa determinar si los controles establecidos están implementados correctamente.
* **Activo (Asset):** Un elemento que se percibe con valor para una organización.
* **Clasificación de activos (Asset classification):** La práctica de etiquetar activos en función de la sensibilidad y la importancia para una organización.
* **Inventario de activos (Asset inventory):** Un catálogo de activos que deben protegerse.
* **Gestión de activos (Asset management):** El proceso de seguimiento de los activos y los riesgos que los afectan.
* **Cifrado asimétrico (Asymmetric encryption):** El uso de un par de claves pública y privada para el cifrado y descifrado de datos.
* **Superficie de ataque (Attack surface):** Todas las vulnerabilidades potenciales que un actor de amenaza podría explotar.
* **Árbol de ataque (Attack tree):** Un diagrama que mapea las amenazas a los activos.
* **Vectores de ataque (Attack vectors):** Las vías que utilizan los atacantes para penetrar las defensas de seguridad.
* **Autenticación (Authentication):** El proceso de verificar quién es alguien.
* **Autorización (Authorization):** El concepto de otorgar acceso a recursos específicos en un sistema.
* **Autorizar (Authorize):** El sexto paso del RMF del NIST que se refiere a ser responsable de los riesgos de seguridad y privacidad que puedan existir en una organización.
* **Automatización (Automation):** El uso de la tecnología para reducir el esfuerzo humano y manual al realizar tareas comunes y repetitivas.
* **Disponibilidad (Availability):** La idea de que los datos son accesibles para aquellos que están autorizados a acceder a ellos.

## B

* **Baiting (señuelo):** Una táctica de ingeniería social que tienta a las personas a comprometer su seguridad.
* **Ancho de banda (Bandwidth):** La capacidad máxima de transmisión de datos a través de una red, medida en bits por segundo.
* **Configuración de referencia o imagen base (Baseline configuration / baseline image):** Un conjunto documentado de especificaciones dentro de un sistema que se utiliza como base para futuras compilaciones, lanzamientos y actualizaciones.
* **Bash:** La shell (intérprete de comandos) predeterminada en la mayoría de las distribuciones de Linux.
* **Autenticación básica (Basic auth):** La tecnología utilizada para establecer la solicitud de un usuario de acceder a un servidor.
* **Sistema básico de entrada/salida (BIOS - Basic Input/Output System):** Un microchip que contiene instrucciones de carga para la computadora y que prevalece en los sistemas más antiguos.
* **Entrevista conductual (Behavioral interview):** Un tipo de entrevista diseñada para comprender cómo respondiste en situaciones pasadas para predecir tu desempeño futuro.
* **Biometría (Biometrics):** Las características físicas únicas que se pueden utilizar para verificar la identidad de una persona.
* **Bit:** La unidad de medida de datos más pequeña en una computadora.
* **Datos booleanos (Boolean data):** Datos que solo pueden tener uno de dos valores: Verdadero (True) o Falso (False).
* **Cargador de arranque (Bootloader):** Un programa de software que arranca el sistema operativo.
* **Botnet:** Una colección de computadoras infectadas por malware que están bajo el control de un único actor de amenaza, conocido como el "bot-herder" (pastor de bots).
* **Notación de corchetes (Bracket notation):** Los índices colocados entre corchetes.
* **Cadena de custodia rota (Broken chain of custody):** Inconsistencias en la recopilación y el registro de pruebas en la cadena de custodia.
* **Ataque de fuerza bruta (Brute force attack):** El proceso de prueba y error para descubrir información privada.
* **Bug bounty (recompensas por errores):** Programas que alientan a los hackers independientes a encontrar e informar vulnerabilidades.
* **Función integrada o nativa (Built-in function):** Una función que existe dentro de Python y se puede llamar directamente.
* **Continuidad del negocio (Business continuity):** La capacidad de una organización para mantener su productividad diaria mediante el establecimiento de planes de recuperación ante desastres de riesgo.
* **Plan de continuidad del negocio (BCP - Business continuity plan):** Un documento que detalla los procedimientos para mantener las operaciones del negocio durante y después de una interrupción significativa.
* **Compromiso de correo electrónico comercial (BEC - Business Email Compromise):** Un tipo de ataque de phishing en el que un actor de amenaza se hace pasar por una fuente conocida para obtener una ventaja financiera.

## C

* **Career Dreamer:** Una herramienta experimental que utiliza IA para hacer que la exploración de carreras sea más fácil y personalizada.
* **Declaración de identidad profesional (Career identity statement):** Unas pocas oraciones sobre ti mismo que proporcionan una visión rápida pero perspicaz de tus habilidades clave, intereses, metas profesionales y aquello que te apasiona.
* **Entrevista de caso (Case interview):** Un tipo de entrevista diseñada para evaluar tus habilidades de resolución de problemas, análisis y comunicación al presentarte desafíos comerciales del mundo real para analizar y resolver.
* **Categorizar (Categorize):** El segundo paso del RMF del NIST que se utiliza para desarrollar procesos y tareas de gestión de riesgos.
* **CentOS:** Una distribución de código abierto de Linux que está estrechamente relacionada con Red Hat.
* **Unidad Central de Procesamiento (CPU - Central Processing Unit):** El procesador principal de una computadora, que se utiliza para realizar tareas informáticas generales en una computadora.
* **Cadena de custodia (Chain of custody):** El proceso de documentar la posesión y el control de las pruebas durante el ciclo de vida de un incidente.
* **Chat:** Un cuadro de entrada en una herramienta de IA donde puedes agregar prompts (indicaciones).
* **Chronicle (Google SecOps):** Una herramienta nativa de la nube diseñada para retener, analizar y buscar datos.
* **Cifrador/Cifra (Cipher):** Un algoritmo que cifra información.
* **Cortafuegos basados en la nube (Cloud-based firewalls):** Cortafuegos de software que están alojados por el proveedor de servicios en la nube.
* **Computación en la nube (Cloud computing):** La práctica de utilizar servidores remotos, aplicaciones y servicios de red alojados en internet en lugar de en dispositivos físicos locales.
* **Red en la nube (Cloud network):** Una colección de servidores o computadoras que almacenan recursos y datos en centros de datos remotos a los que se puede acceder a través de internet.
* **Seguridad en la nube (Cloud security):** El proceso de garantizar que los activos almacenados en la nube estén configurados correctamente y que el acceso a esos activos esté limitado a usuarios autorizados.
* **Comando (Command):** Una instrucción que le dice a la computadora que haga algo.
* **Comando y control (C2 - Command and control):** Las técnicas utilizadas por actores maliciosos para mantener comunicaciones con sistemas comprometidos.
* **Interfaz de línea de comandos (CLI - Command-line interface):** Una interfaz de usuario basada en texto que utiliza comandos para interactuar con la computadora.
* **Comentario (Comment):** Una nota que hacen los programadores sobre la intención detrás de su código.
* **Formato de Evento Común (CEF - Common Event Format):** Un formato de registro (log) que utiliza pares clave-valor para estructurar datos e identificar campos y sus valores correspondientes.
* **Lista de Vulnerabilidades y Exposiciones Comunes (CVE® - Common Vulnerabilities and Exposures list):** Un diccionario de acceso público de vulnerabilidades y exposiciones conocidas.
* **Sistema de Puntuación de Vulnerabilidad Común (CVSS - Common Vulnerability Scoring System):** Un sistema de medición que califica la gravedad de una vulnerabilidad.
* **Cumplimiento (Compliance):** El proceso de adherirse a estándares internos y regulaciones externas.
* **Equipos de respuesta a incidentes de seguridad informática (CSIRT - Computer security incident response teams):** Un grupo especializado de profesionales de la seguridad que están capacitados en la gestión y respuesta a incidentes.
* **Virus informático (Computer virus):** Código malicioso escrito para interferir con las operaciones de la computadora y causar daños a los datos y al software.
* **Sentencia condicional (Conditional statement):** Una instrucción que evalúa el código para determinar si cumple con un conjunto específico de condiciones.
* **Datos confidenciales (Confidential data):** Datos que a menudo tienen límites en la cantidad de personas que tienen acceso a ellos.
* **Confidencialidad (Confidentiality):** La idea de que solo los usuarios autorizados pueden acceder a activos o datos específicos.
* **Tríada de confidencialidad, integridad y disponibilidad (CIA - Confidentiality, integrity, availability triad):** Un modelo que ayuda a informar cómo las organizaciones consideran el riesgo al configurar sistemas y políticas de seguridad.
* **Archivo de configuración (Configuration file):** Un archivo utilizado para configurar los ajustes de una aplicación.
* **Contención (Containment):** El acto de limitar y prevenir daños adicionales causados por un incidente.
* **Zona controlada (Controlled zone):** Una subred que protege la red interna de la zona no controlada.
* **Carta de presentación (Cover letter):** Un documento personalizado que muestra tus habilidades de comunicación y personalidad mientras demuestra cómo tus habilidades y experiencia se relacionan con las necesidades del empleador.
* **Cross-site scripting (XSS):** Un ataque de inyección que inserta código en un sitio web o aplicación web vulnerable.
* **Crowdsourcing:** La práctica de recopilar información utilizando la participación del público y la colaboración.
* **Ataque criptográfico (Cryptographic attack):** Un ataque que afecta las formas seguras de comunicación entre un remitente y el destinatario previsto.
* **Clave criptográfica (Cryptographic key):** Un mecanismo que descifra el texto cifrado.
* **Criptografía (Cryptography):** El proceso de transformar la información en una forma que los lectores no autorizados no puedan entender.
* **Criptojacking (Cryptojacking):** Una forma de malware que instala software para minar criptomonedas ilegalmente.
* **Autoridad de Numeración de CVE (CNA - CVE Numbering Authority):** Una organización que se ofrece voluntariamente a analizar y distribuir información sobre CVE elegibles.
* **Ciberseguridad o seguridad (Cybersecurity / security):** La práctica de garantizar la confidencialidad, integridad y disponibilidad de la información mediante la protección de redes, dispositivos, personas y datos contra el acceso no autorizado o la explotación delictiva.

## D

* **Datos (Data):** Información que es traducida, procesada o almacenada por una computadora.
* **Datos en reposo (Data at rest):** Datos que no se están accediendo actualmente.
* **Responsable del tratamiento de datos (Data controller):** Una persona que determina el procedimiento y el propósito del procesamiento de datos.
* **Custodio de datos (Data custodian):** Cualquier persona o cosa responsable de la manipulación, transporte y almacenamiento seguros de la información.
* **Exfiltración de datos (Data exfiltration):** Transmisión no autorizada de datos desde un sistema.
* **Datos en tránsito (Data in transit):** Datos que viajan de un punto a otro.
* **Datos en uso (Data in use):** Datos que están siendo accedidos por uno o más usuarios.
* **Propietario de datos (Data owner):** La persona que decide quién puede acceder, editar, usar o destruir su información.
* **Paquete de datos (Data packet):** Una unidad básica de información que viaja de un dispositivo a otro dentro de una red.
* **Punto de datos (Data point):** Una pieza específica de información.
* **Encargado del tratamiento de datos (Data processor):** Una persona que es responsable de procesar datos en nombre del responsable del tratamiento.
* **Delegado de protección de datos (DPO - Data protection officer):** Un individuo que es responsable de supervisar el cumplimiento de los procedimientos de protección de datos de una organización.
* **Tipo de datos (Data type):** Una categoría para un tipo particular de elemento de datos.
* **Base de datos (Database):** Una colección organizada de información o datos.
* **Datos de fecha y hora (Date and time data):** Datos que representan una fecha y/o una hora.
* **Depurador (Debugger):** Una herramienta de software que ayuda a localizar la fuente de un error y evaluar sus causas.
* **Depuración (Debugging):** La práctica de identificar y corregir errores en el código.
* **Defensa en profundidad (Defense in depth):** Un enfoque por capas para la gestión de vulnerabilidades que reduce el riesgo.
* **Ataque de denegación de servicio (DoS - Denial of service attack):** Un ataque que se dirige a una red o servidor y lo inunda con tráfico de red.
* **Detectar (Detect):** Una función central del NIST relacionada con la identificación de posibles incidentes de seguridad y la mejora de las capacidades de monitoreo para aumentar la velocidad y la eficiencia de las detecciones.
* **Detección (Detection):** El descubrimiento oportuno de eventos de seguridad.
* **Datos de diccionario (Dictionary data):** Datos que constan de uno o más pares clave-valor.
* **Certificado digital (Digital certificate):** Un archivo que verifica la identidad del titular de una clave pública.
* **Análisis forense digital (Digital forensics):** La práctica de recopilar y analizar datos para determinar qué ha sucedido después de un ataque.
* **Directorio (Directory):** Un archivo que organiza dónde se almacenan otros archivos.
* **Plan de recuperación ante desastres (Disaster recovery plan):** Un plan que permite al equipo de seguridad de una organización detallar los pasos necesarios para minimizar el impacto de un incidente de seguridad.
* **Ataque de denegación de servicio distribuido (DDoS - Distributed denial of service attack):** Un tipo de ataque de denegación de servicio que utiliza múltiples dispositivos o servidores ubicados en diferentes ubicaciones para inundar la red de destino con tráfico no deseado.
* **Distribuciones (Distributions):** Las diferentes versiones de Linux.
* **Documentación (Documentation):** Cualquier forma de contenido registrado que se utiliza para un propósito específico.
* **Ataque XSS basado en DOM (DOM-based XSS attack):** Un caso en el que existe una secuencia de comandos maliciosa en la página web que carga un navegador.
* **Sistema de Nombres de Dominio (DNS - Domain Name System):** Un protocolo de red que traduce los nombres de dominio de Internet en direcciones IP.
* **Dropper (instalador):** Un tipo de malware que viene empaquetado con código malicioso que se entrega e instala en un sistema de destino.

## E

* **Discurso de ascensor (Elevator pitch):** Un breve resumen de tu experiencia, habilidades y antecedentes.
* **Encapsulamiento (Encapsulation):** Un proceso realizado por un servicio VPN que protege sus datos al envolver datos confidenciales en otros paquetes de datos.
* **Cifrado (Encryption):** El proceso de convertir datos de un formato legible a un formato codificado.
* **Dispositivo final (Endpoint):** Cualquier dispositivo conectado a una red.
* **Detección y respuesta de endpoints (EDR - Endpoint detection and response):** Una aplicación que monitorea un dispositivo final en busca de actividad maliciosa.
* **Erradicación (Eradication):** La eliminación completa de los elementos del incidente de todos los sistemas afectados.
* **Política de escalada (Escalation policy):** Un conjunto de acciones que detallan quién debe ser notificado cuando ocurre una alerta de incidente y cómo debe manejarse ese incidente.
* **Evento (Event):** Una ocurrencia observable en una red, sistema o dispositivo.
* **Excepción (Exception):** Un error que involucra código que no se puede ejecutar a pesar de ser sintácticamente correcto.
* **Operador exclusivo (Exclusive operator):** Un operador que no incluye el valor de comparación.
* **Exploit (explotar/aprovechar):** Una forma de aprovechar una vulnerabilidad.
* **Exposición (Exposure):** Un error que puede ser explotado por una amenaza.
* **Amenaza externa (External threat):** Cualquier cosa fuera de la organización que tenga el potencial de dañar los activos de la organización.

## F

* **Falso negativo (False negative):** Un estado donde no se detecta la presencia de una amenaza.
* **Falso positivo (False positive):** Una alerta que detecta incorrectamente la presencia de una amenaza.
* **Malware sin archivos (Fileless malware):** Malware que no necesita ser instalado por el usuario porque utiliza programas legítimos que ya están instalados para infectar una computadora.
* **Ruta de archivo (File path):** La ubicación de un archivo o directorio.
* **Estánadar de Jerarquía del Sistema de Archivos (FHS - Filesystem Hierarchy Standard):** El componente del sistema operativo Linux que organiza los datos.
* **Filtrado (Filtering):** Seleccionar datos que coinciden con una determinada condición.
* **Informe final (Final report):** Documentación que proporciona una revisión exhaustiva de un incidente.
* **Cortafuegos (Firewall):** Un dispositivo de seguridad de red que monitorea el tráfico hacia o desde una red.
* **Datos de punto flotante (Float data):** Datos que consisten en un número con un punto decimal.
* **Clave foránea (Foreign key):** Una columna en una tabla que es una clave primaria en otra tabla.
* **Servidor proxy directo (Forward proxy server):** Un servidor que regula y restringe el acceso de una persona a Internet.
* **Función (Function):** Una sección de código que se puede reutilizar en un programa.

## G

* **Gemini:** Un modelo de IA generativa que puede comprender y combinar varios tipos de información, incluidos textos, código, audio, imágenes y videos.
* **Gemini Deep Research (Investigación Profunda de Gemini):** Una función dentro de las aplicaciones de Gemini que permite a los usuarios realizar investigaciones en profundidad navegando por numerosos sitios web, analizando la información y generando informes de varias páginas.
* **Gemini Live:** Una función en la aplicación Gemini que permite conversaciones de voz naturales y en tiempo real.
* **IA Generativa (Generative AI):** Inteligencia artificial que puede generar contenido nuevo, como texto, imágenes u otros medios.
* **Variable global (Global variable):** Una variable que está disponible en todo el programa.
* **Interfaz gráfica de usuario (GUI - Graphical user interface):** Una interfaz de usuario que utiliza iconos en la pantalla para gestionar diferentes tareas en la computadora.
* **Mente de crecimiento (Growth mindset):** Un compromiso con el aprendizaje y desarrollo continuo.

## H

* **Hacker:** Cualquier persona que utiliza computadoras para obtener acceso a sistemas informáticos, redes o datos.
* **Hacktivista (Hacktivist):** Una persona que utiliza el hacking para lograr un objetivo político.
* **Disco duro (Hard drive):** Un componente de hardware utilizado para la memoria a largo plazo.
* **Hardware:** Los componentes físicos de una computadora.
* **Colisión de hash (Hash collision):** Un caso en el que diferentes entradas producen el mismo valor hash.
* **Función hash (Hash function):** Un algoritmo que produce un código que no se puede descifrar.
* **Tabla hash (Hash table):** Una estructura de datos que se utiliza para almacenar y hacer referencia a valores hash.
* **Ley de Portabilidad y Responsabilidad de Seguros de Salud (HIPAA - Health Insurance Portability and Accountability Act):** Una ley federal de EE. UU. establecida para proteger la información de salud de los pacientes.
* **Honeypot (tarro de miel):** Un sistema o recurso creado como un señuelo vulnerable a los ataques con el propósito de atraer a posibles intrusos.
* **Sistema de detección de intrusiones basado en host (HIDS - Host-based intrusion detection system):** Una aplicación que monitorea la actividad del host en el que está instalada.
* **Hub (concentrador):** Un dispositivo de red que transmite información a todos los dispositivos de la red.
* **Toque humano (Human touch):** El acto de personalizar o refinar la salida de la IA para garantizar que la personalidad, el tono, la voz, el uso del lenguaje y la precisión sean lo más auténticos posible.
* **Protocolo de Transferencia de Hipertexto (HTTP - Hypertext Transfer Protocol):** Un protocolo de capa de aplicación que proporciona un método de comunicación entre clientes y servidores de sitios web.
* **Protocolo Seguro de Transferencia de Hipertexto (HTTPS - Hypertext Transfer Protocol Secure):** Un protocolo de red que proporciona un método seguro de comunicación entre clientes y servidores de sitios web.

## I

* **Identificar (Identify):** Una función central del NIST relacionada con la gestión del riesgo de ciberseguridad y su efecto en las personas y los activos de una organización.
* **Gestión de identidad y acceso (IAM - Identity and access management):** Una colección de procesos y tecnologías que ayuda a las organizaciones a gestionar las identidades digitales en su entorno.
* **IEEE 802.11 (Wi-Fi):** Un conjunto de estándares que definen la comunicación para redes de área local inalámbricas (WLAN).
* **Inmutable (Immutable):** Un objeto que no se puede cambiar después de haber sido creado y de haberle asignado un valor.
* **Implementar (Implement):** El cuarto paso del RMF del NIST que significa implementar planes de seguridad y privacidad para una organización.
* **Uso inapropiado (Improper usage):** Un tipo de incidente que ocurre cuando un empleado de una organización viola las políticas de uso aceptable de la misma.
* **Incidente (Incident):** Una ocurrencia que pone en peligro de manera real o inminente, sin autorización legal, la confidencialidad, integridad o disponibilidad de la información o de un sistema de información; o que constituye una violación o amenaza inminente de violación de la ley, las políticas de seguridad, los procedimientos de seguridad o las políticas de uso aceptable.
* **Escalación de incidentes (Incident escalation):** El proceso de identificar un posible incidente de seguridad, clasificarlo y entregarlo a un miembro del equipo con más experiencia.
* **Diario del controlador de incidentes (Incident handler’s journal):** Una forma de documentación utilizada en la respuesta a incidentes.
* **Respuesta a incidentes (Incident response):** El intento rápido de una organización para identificar un ataque, contener el daño y corregir los efectos de una brecha de seguridad.
* **Plan de respuesta a incidentes (Incident response plan):** Un documento que detalla los procedimientos a seguir en cada paso de la respuesta a un incidente.
* **Operador inclusivo (Inclusive operator):** Un operador que incluye el valor de comparación.
* **Sangría (Indentation):** Espacio agregado al comienzo de una línea de código.
* **Índice (Index):** Un número asignado a cada elemento en una secuencia que indica su posición.
* **Indicadores de ataque (IoA - Indicators of attack):** La serie de eventos observados que indican un incidente en tiempo real.

* **Centro de operaciones de seguridad o SOC (Security operations center):** Una unidad organizativa dedicada a monitorear redes, sistemas y dispositivos en busca de amenazas o ataques de seguridad.
* **Orquestación, automatización y respuesta de seguridad o SOAR (Security orchestration, automation, and response):** Una colección de aplicaciones, herramientas y flujos de trabajo que utilizan la automatización para responder a eventos de seguridad.
* **Postura de seguridad (Security posture):** La capacidad de una organización para gestionar la defensa de sus activos y datos críticos y reaccionar al cambio.
* **Zona de seguridad (Security zone):** Un segmento de la red de una empresa que protege la red interna de Internet.
* **Seleccionar (Select):** El tercer paso del RMF del NIST que significa elegir, personalizar y registrar la documentación de los controles que protegen a una organización.
* **Datos sensibles (Sensitive data):** Un tipo de datos que incluye información de identificación personal (PII), información de identificación personal sensible (SPII) o información de salud protegida (PHI).
* **Información de identificación personal sensible (SPII - Sensitive personally identifiable information):** Un tipo específico de PII que cae bajo pautas de manejo más estrictas.
* **Separación de funciones o deberes (Separation of duties):** El principio de que a los usuarios no se les deben otorgar niveles de autorización que les permitan hacer un uso indebido de un sistema.
* **Sesión (Session):** Una secuencia de solicitudes y respuestas HTTP de red asociadas con el mismo usuario.
* **Cookie de sesión (Session cookie):** Un token que los sitios web utilizan para validar una sesión y determinar cuánto tiempo debe durar esa sesión.
* **Secuestro de sesión (Session hijacking):** Un evento en el que los atacantes obtienen el ID de sesión de un usuario legítimo.
* **ID de sesión (Session ID):** Un token único que identifica a un usuario y su dispositivo mientras accede a un sistema.
* **Datos de conjunto (Set data):** Datos que consisten en una colección desordenada de valores únicos.
* **Responsabilidad compartida (Shared responsibility):** La idea de que todas las personas dentro de una organización asumen un papel activo en la reducción de riesgos y el mantenimiento de la seguridad tanto física como virtual.
* **Shell:** El intérprete de línea de comandos.
* **Firma (Signature):** Un patrón que está asociado con una actividad maliciosa.
* **Análisis de firmas (Signature analysis):** Un método de detección utilizado para encontrar eventos de interés.
* **Protocolo Simple de Administración de Red o SNMP (Simple Network Management Protocol):** Un protocolo de red utilizado para monitorear y administrar dispositivos en una red.
* **Inicio de sesión único o SSO (Single sign-on):** Una tecnología que combina varios inicios de sesión diferentes en uno solo.
* **Smishing:** El uso de mensajes de texto (SMS) para engañar a los usuarios para que proporcionen información confidencial o para hacerse pasar por una fuente conocida.
* **Ataque Smurf (Smurf attack):** Un ataque de red realizado cuando un atacante rastrea (sniffa) la dirección IP de un usuario autorizado y la inunda con paquetes ICMP.
* **Ingeniería social (Social engineering):** Una técnica de manipulación que explota el error humano para obtener información privada, acceso u objetos de valor.
* **Phishing en redes sociales (Social media phishing):** Un tipo de ataque en el que un actor de amenaza recopila información detallada sobre su objetivo en los sitios de redes sociales antes de iniciar el ataque.
* **Spear phishing (phishing dirigido):** Un ataque de correo electrónico malicioso dirigido a un usuario o grupo de usuarios específico, que parece provenir de una fuente de confianza.
* **Velocidad (Speed):** La velocidad a la que un dispositivo envía y recibe datos, medida en bits por segundo.
* **Splunk Cloud:** Una herramienta alojada en la nube utilizada para recopilar, buscar y monitorear datos de registro.
* **Splunk Enterprise:** Una herramienta de alojamiento propio que se utiliza para retener, analizar y buscar datos de registro de una organización para proporcionar información de seguridad y alertas en tiempo real.
* **Spyware (software espía):** Malware que se utiliza para recopilar y vender información sin consentimiento.
* **SQL (Lenguaje de Consulta Estructurado / Structured Query Language):** Un lenguaje de programación utilizado para crear, interactuar y solicitar información de una base de datos.
* **Inyección SQL (SQL injection):** Un ataque que ejecuta consultas inesperadas en una base de datos.
* **Parte interesada (Stakeholder):** Un individuo o grupo que tiene interés en cualquier decisión o actividad de una organización.
* **Error estándar o stderr (Standard error):** Un mensaje de error devuelto por el sistema operativo a través de la shell.
* **Entrada estándar o stdin (Standard input):** Información recibida por el sistema operativo a través de la línea de comandos.
* **Salida estándar o stdout (Standard output):** Información devuelta por el sistema operativo a través de la shell.
* **Estándares (Standards):** Referencias que informan cómo establecer políticas.
* **Método STAR (STAR method):** Un marco narrativo que te ayuda a comunicar tus experiencias y habilidades de una manera clara, concisa y convincente para ayudar a un entrevistador a comprender exactamente cómo manejaste con éxito ciertas situaciones; significa Situación, Tarea, Acción y Resultado.
* **Con estado (Stateful):** Una clase de cortafuegos que realiza un seguimiento de la información que pasa a través de él y filtra de manera proactiva las amenazas.
* **Sin estado (Stateless):** Una clase de cortafuegos que opera en función de reglas predefinidas y que no realiza un seguimiento de la información de los paquetes de datos.
* **Ataque XSS almacenado (Stored XSS attack):** Un caso en el que una secuencia de comandos maliciosa se inyecta directamente en el servidor.
* **Concatenación de cadenas (String concatenation):** El proceso de unir dos cadenas de texto.
* **Datos de cadena o String (String data):** Datos que consisten en una secuencia ordenada de caracteres.
* **Guía de estilo (Style guide):** Un manual que informa la escritura, el formato y el diseño de los documentos.
* **Subredes o Subnetting (Subnetting):** La subdivisión de una red en grupos lógicos llamados subredes.
* **Subcadena (Substring):** Una secuencia continua de caracteres dentro de una cadena de texto.
* **Sudo:** Un comando que otorga temporalmente privilegios elevados a usuarios específicos.
* **Ataque a la cadena de suministro (Supply-chain attack):** Un ataque que se dirige a sistemas, aplicaciones, hardware y/o software para localizar una vulnerabilidad donde se pueda implementar malware.
* **Suricata:** Un sistema de detección de intrusiones, sistema de prevención de intrusiones y herramienta de análisis de red de código abierto.
* **Switch (conmutador):** Un dispositivo que realiza conexiones entre dispositivos específicos en una red enviando y recibiendo datos entre ellos.
* **Cifrado simétrico (Symmetric encryption):** El uso de una única clave secreta para intercambiar información.
* **Ataque de inundación SYN o SYN flood (Synchronize flood attack):** Un tipo de ataque DoS que simula una conexión TCP/IP e inunda un servidor con paquetes SYN.
* **Sintaxis (Syntax):** Las reglas que determinan lo que está correctamente estructurado en un lenguaje de programación.
* **Error de sintaxis (Syntax error):** Un error que implica un uso no válido de un lenguaje de programación.

## T

* **Tailgating:** Una táctica de ingeniería social en la que personas no autorizadas siguen a una persona autorizada a un área restringida.
* **Modelo TCP/IP (TCP/IP model):** Un marco de referencia utilizado para visualizar cómo se organizan y transmiten los datos a través de una red.
* **tcpdump:** Un analizador de protocolos de red de línea de comandos.
* **Entrevista técnica (Technical interview):** Un tipo de entrevista diseñada para evaluar tu competencia técnica; común en campos como la ingeniería informática, la informática y las TI.
* **Habilidades técnicas (Technical skills):** Habilidades que requieren conocimiento de herramientas, procedimientos y políticas específicas.
* **Telemetría (Telemetry):** La recopilación y transmisión de datos para su análisis.
* **Amenaza (Threat):** Cualquier circunstancia o evento que pueda afectar negativamente a los activos.
* **Actor de amenaza (Threat actor):** Cualquier persona o grupo que represente un riesgo de seguridad.
* **Búsqueda de amenazas o Threat hunting (Threat hunting):** La búsqueda proactiva de amenazas en una red.
* **Inteligencia de amenazas (Threat intelligence):** Información sobre amenazas basada en evidencia que proporciona contexto sobre amenazas existentes o emergentes.
* **Modelado de amenazas (Threat modeling):** El proceso de identificar activos, sus vulnerabilidades y cómo cada uno está expuesto a las amenazas.
* **Habilidades transferibles (Transferable skills):** Habilidades que has aprendido en una situación y que se pueden aplicar a una situación completamente diferente, como un nuevo empleo.
* **Protocolo de Control de Transmisión o TCP (Transmission Control Protocol):** Un protocolo de comunicación de Internet que permite a dos dispositivos formar una conexión y transmitir datos.
* **Triaje o Triage (Triage):** La priorización de incidentes según su nivel de importancia o urgencia.
* **Caballo de Troya o Troyano (Trojan horse):** Malware que parece un archivo o programa legítimo.
* **Verdadero negativo (True negative):** Un estado donde no hay detección de actividad maliciosa.
* **Verdadero positivo (True positive):** Una alerta que detecta correctamente la presencia de un ataque.
* **Datos de tupla o Tuple (Tuple data):** Estructura de datos que consiste en una colección de datos que no se puede cambiar.
* **Error de tipo (Type error):** Un error que resulta de usar un tipo de datos incorrecto.

---

## U

* **Ubuntu:** Una distribución de código abierto y fácil de usar que se utiliza ampliamente en la seguridad y otras industrias.
* **Acceso no autorizado (Unauthorized access):** Un tipo de incidente que ocurre cuando un individuo obtiene acceso digital o físico a un sistema o aplicación sin permiso.
* **Zona no controlada (Uncontrolled zone):** Cualquier red fuera del control de su organización.
* **Interfaz de Firmware Extensible Unificada (UEFI - Unified Extensible Firmware Interface):** Un microchip que contiene instrucciones de carga para la computadora y reemplaza a BIOS en los sistemas más modernos.
* **Baiting por USB o USB baiting (USB baiting):** Un ataque en el que un actor de amenaza deja estratégicamente una memoria USB con malware para que un empleado la encuentre e instale, infectando sin saberlo una red.
* **Usuario (User):** La persona que interactúa con una computadora.
* **Protocolo de Datagramas de Usuario o UDP (User Datagram Protocol):** Un protocolo sin conexión que no establece una conexión entre dispositivos antes de las transmisiones.
* **Función definida por el usuario (User-defined function):** Una función que los programadores diseñan para sus necesidades específicas.
* **Interfaz de usuario (User interface):** Un programa que permite al usuario controlar las funciones del sistema operativo.
* **Aprovisionamiento de usuarios (User provisioning):** El proceso de crear y mantener la identidad digital de un usuario.

---

## V

* **Variable:** Un contenedor que almacena datos.
* **Máquina virtual o VM (Virtual machine):** Una versión virtual de una computadora física.
* **Red Privada Virtual o VPN (Virtual Private Network):** Un servicio de seguridad de red que cambia su dirección IP pública y oculta su ubicación virtual para que pueda mantener sus datos privados cuando utiliza una red pública como Internet.
* **Virus:** Código malicioso escrito para interferir con las operaciones de la computadora y causar daños a los datos y al software.
* **VirusTotal:** Un servicio que permite a cualquiera analizar archivos, dominios, URL y direcciones IP sospechosos en busca de contenido malicioso.
* **Vishing:** La explotación de la comunicación de voz electrónica para obtener información confidencial o hacerse pasar por una fuente conocida.
* **Tablero visual o Dashboard (Visual dashboard):** Una forma de mostrar varios tipos de datos rápidamente en un solo lugar.
* **Vulnerabilidad (Vulnerability):** Una debilidad que puede ser explotada por una amenaza.
* **Evaluación de vulnerabilidades (Vulnerability assessment):** El proceso de revisión interna de los sistemas de seguridad de una organización.
* **Gestión de vulnerabilidades (Vulnerability management):** El proceso de encontrar y parchear vulnerabilidades.
* **Escáner de vulnerabilidades (Vulnerability scanner):** Software que compara automáticamente las vulnerabilidades y exposiciones comunes existentes con las tecnologías en la red.

---

## W

* **Ataque de pozo de agua o Watering hole (Watering hole attack):** Un tipo de ataque en el que un actor de amenaza compromete un sitio web visitado con frecuencia por un grupo específico de usuarios.
* **Exploits basados en web (Web-based exploits):** Código o comportamiento malicioso que se utiliza para aprovechar los fallos de codificación en una aplicación web.
* **Whaling (pesca de ballenas):** Una categoría de intentos de spear phishing dirigidos a ejecutivos de alto rango en una organización.
* **Red de área amplia o WAN (Wide Area Network):** Una red que abarca una gran área geográfica como una ciudad, estado o país.
* **Acceso Protegido Wi-Fi o WPA (Wi-Fi Protected Access):** Un protocolo de seguridad inalámbrico para que los dispositivos se conecten a Internet.
* **Comodín o Wildcard (Wildcard):** Un carácter especial que se puede sustituir por cualquier otro carácter.
* **Wireshark:** Un analizador de protocolos de red de código abierto.
* **Archivo de escritura pública o World-writable (World-writable file):** Un archivo que puede ser modificado por cualquier persona en el mundo.
* **Gusano o Worm (Worm):** Malware que puede duplicarse y propagarse por sí mismo a través de los sistemas.

---

## X

* **Enfoque X-Y-Z (X-Y-Z approach):** Una fórmula o técnica que le ayuda a estructurar sus logros para mostrar claramente su impacto, especialmente en una entrevista o materiales de solicitud de empleo; X = logro o acción; Y = resultado cuantificable; Z = método o habilidades utilizadas.

---

## Y

* **YARA-L:** Un lenguaje informático utilizado para crear reglas para buscar a través de los datos de registro ingeridos.

---

## Z

* **Día cero o Zero-day (Zero-day):** Un exploit que antes era desconocido.
