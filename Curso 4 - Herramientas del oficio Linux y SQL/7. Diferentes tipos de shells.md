# Diferentes Tipos de Shells

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se repasan los shells de Linux y sus funciones, explorando los distintos tipos existentes y detallando **Bash**, el shell por defecto y estándar en la profesión de la ciberseguridad.

---

## Comunicación a través de un Shell

El **shell** (o intérprete de la línea de comandos) actúa como un traductor e intermediario entre el usuario y el sistema informático (kernel).

```
┌─────────────┐       Comando (Texto)       ┌─────────────┐     Llamadas al sistema     ┌─────────────┐
│   USUARIO   │ ──────────────────────────► │    SHELL    │ ──────────────────────────► │   KERNEL    │
│  (Analista) │ ◄────────────────────────── │(Intérprete) │ ◄────────────────────────── │ (Hardware)  │
└─────────────┘       Resultado/Salida      └─────────────┘         Respuestas          └─────────────┘
```

### Funciones Principales:
* **Intermediario de Comunicación:** Le permite dar órdenes a la computadora y recibir respuestas de ella.
* **Procesamiento Interno:** Al introducir un comando en el shell, este ejecuta múltiples procesos internos para:
  1. Interpretar y validar la orden introducida.
  2. Enviarla al **kernel** para su procesamiento físico.
  3. Devolver y presentar los resultados obtenidos al usuario.

## Tipos de Shells en Linux

Todas las shells de Linux utilizan los comandos comunes de Linux, pero pueden diferir en características avanzadas, sintaxis de scripting y en el indicador de línea de comandos (*prompt*).

### Principales Shells de Linux

| Shell | Nombre Completo | Indicador (*Prompt*) | Descripción y Uso |
| :--- | :--- | :--- | :--- |
| **`bash`** | Bourne-Again Shell | Signo de dólar (`$`) | Estándar de la industria, fácil de usar y shell por defecto en la mayoría de distribuciones. |
| **`zsh`** | Z Shell | Signo de porcentaje (`%`) | Altamente personalizable con autocompletado avanzado y gestión de temas. |
| **`ksh`** | Korn Shell | Signo de dólar (`$`) | Desarrollado en Bell Labs; combina características de Bourne shell y C shell. |
| **`csh`** | C Shell | Signo de porcentaje (`%`) | Utiliza una sintaxis de comandos basada en el lenguaje de programación C. |
| **`tcsh`** | Enhanced C Shell | Signo de porcentaje (`%` / `>`) | Versión mejorada de `csh` con completado automático de comandos y edición en línea. |

> [!NOTE]
> **Indicador de comandos (*Prompt*):** Muestra el símbolo que indica dónde teclea el usuario sus comandos. Por ejemplo:
> * `ksh` y `bash` utilizan habitualmente el signo del dólar (`$`).
> * Otros shells como `zsh` y `csh` utilizan el signo de porcentaje (`%`).

## Bash (*Bourne-Again Shell*)

**Bash** es el shell por defecto en la mayoría de las distribuciones de Linux y se considera un entorno sumamente fácil de usar e intuitivo.

### Características Clave:
* **Versatilidad:** Puede utilizar Bash tanto para tareas y comandos básicos de Linux como para automatización de proyectos más grandes mediante scripts.
* **Popularidad en Ciberseguridad:** Es el shell más extendido y popular en la profesión de la ciberseguridad.
* **Entorno de Práctica:** Será el shell principal que utilizará a lo largo de este curso para aprender y practicar los comandos de Linux.

---

## Puntos Clave

> [!IMPORTANT]
> * **Naturaleza del Shell:** Los shells son una parte fundamental del sistema operativo Linux que actúan como traductores entre el usuario y el equipo.
> * **Interacción:** Permiten enviar comandos al sistema informático y recibir respuestas procesadas.
> * **Variedad de Shells:** Existen diversos tipos de shells (`bash`, `csh`, `ksh`, `tcsh`, `zsh`), diferenciados principalmente por funciones avanzadas e indicadores visuales (*prompts*).
> * **Uso Estándar:** El shell **Bash** es el más utilizado en la profesión de la ciberseguridad y el estándar de trabajo en este curso.
