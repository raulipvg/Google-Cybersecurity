# Explicación de la Arquitectura de Linux

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se detalla la arquitectura del sistema operativo Linux, analizando cómo fluyen las peticiones a través de sus componentes fundamentales: **Usuario ➔ Aplicaciones ➔ Shell ➔ FHS ➔ Kernel ➔ Hardware**.

---

## Flujo de la Arquitectura de Linux

Linux está estructurado en capas jerárquicas interconectadas. Cada capa cumple un rol específico para traducir la intención del usuario en operaciones físicas en el hardware:

```
┌────────────────────────────────────────────────────────┐
│                        USUARIO                         │
│            (Sistema Multiusuario / Humano)             │
└──────────────────────────┬─────────────────────────────┘
                           │ Peticiones de tareas
                           ▼
┌────────────────────────────────────────────────────────┐
│                      APLICACIONES                      │
│        (Gestor de Paquetes / Software de Usuario)      │
└──────────────────────────┬─────────────────────────────┘
                           │ Comandos basados en texto
                           ▼
┌────────────────────────────────────────────────────────┐
│                         SHELL                          │
│           (Intérprete de Línea de Comandos)            │
└──────────────────────────┬─────────────────────────────┘
                           │ Rutas e Intermediación de Datos
                           ▼
┌────────────────────────────────────────────────────────┐
│     ESTÁNDAR DE JERARQUÍA DEL SISTEMA DE ARCHIVOS      │
│            (FHS - Organización de Directorios)         │
└──────────────────────────┬─────────────────────────────┘
                           │ Llamadas al Sistema (Syscalls)
                           ▼
┌────────────────────────────────────────────────────────┐
│                         KERNEL                         │
│           (Gestión de Procesos, Memoria y RAM)         │
└──────────────────────────┬─────────────────────────────┘
                           │ Instrucciones directas
                           ▼
┌────────────────────────────────────────────────────────┐
│                        HARDWARE                        │
│            (Interno: CPU, RAM, Disco | Periféricos)    │
└────────────────────────────────────────────────────────┘
```

---

## Análisis de los Componentes Principales

### 1. Usuario (*User*)
* **Rol:** Es la persona que inicia, supervisa y finaliza las tareas en el equipo.
* **Sistema Multiusuario:** Linux está diseñado desde su origen como un sistema **multiusuario**, permitiendo que múltiples usuarios inicien sesión, ejecuten procesos y compartan recursos simultáneamente con sus propios permisos y aislamientos de seguridad.

### 2. Aplicaciones (*Applications*)
* **Rol:** Programas de software diseñados para realizar tareas específicas (ej. calculadoras, navegadores web, clientes de correo o herramientas de seguridad).
* **Gestor de Paquetes (*Package Manager*):** Herramienta esencial de Linux para buscar, instalar, actualizar y eliminar software.
* **Paquete (*Package*):** Archivo comprimido que contiene código ejecutable, bibliotecas y archivos de configuración necesarios para construir o ejecutar una aplicación.

### 3. Shell (Intérprete de Comandos)
* **Rol:** Funciona como un **traductor** entre el usuario y el kernel.
* **Funcionamiento:** Recibe comandos en texto tipeados por el usuario, interpreta la sintaxis y los traduce en instrucciones comprensibles para el kernel de Linux.

### 4. Estándar de Jerarquía del Sistema de Archivos (FHS - *Filesystem Hierarchy Standard*)
* **Rol:** Define la estructura y organización estándar del sistema de archivos en todas las distribuciones de Linux.
* **Directorio (*Directory*):** Archivo contenedor especial que almacena y organiza otros archivos y subdirectorios. El FHS asegura que el OS y el usuario sepan exactamente en qué ubicación `/bin`, `/etc`, `/var`, `/home`, etc.) encontrar datos o binarios específicos.

### 5. Kernel (Núcleo de Linux)
* **Rol:** Es el corazón del sistema operativo. Gestiona la CPU, la memoria RAM, los dispositivos de entrada/salida y el control de procesos.
* **Funciones Críticas:** Asigna recursos a las aplicaciones, gestiona el aislamiento de memoria entre procesos y comunica las llamadas del sistema (*syscalls*) directamente con los componentes de hardware.

## El Hardware: Componentes Internos y Periféricos

El hardware abarca la totalidad de las partes físicas de la computadora y se divide en dos categorías:

```
                                  ┌───────────────────┐
                                  │     HARDWARE      │
                                  └─────────┬─────────┘
                                            │
               ┌────────────────────────────┴────────────────────────────┐
               ▼                                                         ▼
    ┌──────────────────────┐                                  ┌──────────────────────┐
    │  HARDWARE INTERNO    │                                  │DISPOSITIVOS PERIFÉRICOS│
    ├──────────────────────┤                                  ├──────────────────────┤
    │ • Placa Base (Mother)│                                  │ • Monitor / Impresora│
    │ • CPU (Procesador)   │                                  │ • Teclado / Ratón    │
    │ • RAM (Corto plazo)  │                                  │ (Conectados/Libres)  │
    │ • Disco (Largo plazo)│                                  └──────────────────────┘
    └──────────────────────┘
```

### Dispositivos Periféricos
Componentes externos conectados y controlados por la computadora (ej. monitores, impresoras, teclados, ratones). No son indispensables para que la placa base encienda y procese información básica, por lo que pueden conectarse o desconectarse según la necesidad.

### Hardware Interno
Componentes imprescindibles ensamblados en la placa de circuito principal (**Motherboard**):

| Componente | Tipo de Memoria / Función | Descripción |
| :--- | :--- | :--- |
| **CPU** (*Central Processing Unit*) | Procesador Principal | Ejecuta las instrucciones del código y procesa los datos generales del sistema. |
| **RAM** (*Random Access Memory*) | **Corto Plazo / Volátil** | Almacena temporalmente los datos de las aplicaciones en ejecución. **Se borra al apagar la computadora**. La CPU lee datos directamente de la RAM. |
| **Disco Duro / SSD** | **Largo Plazo / No Volátil** | Guarda archivos, programas y el propio SO de forma permanente. **Mantiene la información al apagar el equipo**. |

---

## Puntos Clave

1. **Flujo Jerárquico:** Una solicitud en Linux atraviesa ordenadamente 6 capas: **Usuario ➔ Aplicaciones ➔ Shell ➔ FHS ➔ Kernel ➔ Hardware**.
2. **Linux Multiusuario:** Soporta el uso simultáneo de recursos por múltiples usuarios con control de permisos.
3. **El Shell como Traductor:** Traduce órdenes en texto tipeadas en la CLI hacia el Kernel.
4. **FHS:** Normaliza la organización y ubicación de archivos y directorios en todo sistema Linux.
5. **Kernel:** Administra la memoria, procesos y recursos de hardware.
6. **RAM vs. Disco:** La RAM es memoria de trabajo temporal (volátil) para la CPU; el disco duro es memoria de almacenamiento permanente (no volátil).
