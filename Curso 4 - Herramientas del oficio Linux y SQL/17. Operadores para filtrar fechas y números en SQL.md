# Operadores para Filtrar Fechas y Números en SQL

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se analiza el uso de operadores de comparación relacionales y el operador de rango **`BETWEEN`** para filtrar datos numéricos y marcas de tiempo (*timestamps*) en investigaciones de ciberseguridad.

---

## 1. Datos Numéricos y Temporales en Ciberseguridad

* **Datos Numéricos:** Permiten identificar ataques de fuerza bruta (ej. umbral de intentos fallidos > 10) o exfiltración de información (ej. tamaño de transferencia de datos inusualmente alto).
* **Datos de Fecha y Hora (*Timestamps*):** Permiten acotar la ventana de tiempo exacta en que se produjo un incidente o verificar si un sistema vulnerable recibió un parche a tiempo.

## 2. Operadores de Comparación en SQL

Los operadores relacionales permiten evaluar condiciones numéricas y cronológicas dentro de la cláusula **`WHERE`**.

| Operador | Significado | Tipo de Evaluación | Ejemplo de Consulta |
| :---: | :--- | :---: | :--- |
| **`<`** | Menor que | **Exclusivo** | `WHERE failed_attempts < 5` |
| **`>`** | Mayor que | **Exclusivo** | `WHERE birthdate > '1970-01-01'` |
| **`=`** | Igual a | Coincidencia exacta | `WHERE port_number = 443` |
| **`<=`** | Menor o igual que | **Inclusivo** | `WHERE response_code <= 399` |
| **`>=`** | Mayor o igual que | **Inclusivo** | `WHERE birthdate >= '1970-01-01'` |
| **`<>`** / **`!=`** | No igual a / Distinto de | Exclusión | `WHERE status_code <> 200` |

```
                 ┌─────────────────────────────────────────┐
                 │       INCLUSIVIDAD DEL OPERADOR         │
                 └────────────────────┬────────────────────┘
                                      │
        ┌─────────────────────────────┴─────────────────────────────┐
        ▼                                                           ▼
┌───────────────────────────────┐                   ┌───────────────────────────────┐
│     OPERADOR EXCLUSIVO        │                   │      OPERADOR INCLUSIVO       │
│        ( > , < )              │                   │       ( >= , <= , BETWEEN )   │
├───────────────────────────────┤                   ├───────────────────────────────┤
│ • NO incluye el valor límite  │                   │ • SÍ incluye el valor exacto  │
│   de la comparación.          │                   │   del límite especificado.    │
│ • birthdate > '1970-01-01'    │                   │ • birthdate >= '1970-01-01'   │
│   (Solo nacidos desde el 2/Ene)│                  │   (Incluye nacidos el 1/Ene)  │
└───────────────────────────────┘                   └───────────────────────────────┘
```

> [!NOTE]
> En SQL estándar, tanto **`<>`** como **`!=`** se utilizan para representar la condición de desigualdad ("distinto de"), siendo ambos ampliamente soportados por la mayoría de motores de bases de datos.

## 3. Filtrado por Rangos: El Operador `BETWEEN`

El operador **`BETWEEN`** permite simplificar la búsqueda de valores numéricos o cronológicos que caen dentro de un intervalo cerrado.

### Sintaxis General:
```sql
SELECT columna1, columna2
FROM nombre_tabla
WHERE columna BETWEEN valor_inicial AND valor_final;
```

### Ejemplo en la Base de Datos Chinook:
Recuperar los empleados contratados entre el 1 de enero de 2002 y el 1 de enero de 2003:

```sql
SELECT firstname, lastname, hiredate
FROM employees
WHERE hiredate BETWEEN '2002-01-01' AND '2003-01-01';
```

> [!IMPORTANT]
> **Naturaleza Inclusiva de `BETWEEN`:** El operador `BETWEEN` es **inclusivo**, lo que significa que los registros cuya fecha sea exactamente `'2002-01-01'` o `'2003-01-01'` serán incorporados en los resultados finales.

---

## 4. Ejemplos Aplicados a la Ciberseguridad

### A. Detección de Intentos de Acceso Sospechosos
Filtrar cuentas que hayan superado un umbral de seguridad de 5 intentos de inicio de sesión fallidos:
```sql
SELECT username, ip_address, failed_attempts
FROM login_logs
WHERE failed_attempts > 5;
```

### B. Análisis Forense en una Ventana de Incidente
Aislar eventos ocurridos durante una ventana horaria sospechosa:
```sql
SELECT event_id, event_type, timestamp
FROM security_events
WHERE timestamp BETWEEN '2026-08-16 02:00:00' AND '2026-08-16 04:30:00';
```

---

## Puntos Clave

> [!IMPORTANT]
> * **Operadores Exclusivos vs. Inclusivos:** Los operadores `<` y `>` descartan el valor frontera, mientras que `<=`, `>=` y `BETWEEN` lo incluyen explícitamente en el conjunto de resultados.
> * **Formato de Fechas:** Las fechas en SQL se expresan convencionalmente en formato `'YYYY-MM-DD'` (o `'YYYY-MM-DD HH:MM:SS'` para timestamps) encerradas entre comillas simples.
> * **Eficiencia con `BETWEEN`:** Facilita la legibilidad al evitar tener que escribir condiciones compuestas redundantes (como `fecha >= inicio AND fecha <= fin`).
