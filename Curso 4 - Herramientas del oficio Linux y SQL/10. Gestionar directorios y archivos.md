# Gestionar Directorios y Archivos

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se repasan las operaciones fundamentales para la creación, modificación, desplazamiento y eliminación de directorios y archivos en Linux, el uso del editor de texto en terminal `nano`, y la redirección de salida estándar (`>` y `>>`).

---

## 1. Creación y Modificación de Directorios

Linux ofrece comandos específicos para estructurar y organizar carpetas utilizando rutas absolutas o relativas.

| Comando | Función | Ejemplo de Uso | Notas / Restricciones |
| :--- | :--- | :--- | :--- |
| **`mkdir`** | *Make Directory* | `mkdir /home/analyst/logs/network` | Crea un nuevo directorio en la ruta especificada. |
| **`rmdir`** | *Remove Directory* | `rmdir /home/analyst/logs/network` | Elimina un directorio **únicamente si está vacío**. |

> [!WARNING]
> **Restricción de `rmdir`:** Intentar eliminar un directorio que contenga archivos o subdirectorios con `rmdir` devolverá un mensaje de error. Para verificar si la carpeta fue creada o eliminada, use `ls`.

---

## 2. Creación, Copia, Movimiento y Eliminación de Archivos

| Comando | Función | Ejemplo de Uso | Descripción / Comportamiento |
| :--- | :--- | :--- | :--- |
| **`touch`** | Crear Archivo Vacío | `touch permissions.txt` | Crea un nuevo archivo en blanco sin contenido inicial. |
| **`rm`** | *Remove* (Eliminar) | `rm permissions.txt` | Borra de forma permanente un archivo del sistema. |
| **`mv`** | *Move* (Mover / Renombrar) | `mv permissions.txt /home/analyst/logs` <br> `mv permissions.txt perm.txt` | Mueve un archivo a una nueva ubicación (eliminándolo de la fuente) **o** renombra el archivo si el segundo argumento es un nuevo nombre. |
| **`cp`** | *Copy* (Copiar) | `cp permissions.txt /home/analyst/logs` | Duplica el archivo en el destino especificado, conservando la copia original. |

> [!CAUTION]
> **Eliminación irreversibles con `rm`:** Los archivos eliminados mediante `rm` no van a una papelera de reciclaje y son difíciles de recuperar. Use este comando con extrema precaución.

## 3. Editor de Texto `nano`

**`nano`** es un editor de texto interactivo de línea de comandos preinstalado en la mayoría de distribuciones de Linux. Es ampliamente utilizado en ciberseguridad por su sencillez para editar archivos de configuración y scripts.

### Modos de Inicio:
* **Abrir un archivo existente:** `nano permissions.txt` o `nano /home/analyst/reports/permissions.txt`
* **Crear un archivo nuevo:** `nano authorized_users.txt` (crea y abre el archivo en el directorio actual).

### Accesos Directos de Teclado Esenciales:

| Combinación | Acción | Descripción |
| :--- | :--- | :--- |
| **`Ctrl + O`** | *WriteOut* (Guardar) | Guarda los cambios realizados en el archivo (solicita confirmar el nombre). |
| **`Ctrl + X`** | *Exit* (Salir) | Cierra el editor `nano` y regresa a la ventana de la terminal. |

> [!NOTE]
> `nano` no posee función de autoguardado; es imprescindible pulsar `Ctrl + O` antes de salir con `Ctrl + X`. Otros editores de texto populares en consola son **Vim** y **Emacs**.

## 4. Redirección de Salida Estándar (`>` y `>>`)

Además de utilizar editores interactivos como `nano`, es posible escribir texto directamente en archivos redirigiendo la salida estándar (*stdout*) devuelta por comandos como `echo`.

```
                        ┌─────────────────────────────────────────┐
                        │      REDISRECCIÓN DE SALIDA (stdout)    │
                        └────────────────────┬────────────────────┘
                                             │
               ┌─────────────────────────────┴─────────────────────────────┐
               ▼                                                           ▼
┌─────────────────────────────┐                             ┌─────────────────────────────┐
│   OPERADOR DE SOBRESCRITURA │                             │    OPERADOR DE ANEXADO     │
│             (>)             │                             │            (>>)             │
├─────────────────────────────┤                             ├─────────────────────────────┤
│ • Reemplaza TODO el contenido│                             │ • Agrega el contenido al    │
│   anterior del archivo.     │                             │   FINAL del archivo actual. │
└─────────────────────────────┘                             └─────────────────────────────┘
```

### Comparación entre `>` y `>>`:

| Operador | Tipo | Sintaxis de Ejemplo | Resultado |
| :--- | :--- | :--- | :--- |
| **`>>`** | **Anexar** (*Append*) | `echo "last updated date" >> permissions.txt` | Añade la cadena al final del contenido existente sin borrar nada. |
| **`>`** | **Sobrescribir** (*Overwrite*) | `echo "time" > permissions.txt` | **Elimina todo el contenido previo** de `permissions.txt` y lo reemplaza únicamente con `"time"`. |

> [!IMPORTANT]
> * Tanto `>` como `>>` **crearán automáticamente el archivo** objetivo si este no existe previamente.
> * **Atención con `>`:** Utilizar `>` de forma errónea borrará el contenido previo del archivo sin pedir confirmación.

---

## Puntos Clave

> [!IMPORTANT]
> * **Gestión de Directorios:** `mkdir` crea directorios y `rmdir` elimina carpetas estrictamente vacías.
> * **Manipulación de Archivos:** `touch` crea archivos en blanco, `rm` los elimina de forma irreversible, `cp` los duplica y `mv` los desplaza o renombra.
> * **Escritura e Inspección:** `nano` permite la edición interactiva de archivos mediante `Ctrl + O` (guardar) y `Ctrl + X` (salir).
> * **Redirección de Salida:** El operador `>>` concatena información al final de un archivo, mientras que `>` reemplaza todo el contenido existente.
