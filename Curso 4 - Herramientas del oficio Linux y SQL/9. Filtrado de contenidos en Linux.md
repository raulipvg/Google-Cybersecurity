# Filtrado de Contenidos en Linux

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se exploran las herramientas y comandos esenciales para **filtrar información** en el sistema de archivos de Linux, incluyendo la búsqueda de patrones en texto con `grep`, la conexión de comandos mediante canalización (`|`), y la localización de archivos y directorios según criterios específicos con `find`.

---

## La Importancia del Filtrado en Ciberseguridad

El **filtrado** consiste en seleccionar únicamente los datos que cumplen con criterios o condiciones específicas (por ejemplo, buscar cadenas de texto en registros, identificar archivos por extensión o localizar ficheros modificados recientemente).

* **Aplicaciones prácticas:**
  * Aislar registros de eventos de seguridad (*security logs*) que contengan la palabra `error`, `failed` o `unauthorized`.
  * Localizar archivos maliciosos ocultos o modificados por atacantes tras un incidente.
  * Agilizar el análisis forense filtrando millones de líneas de texto a solo la información relevante.

---

## 1. El Comando `grep` (Búsqueda de Cadenas de Texto)

El comando **`grep`** busca en uno o más archivos y devuelve únicamente las líneas de texto que contienen una cadena o patrón coincidente.

### Sintaxis Básica:
```bash
grep [cadena_buscada] [archivo_destino]
```

### Ejemplos Prácticos:

| Comando | Acción / Descripción |
| :--- | :--- |
| `grep OS updates.txt` | Escanea `updates.txt` e imprime solo las líneas que contienen la cadena exacta `OS`. |
| `grep error time_logs.txt` | Escanea `time_logs.txt` y devuelve todas las líneas donde aparece la palabra `error`. |

---

## 2. Canalización o Tuberías (`|` - *Piping*)

La **canalización** utiliza el operador barra vertical (`|`) para redirigir la salida estándar (*stdout*) de un comando y enviarla directamente como entrada estándar (*stdin*) a otro comando para su procesamiento posterior.

```
┌─────────────────────────┐       Salida Estándar (stdout)       ┌─────────────────────────┐
│       COMANDO 1         │ ───────────────────────────────────► │        COMANDO 2        │
│    (ej. ls /reports)    │                 |                    │    (ej. grep users)     │
└─────────────────────────┘             Operador                 └─────────────────────────┘
```

### Ejemplo Combinado (`ls` + `|` + `grep`):
```bash
ls /home/analyst/reports | grep users
```
1. `ls /home/analyst/reports`: Genera la lista de archivos y carpetas del directorio `reports`.
2. `|`: Redirige esa lista al comando `grep`.
3. `grep users`: Filtra y muestra únicamente los nombres de archivos/directorios que contengan la palabra `users`.

> [!NOTE]
> La canalización es una forma general de redirección en Linux que se puede encadenar múltiples veces para crear tuberías complejas de análisis de datos.

## 3. El Comando `find` (Búsqueda de Archivos y Directorios)

El comando **`find`** busca en el sistema de archivos aquellos elementos que cumplan con criterios específicos como nombres, patrones, tamaños o fechas de modificación.

### Sintaxis Básica:
```bash
find [ruta_de_inicio] [opciones_y_criterios]
```

---

### Opciones de Búsqueda por Nombre (`-name` e `-iname`)

Para buscar elementos por nombre o patrón, se utilizan las opciones `-name` o `-iname` acompañadas de la cadena entre comillas.

| Opción | Sensibilidad a Mayúsculas | Ejemplo | Resultado |
| :--- | :--- | :--- | :--- |
| **`-name`** | **Sensible** (*Case-sensitive*) | `find /home/analyst/projects -name "*log*"` | Coincide con `syslog`, `log.txt`, pero **ignora** `Log` o `LOG`. |
| **`-iname`** | **Insensible** (*Case-insensitive*) | `find /home/analyst/projects -iname "*log*"` | Coincide con `log`, `Log`, `LOG`, `syslog.LOG`, etc. |

> [!TIP]
> **Comodines (*Wildcards*):** El asterisco (`*`) representa cero o más caracteres desconocidos. La expresión `"*log*"` buscará cualquier archivo cuyo nombre contenga la palabra `log` en cualquier posición.

---

### Opciones de Búsqueda por Fecha de Modificación (`-mtime` y `-mmin`)

Los analistas de ciberseguridad usan `-mtime` para identificar archivos alterados o creados recientemente dentro de una ventana de tiempo.

| Opción / Criterio | Unidad de Tiempo | Significado del Parámetro | Ejemplo |
| :--- | :--- | :--- | :--- |
| **`-mtime -3`** | Días | Modificado en los **últimos 3 días** (< 3 días). | `find /home/analyst/projects -mtime -3` |
| **`-mtime +1`** | Días | Modificado **hace más de 1 día** (> 1 día). | `find /home/analyst/projects -mtime +1` |
| **`-mtime -1`** | Días | Modificado en las **últimas 24 horas** (< 1 día). | `find /home/analyst/projects -mtime -1` |
| **`-mmin -60`** | Minutos | Modificado en los **últimos 60 minutos** (< 60 min). | `find /home/analyst/projects -mmin -60` |

---

## Puntos Clave

> [!IMPORTANT]
> * **Búsqueda en Archivos (`grep`):** Permite filtrar líneas específicas en archivos de texto o registros usando cadenas clave.
> * **Redirección Operativa (`|`):** Conecta la salida de un comando con la entrada del siguiente para realizar filtros en cadena.
> * **Búsqueda en Directorios (`find`):** Localiza archivos según su nombre (`-name` / `-iname`), comodines (`*`), o marcas de tiempo de modificación (`-mtime` / `-mmin`).
