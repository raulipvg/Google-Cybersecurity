## 2. Comandos Integrados de Ayuda en la Terminal (CLI)

El sistema operativo Linux incluye herramientas nativas para consultar manuales y descubrir comandos sin necesidad de una conexión a Internet.

| Comando | Significado / Origen | Propósito y Función | Ejemplo de Uso |
| :--- | :--- | :--- | :--- |
| **`man`** | *Manual* | Muestra la **página de manual completa y detallada** de un comando específico (opciones, argumentos y ejemplos). | `man chown` |
| **`apropos`** | *A propósito de...* | Busca palabras clave dentro de las descripciones de todas las páginas de manual. Útil si no recuerda el nombre exacto de un comando. | `apropos editor` <br> `apropos -a graph editor` |
| **`whatis`** | *¿Qué es?* | Muestra una **descripción concisa de una sola línea** sobre la función de un comando. Ideal para recordatorios rápidos. | `whatis nano` |

---

### Detalle de Comandos Integrados

### 1. `man` (Páginas de Manual)
Muestra la documentación técnica completa estructurada en secciones (NOMBRE, SINOPSIS, DESCRIPCIÓN, OPCIONES, EJEMPLOS).
```bash
man chown
```
> [!TIP]
> Durante la navegación en una página de `man`, puede presionar la tecla `q` para salir y regresar a la terminal.

### 2. `apropos` (Búsqueda por Palabras Clave)
Permite localizar comandos relacionados con un tema o tarea cuando desconoce el nombre ejecutable del programa.
```bash
# Busca comandos cuya descripción contenga 'editor' Y 'graph' simultáneamente:
apropos -a graph editor
```
* **Opción `-a` (*AND*):** Requiere que todas las palabras clave especificadas estén presentes en la descripción de la página del manual.

### 3. `whatis` (Resumen Breve)
Devuelve únicamente la primera línea descriptiva de la página de manual para ofrecer un contexto rápido de la herramienta.
```bash
whatis nano
# Salida típica: nano (1) - Nano's ANOther editor, an enhanced free Pico clone
```

## Puntos Clave

> [!IMPORTANT]
> * **Autonomía y Aprendizaje:** La capacidad de investigar de forma independiente mediante la comunidad global (como Unix & Linux Stack Exchange) es una habilidad técnica crítica para los analistas de ciberseguridad.
> * **Documentación Interna Completa (`man`):** Proporciona manuales exhaustivos sobre la sintaxis y flags de cada comando.
> * **Búsqueda Funcional (`apropos`):** Permite encontrar herramientas buscando por la función que realizan.
> * **Referencia Rápida (`whatis`):** Permite verificar en una sola línea para qué sirve cualquier comando antes de ejecutarlo.
