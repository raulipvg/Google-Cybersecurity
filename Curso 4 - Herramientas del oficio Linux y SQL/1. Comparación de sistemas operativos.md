# Comparación de Sistemas Operativos

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se comparan los sistemas operativos (SO) más utilizados en el sector tecnológico, analizando la diferencia entre código abierto y cerrado, los entornos móviles frente a los de escritorio y los riesgos de ciberseguridad asociados a los **sistemas operativos heredados** (*Legacy OS*).

---

### 1. Windows (Microsoft)
- **Lanzamiento:** 1985.
- **Modelo:** **Código cerrado** (*Closed-Source*). Su código fuente es propiedad exclusiva de Microsoft y no se comparte con el público.
- **Uso:** Sistema predominante en estaciones de trabajo empresariales y computadoras personales a nivel mundial.

### 2. macOS® (Apple)
- **Lanzamiento:** 1984.
- **Modelo:** **Parcialmente de código abierto**. Su núcleo subyacente (kernel XNU/Darwin) contiene componentes *open-source*, pero sus capas superiores e interfaz de usuario son de código cerrado.
- **Uso:** Computadoras personales y entornos corporativos.

### 3. Linux
- **Lanzamiento:** 1991 (Kernel creado por Linus Torvalds).
- **Modelo:** **Totalmente de código abierto** (*Open-Source*). Cualquiera puede inspeccionar, modificar, personalizar y distribuir su código fuente de forma libre.
- **Importancia en Ciberseguridad:** Es el sistema operativo de referencia para la infraestructura de servidores, servicios en la nube y herramientas de auditoría de seguridad. Existen distribuciones diseñadas específicamente para seguridad defensiva y pentesting (ej. Kali Linux, Parrot OS).

### 4. ChromeOS (Google)
- **Lanzamiento:** 2011.
- **Modelo:** **Parcialmente de código abierto** (basado en Chromium OS, que es 100% *open-source*).
- **Uso:** Ampliamente extendido en el sector educativo y dispositivos ligeros basados en la nube (*Chromebooks*).

### 5. Sistemas Operativos Móviles: Android e iOS
Diseñados específicamente para funcionar en smartphones, tablets y dispositivos portátiles (*wearables*).
- **Android (Google):** Lanzado en 2008. De código abierto (*Android Open Source Project* - AOSP).
- **iOS (Apple):** Lanzado en 2007. Parcialmente de código abierto.

## Vulnerabilidades y Sistemas Operativos Heredados (Legacy OS)

Incluso con parches de seguridad continuos, todos los sistemas operativos presentan vulnerabilidades que pueden ser explotadas por actores maliciosos.

### Sistemas Operativos Heredados (Legacy OS)
Un **sistema operativo heredado** es un sistema obsoleto que ha alcanzado el fin de su ciclo de vida (*End of Life* - EOL) pero que continúa utilizándose en la infraestructura de una organización.

- **Razones de Uso:** Algunas industrias (medicina, manufactura, transporte) dependen de software embebido o aplicaciones propietarias antiguas incompatibles con sistemas modernos.
- **Riesgo Crítico de Ciberseguridad:**

> [!CAUTION]
> **Sin Soporte ni Parches de Seguridad:** Al estar fuera de soporte por parte del fabricante, los sistemas heredados **no reciben parches de vulnerabilidad**. Cualquier nueva amenaza o exploit descubierto afectará indefinidamente a estos sistemas, convirtiéndolos en un punto crítico de entrada para ciberataques.

---

## Fuentes Oficiales para el Rastreo de Vulnerabilidades

Los analistas de seguridad deben monitorear constantemente los boletines oficiales para identificar y mitigar vulnerabilidades conocidas:

1. **MSRC (Microsoft Security Response Center):** Publicación de boletines y parches de seguridad para productos Windows.
2. **Apple Security Updates:** Registro de boletines de seguridad para macOS, iOS, iPadOS y tvOS.
3. **Ubuntu CVE Tracker:** Base de datos de Vulnerabilidades y Exposiciones Comunes (CVE) específicas para la distribución Ubuntu Linux.
4. **Google Cloud Security Bulletins:** Avisos de seguridad y vulnerabilidades que afectan a la infraestructura de Google Cloud.

---

## Puntos Clave

1. **Diversidad de SO:** Conocimiento de Windows, macOS, Linux, ChromeOS, Android e iOS en entornos mixtos corporativos.
2. **Código Abierto vs. Cerrado:** Linux y Android ofrecen acceso total a su código fuente; Windows es cerrado; macOS, iOS y ChromeOS son parcialmente abiertos.
3. **Peligro del Legacy OS:** Los sistemas heredados carecen de actualizaciones de seguridad, siendo un objetivo prioritario para exploits y malware.
4. **Monitoreo de Vulnerabilidades:** Esencial consultar fuentes como MSRC, Apple Updates, Ubuntu CVE Tracker y Google Cloud Bulletins para aplicar parches a tiempo.
