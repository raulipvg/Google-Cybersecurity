# Navegar por Linux y Leer el Contenido de los Archivos

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se analiza cómo navegar por el sistema de archivos de Linux utilizando comandos de Bash, la estructura del **Estándar de Jerarquía del Sistema de Archivos (FHS)**, el uso de rutas absolutas y relativas, y los comandos fundamentales para visualizar el contenido de archivos de texto y registros (*logs*).

---

## Estándar de Jerarquía del Sistema de Archivos (FHS)

El **Estándar de Jerarquía del Sistema de Archivos** (*Filesystem Hierarchy Standard - FHS*) define la estructura organizativa de los directorios, archivos y almacenamiento dentro del sistema operativo Linux.

```
/ (Directorio Raíz)
├── bin/     (Ejecutables y binarios del sistema)
├── etc/     (Archivos de configuración del sistema)
├── tmp/     (Archivos temporales)
├── mnt/     (Puntos de montaje para medios externos)
└── home/    (Directorios personales de los usuarios)
    ├── analyst/ (~)
    │   ├── projects/
    │   ├── logs/
    │   └── reports/
    └── analyst2/
```

---

## Directorios FHS Estándar

| Directorio | Nombre Completo / Significado | Descripción y Relevancia en Ciberseguridad |
| :--- | :--- | :--- |
| **`/`** | Directorio Raíz (*Root*) | Nivel superior de la jerarquía; de él se ramifican todos los demás directorios. |
| **`/home`** | Directorio Personal | Contiene las carpetas personales de cada usuario registrado en el sistema. |
| **`/bin`** | Binarios (*Binaries*) | Contiene comandos ejecutables y binarios esenciales para todos los usuarios. |
| **`/etc`** | Archivos de Configuración | Almacena los archivos de configuración del sistema y servicios. |
| **`/tmp`** | Temporales (*Temporary*) | Archivos temporales. **Atención en Ciberseguridad:** Habitualmente usado por atacantes para desplegar payloads o scripts al ser modificable por cualquier usuario. |
| **`/mnt`** | Montaje (*Mount*) | Ubicación predeterminada para montar medios externos (unidades USB, discos duros). |

> [!TIP]
> **Consejo Profesional:** Puede ejecutar el comando `man hier` en el terminal para consultar la documentación del manual oficial sobre la estructura jerárquica del FHS.

## Conceptos de Rutas de Archivos (*File Paths*)

Una **ruta de archivo** describe la ubicación exacta de un directorio o archivo en la jerarquía del sistema, utilizando barras oblicuas (`/`) para delimitar niveles.

* **Directorio Raíz (`/`):** Representa el nivel más alto del sistema de archivos.
* **Atajo de Directorio Personal (`~`):** La tilde representa la ruta completa hacia el directorio home del usuario actual (ej. `~/logs` equivale a `/home/analyst/logs`).

### Rutas Absolutas vs. Relativas

```
                               ┌──────────────────────────────────┐
                               │       RUTAS EN EL SISTEMA        │
                               └────────────────┬─────────────────┘
                                                │
                 ┌──────────────────────────────┴──────────────────────────────┐
                 ▼                                                             ▼
┌─────────────────────────────────┐                           ┌─────────────────────────────────┐
│     RUTA ABSOLUTA (Completa)    │                           │     RUTA RELATIVA (Parcial)     │
├─────────────────────────────────┤                           ├─────────────────────────────────┤
│ • Parte siempre de la raíz (/). │                           │ • Parte del directorio actual.  │
│ • Ej: /home/analyst/projects    │                           │ • usa '.' (actual) o '..' (padre)│
└─────────────────────────────────┘                           └─────────────────────────────────┘
```

* **Ruta Absoluta:** Especifica la trayectoria completa desde el directorio raíz (`/`). Ejemplo: `/home/analyst/projects`.
* **Ruta Relativa:** Parte de la ubicación o directorio de trabajo actual.
  * **`.` (Punto único):** Representa el directorio actual.
  * **`..` (Doble punto):** Representa el directorio padre (un nivel superior). Ejemplo: `../projects`.

## Comandos Clave para Navegar por el Sistema de Archivos

| Comando | Función | Ejemplo de Uso | Descripción |
| :--- | :--- | :--- | :--- |
| **`pwd`** | *Print Working Directory* | `pwd` | Muestra la ruta absoluta completa del directorio actual (ej. `/home/analyst`). |
| **`whoami`** | *Who Am I* | `whoami` | Devuelve el nombre de usuario de la sesión activa en la consola. |
| **`ls`** | *List* | `ls` / `ls projects` | Lista archivos y directorios del directorio actual o de una ruta pasada como argumento. |
| **`cd`** | *Change Directory* | `cd /var/log` / `cd ..` | Cambia el directorio de trabajo actual a una ruta absoluta, relativa o sube un nivel con `..`. |

> [!NOTE]
> * Si ejecuta `cd` sin argumentos, el shell lo llevará automáticamente a su directorio personal (`~`).
> * Para subir un nivel en la jerarquía de directorios, utilice la ruta relativa `cd ..`.

## Comandos para Leer e Inspeccionar Contenido de Archivos

Los analistas de ciberseguridad leen y examinan continuamente archivos de configuración, código y logs del sistema.

### 1. `cat` (*Concatenate*)
* **Propósito:** Muestra todo el contenido de uno o más archivos secuencialmente en la terminal.
* **Uso típico:** `cat updates.txt`
* **Limitación:** Si el archivo es muy extenso, se desplaza rápidamente superando el búfer de la consola.

### 2. `head`
* **Propósito:** Visualiza el inicio de un archivo (primeras 10 líneas por defecto).
* **Uso típico:** `head updates.txt`
* **Personalización de líneas (`-n`):** Para inspeccionar una cantidad específica de líneas, use el parámetro `-n`.
  * Ejemplo: `head -n 5 updates.txt` (muestra únicamente las primeras 5 líneas).

### 3. `tail`
* **Propósito:** Muestra la parte final de un archivo (últimas 10 líneas por defecto).
* **Uso típico:** `tail updates.txt`
* **Aplicación en Ciberseguridad:** Ideal para inspeccionar los **eventos más recientes en archivos de registro (*logs*)**.
  * Ejemplo: `tail -n 20 /var/log/syslog`

### 4. `less`
* **Propósito:** Abre un paginador interactivo que permite navegar por archivos extensos pantalla a pantalla sin cargar todo el archivo en memoria de golpe.
* **Uso típico:** `less updates.txt`

#### Atajos de Teclado en `less`:

| Tecla | Acción |
| :--- | :--- |
| **`Barra Espaciadora`** | Avanzar una página completa hacia adelante. |
| **`b`** | Retroceder una página completa (*backwards*). |
| **`Flecha Abajo` / `Enter`** | Avanzar línea por línea. |
| **`Flecha Arriba`** | Retroceder línea por línea. |
| **`q`** | Salir del visor `less` y regresar al indicador de comandos. |

## Puntos Clave

> [!IMPORTANT]
> * **Estructura FHS:** Es fundamental comprender la jerarquía del sistema de archivos Linux para localizar binarios (`/bin`), configuraciones (`/etc`), temporales vulnerablemente abiertos (`/tmp`) y datos personales (`/home`).
> * **Comandos de Navegación:** El flujo de trabajo diario en CLI requiere el dominio directo de `pwd`, `whoami`, `ls` y `cd`.
> * **Lectura de Archivos:** La inspección de evidencias y registros de auditoría se realiza de forma eficiente combinando la visualización completa (`cat`), el filtrado de extremos (`head`/`tail`) y la lectura interactiva paginada (`less`).
