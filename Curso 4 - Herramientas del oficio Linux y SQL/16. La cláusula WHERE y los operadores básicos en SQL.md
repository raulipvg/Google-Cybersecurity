# La Cláusula WHERE y los Operadores Básicos en SQL

En esta lectura del **Curso 4: Herramientas del oficio (Linux y SQL)**, se profundiza en el filtrado de consultas mediante la cláusula **`WHERE`**, el uso del operador de coincidencia de patrones **`LIKE`** y los comodines **`%`** (signo de porcentaje) y **`_`** (guión bajo).

---

## 1. El Rol del Filtrado en Ciberseguridad

Los analistas de seguridad gestionan bases de datos con millones de registros de auditoría y tráfico. El filtrado preciso con SQL permite:

* **Investigación de Incidentes:** Aislar los intentos de inicio de sesión de una cuenta comprometida durante un lapso específico.
* **Gestión de Vulnerabilidades:** Identificar dispositivos que ejecuten versiones desactualizadas de un sistema o aplicación.
* **Auditoría de Accesos:** Filtrar empleados por departamento o nivel de privilegios para revisiones de seguridad.

---

## 2. La Cláusula `WHERE` (Filtrado por Igualdad Exacta)

La cláusula **`WHERE`** establece la condición que deben cumplir las filas para ser devueltas en el resultado.

```
┌────────────────────────────────────────────────────────┐
│                   FLUJO DE EVALUACIÓN                  │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
               ┌───────────────────────┐
               │         FROM          │ ➔ Identifica la tabla
               └───────────┬───────────┘
                           │
                           ▼
               ┌───────────────────────┐
               │         WHERE         │ ➔ Descarta las filas que no cumplen
               └───────────┬───────────┘
                           │
                           ▼
               ┌───────────────────────┐
               │        SELECT         │ ➔ Proyecta las columnas resultantes
               └───────────────────────┘
```

### Sintaxis Básica:
```sql
SELECT firstname, lastname, title, email
FROM employees
WHERE title = 'IT Staff';
```

* **Operador `=` (Signo de Igualdad):** Exige una coincidencia exacta con el valor especificado (las cadenas de texto van encerradas entre comillas simples `' '`).
* **Punto y coma (`;`):** Se ubica siempre al final de la consulta completa, después de la condición `WHERE`.

## 3. Filtrado por Patrones: Operador `LIKE` y Comodines

Cuando no se conoce el valor exacto o se desea buscar coincidencias parciales (por ejemplo, cargos que comiencen por un prefijo o códigos con una longitud determinada), se sustituye el signo `=` por el operador **`LIKE`**.

```
                         ┌─────────────────────────────────────────┐
                         │          COMODINES DE PATRÓN            │
                         └────────────────────┬────────────────────┘
                                              │
                ┌─────────────────────────────┴─────────────────────────────┐
                ▼                                                           ▼
┌───────────────────────────────┐                           ┌───────────────────────────────┐
│     SIGNO DE PORCENTAJE (%)   │                           │        GUIÓN BAJO (_)         │
├───────────────────────────────┤                           ├───────────────────────────────┤
│ • Representa CERO, UNO o      │                           │ • Representa EXACTAMENTE UN   │
│   MÚLTIPLES caracteres.       │                           │   ÚNICO carácter.             │
└───────────────────────────────┘                           └───────────────────────────────┘
```

---

### Matriz de Comodines y Comportamiento de Búsqueda

| Patrón | Significado / Regla | Ejemplos Coincidentes |
| :--- | :--- | :--- |
| **`'a%'`** | Comienza con `a`, seguido de cualquier cantidad de caracteres. | `apple123`, `art`, `a` |
| **`'a_'`** | Comienza con `a` y tiene **exactamente 2 caracteres**. | `as`, `an`, `a7` |
| **`'a__'`** | Comienza con `a` y tiene **exactamente 3 caracteres**. | `ant`, `add`, `a1c` |
| **`'%a'`** | Termina con `a`, precedido de cualquier cantidad de caracteres. | `pizza`, `Z6ra`, `a` |
| **`'_a'`** | Termina con `a` y tiene **exactamente 2 caracteres**. | `ma`, `1a`, `Ha` |
| **`'%a%'`** | Contiene la letra `a` en **cualquier posición**. | `Again`, `back`, `a` |
| **`'_a_'`** | Longitud total de **3 caracteres** con `a` en la posición central. | `Car`, `ban`, `ea7` |

## 4. Ejemplos Prácticos en SQL

### Ejemplo 1: Búsqueda con `%` (Prefijos Múltiples)
Buscar a todos los empleados con cargos del área de TI (`IT Staff`, `IT Manager`, `IT Support`):

```sql
SELECT lastname, firstname, title, email
FROM employees
WHERE title LIKE 'IT%';
```

> [!TIP]
> Al utilizar `'IT%'`, la consulta recuperará cualquier registro cuyo campo `title` empiece por las letras `IT`, sin importar cuántos caracteres le sigan.

---

### Ejemplo 2: Búsqueda con `_` (Longitud Fija de Caracteres)
Localizar clientes cuyo estado (`state`) comience por la letra `N` y tenga exactamente dos caracteres (abreviaturas como `NY`, `NV`, `NS`, `NT`):

```sql
SELECT firstname, lastname, state, country
FROM customers
WHERE state LIKE 'N_';
```

---

## Puntos Clave

> [!IMPORTANT]
> * **Propósito de `WHERE`:** Filtra los registros devueltos por una consulta antes de proyectar las columnas seleccionadas.
> * **Operador `LIKE`:** Permite realizar búsquedas basadas en patrones y comparaciones parciales de texto.
> * **Comodín `%`:** Sustituye cero, uno o múltiples caracteres arbitrarios.
> * **Comodín `_`:** Sustituye de forma estricta un solo carácter por cada guión bajo utilizado.
