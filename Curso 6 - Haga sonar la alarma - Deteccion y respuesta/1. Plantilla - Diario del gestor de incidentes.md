# Diario del gestor de incidentes

## Instrucciones

A medida que avanzas en este curso, puedes usar esta plantilla para registrar tus hallazgos después de completar una actividad o para tomar notas sobre lo que has aprendido sobre una herramienta o concepto específico. También puedes usar este diario como una forma de registrar los puntos clave sobre las diferentes herramientas o conceptos de ciberseguridad con los que te encuentres a lo largo de este curso.
