# Bitácora de Aprendizaje y Portafolio: Google Cybersecurity

Este repositorio documenta mi trayectoria y aprendizajes durante la preparación para obtener el **Certificado Profesional de Google Cybersecurity**. Aquí archivo mis resúmenes, análisis de conceptos, glosarios y documentación sobre herramientas y metodologías clave del sector.

---

## Escenario y Propósito

El objetivo principal de este espacio es doble:

1. **Consolidar conocimientos técnicos:** Servir como base de conocimiento sobre redes, sistemas operativos, programación (Python/SQL), herramientas defensivas (SIEM/IDS) y metodologías forenses.
2. **Construir un portafolio profesional:** Diseñar y refinar una **Declaración Profesional** activa que evolucione a medida que adquiera nuevas habilidades, con el fin de compartirla con futuros empleadores al iniciar mi búsqueda laboral en el sector de la ciberseguridad.

---
